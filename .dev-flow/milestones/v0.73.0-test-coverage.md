### 2 Rollup 编译警告修复

- **功能目标**：修复 `bun run build` 时 Rollup 报告的 @vueuse/core #__PURE__ 注释解析警告
- **文件结构**：
  - 可能修改：`packages/rex-console-web/package.json`（升级 @vueuse/core 版本）
  - 可能修改：`packages/rex-console-web/vite.config.ts`（配置 Rollup treeshake 选项）
- **修复方案**（按优先级尝试）：
  1. 升级 @vueuse/core 到最新版本（可能已修复）
  2. 若升级无效，在 vite.config.ts 的 build.rollupOptions 中配置 `treeshake.moduleSideEffects` 忽略该模块的注释警告
  3. 若以上均无效，确认警告不影响构建产物，在构建脚本中抑制该警告
- **测试标准**：`bun run build` 无警告输出（或仅剩无法修复的第三方警告）
- **提交信息**：`fix: resolve Rollup build warning for @vueuse/core #__PURE__`
