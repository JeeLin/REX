# v0.71.1: 原型对齐修复

## Context
v0.71.0 完成了全站 UI/UX 重设计，但审计发现多处与原型的偏差。本里程碑逐页修复所有 🔴/🟡 问题，确保 Vue 实现严格对齐 `prototypes/rex-1.0/` 原型。

版本类型：patch（修复偏差，无新功能）

## 产品边界
**本阶段做**：
- 修复所有 🔴 CRITICAL 偏差（结构/布局/功能缺失）
- 修复所有 🟡 MODERATE 偏差（交互/样式差异）
- 不改变任何 TypeScript 逻辑、API 调用、数据流
- 不添加新功能，只对齐已有原型

**本阶段不做**：
- 🟢 MINOR 偏差（类命名、加载状态等可接受差异）
- 工作空间分组（主用/排障）— 需要后端支持，下个版本
- 拓扑视图 — 需要后端 API，下个版本
- 审计详情操作特定内容 — 需要后端支持，下个版本

### 1 AppLayout 侧栏+顶栏修复

- **功能目标**：侧栏和顶栏严格对齐 `01-dashboard.html` 原型
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **原型参考**：`prototypes/rex-1.0/01-dashboard.html`
- **修复项**：
  - 侧栏：添加"新建资源"按钮（原型中有 `REX.newResource()` 按钮）
  - 顶栏：添加搜索框（Quick connect, Ctrl N）、通知铃铛图标、刷新按钮
  - 面包屑：显示 "REX" 而非 "REX Hub"
  - 主题切换图标：月亮（原型）vs 太阳（当前）
  - 语言切换：显示"中"文字（原型）vs 地球 SVG 图标（当前）
  - 品牌 glyph：添加 `box-shadow` 琥珀色光环
  - 快捷键：显示 "Ctrl K"（原型）vs "⌘K"（当前）
- **提交信息**：`fix(ui): align sidebar+topbar with 01-dashboard prototype`
