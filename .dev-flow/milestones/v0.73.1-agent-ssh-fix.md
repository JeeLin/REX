# v0.73.1: Agent SSH 连接修复

## Context

v0.73.0（测试覆盖补全 + 质量门禁）已完成，所有核心功能和质量门禁已就绪。用户报告 Agent 模式下 SSH 连接存在阻断性 bug：首次连接建立后无法输入命令，后续连接全部报 "SSH connection failed"。日志显示首条 `AGENT_SSH_CONNECTED` 成功，但之后连续 `AGENT_SSH_FAILED`。这是 Agent 协议终结架构（v0.70.6 引入）的回归问题。

版本类型：patch（bug 修复，无新功能）

## 产品边界

**本阶段做什么：**
- 定位 Agent SSH 隧道中命令输入失败和后续连接失败的根因
- 修复 Agent 模式下 SSH 会话的命令输入和连接复用问题
- 回归测试：验证直连/Agent 模式 SSH 均可用，质量门禁全绿

**不做什么：**
- 不新增 SSH 功能（如新认证方式、新终端特性）
- 不修改 Hub 直连 SSH 的代码路径
- 不重构 Agent 隧道架构

## 子任务详细设计

### 1 定位问题根因

- **功能目标**：分析 Agent SSH 隧道中命令输入失败和后续连接失败的原因
- **文件结构**：
  - 分析：`crates/rex-agent/src/agent_ssh.rs`（Agent SSH 会话管理）
  - 分析：`crates/rex-agent/src/agent_ws.rs`（Agent WebSocket 隧道、channel 管理）
  - 分析：`crates/rex-hub/src/terminal_ws.rs`（Hub 侧 Agent 终端桥接）
  - 分析：`crates/rex-ssh/src/`（russh 会话封装）
- **排查方向**：
  1. **Channel 清理**：首次 SSH 会话结束后，`channels` map 中的条目是否被正确移除；Hub 侧 `tunnel_data` map 是否同步清理
  2. **SSH 会话生命周期**：russh Session 是否在 `run_ssh_session` 结束后被正确 drop；是否存在连接池或句柄泄漏
  3. **PTY 分配**：首次连接是否正确请求了 PTY；终端数据是否经过 PTY 而非 raw channel
  4. **数据转发路径**：Hub → Agent 的 `[4B channelId][data]` 帧是否被正确路由到 `data_rx`；Agent → Hub 的终端输出帧是否被 Hub 正确分发到前端 WebSocket
  5. **错误处理**：`AGENT_SSH_FAILED` 的具体 error message 是什么；是否为 SSH 认证失败、连接超时、或 channel 冲突
- **测试标准**：产出根因分析报告，明确问题点和修复方案
- **提交信息**：`fix: diagnose agent SSH connection failure root cause`

### 2 修复 SSH 连接

- **功能目标**：修复 Agent 模式下 SSH 会话的命令输入和后续连接问题
- **文件结构**：
  - 可能修改：`crates/rex-agent/src/agent_ssh.rs`（SSH 会话管理、channel 注册/清理）
  - 可能修改：`crates/rex-agent/src/agent_ws.rs`（channel 生命周期、connect 路由）
  - 可能修改：`crates/rex-hub/src/terminal_ws.rs`（Hub 侧 tunnel data 清理、重连逻辑）
  - 可能修改：`crates/rex-ssh/src/`（russh 会话封装，如有 PTY/连接问题）
- **修复原则**：
  - 最小化修改范围，仅修复阻断性问题
  - 不改变 Agent SSH 的整体架构（russh 终结 + tunnel 帧复用）
  - 确保首次连接可正常输入命令
  - 确保连接关闭后资源完全释放，后续连接可正常建立
- **测试标准**：修复后 Agent SSH 首次连接可正常交互；关闭后再次连接正常；直连 SSH 不受影响
- **提交信息**：`fix: resolve agent SSH command input and reconnection failure`

### 3 回归测试 + 质量门禁

- **功能目标**：验证修复有效，全量质量门禁通过
- **检查项**：
  - `cargo fmt --check` — Rust 格式检查
  - `cargo clippy --workspace --all-targets` — Rust lint 检查
  - `cargo test --workspace` — Rust 测试全部通过

  - `bun run build` — 前端构建成功
  - `bun run test` — 前端 vitest 测试全部通过
- **测试标准**：以上全部检查通过，无 error
- **提交信息**：`test: verify agent SSH fix with quality gate`
