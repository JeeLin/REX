# REX Hub — 产品文档

REX Hub 是一款面向个人开发者和运维工程师的自托管远程资源统一管理平台。

---

## 0. 设计基调

**视觉语言是 REX 自己的，但交互布局与操作逻辑对标成熟专业工具**，以降低学习成本、提升专业感：

| 模块 | 对标产品 | 借鉴的层面 |
|------|----------|-----------|
| 工作空间外壳 | **Xshell** | 连接管理、Tab、分屏、状态栏 |
| SSH 终端 | **Xshell** | 终端交互、选择/查找、SFTP 抽屉 |
| 数据库控制台 | **Navicat** | 库表树、查询编辑器、结果网格、表设计器 |
| Redis 控制台 | **Another Redis Desktop Manager (ARDM)** | 键树、值查看器、CLI、Server Status |
| 文件管理 (SFTP) | **Xftp** | 双面板、传输队列、同步浏览 |
| 对象存储 (S3/MinIO) | **Xftp（文件系统风格）** | 双面板、传输队列 |
| 管理模块（仪表盘/环境/Agent/审计/设置） | **REX 自有设计系统** | — |

> 关键原则：**复刻的是操作方式与布局逻辑，不是 Windows 桌面软件的外观**。所有界面是现代 Web 实现、深色优先、极客美学、高信息密度、键盘驱动、易用。

### 设计三要素

- **现代化（Modern）**：Web 原生交互，不使用桌面软件皮肤移植；自定义细滚动条、流畅过渡、响应式。
- **极客化（Geek）**：终端美学、等宽字体、高信息密度、键盘优先、深色优先、可定制主题。
- **易用化（Usable）**：操作逻辑对标用户已熟悉的专业工具，降低心智负担；一致的交互范式贯穿全站。

## 1. 产品定位

### 核心问题

| 问题 | 现状 | REX Hub 的答案 |
|------|------|---------------|
| 多种资源需要多个工具 | SSH 用 Terminal，MySQL 用 Navicat，Redis 用 ARDM，文件用 FileZilla… | **一个 Web 页面**管理所有远程资源 |
| 内网资源无法从外部访问 | 依赖 VPN、端口转发、跳板机 | 部署 Agent 后，**任何有网络的地方**都能访问 |
| 数据在第三方平台 | 使用在线 SaaS 工具，数据不可控 | 完全**自托管**，数据留在自己的基础设施上 |

### 两个目标

1. **一个平台覆盖多种资源类型** — SSH 终端、数据库查询、Redis 管理、文件传输、对象存储，不再在多个客户端之间切换。
2. **一个服务访问公网 + 内网资源** — 通过内网 Agent 代理，公网和内网服务器统一管理，无需 VPN 或端口转发。

### 设计方法

每个协议模块的交互与布局对标其领域最成熟的桌面工具（工作区 / Xshell、SQL / Navicat、Redis / ARDM、文件 / Xftp），用现代 Web 实现复刻其**操作逻辑**，而非其外观。对标是 1.0 阶段打磨每个协议体验的手段，不是承诺在每个单点上超越原工具。

### 产品属性

- **单用户** — 专为个人使用设计，不涉及多用户、团队协作、RBAC 权限。
- **自托管** — Docker 部署，数据完全自主掌控。
- **深色优先** — 终端美学，适合长时间运维工作场景。

### 1.0 边界（阶段）

- **阶段 1 — 单协议深度**：7 类协议各自做到可用、好用，交互对标成熟工具。
- **阶段 2 — Agent 代理体验**：内网隧道、注册、心跳、自更新、断线自愈、部署指南完整可用。
- **阶段 1 + 阶段 2 即 1.0。**
- **支持的资源类型**：SSH、SFTP、MySQL、PostgreSQL、Redis、SQLite、S3 / MinIO、SIP 电话 —— 覆盖终端、数据库、缓存、文件、对象存储、语音通信六类，是 1.0 阶段的核心能力边界。
- **访问形态**：1.0 通过 Web 控制台访问。阶段 4（桌面端）为后续演进方向，故 Web 是 1.0 的呈现形态而非产品固有属性。
- 阶段 3（跨协议联动）与阶段 4（桌面端）为 1.0 之后的演进方向，当前不在 1.0 范围内。

### 命名

- **REX** = **R**emote **E**xchange（远程交换）：在一个页面里交换、中转对各类远程资源的操作。
- **Hub / Agent** 是两个二进制：Hub 是部署在用户侧的服务端（托管前端 + 聚合资源），Agent 是部署在目标内网的反向代理进程。**"Hub" 用于与 Agent 区分**，不是泛称"中枢"。

## 2. 核心概念

### 2.1 环境 (Environment)

资源的逻辑分组。按部署网络或用途划分，每个环境拥有独立的 Agent 和资源集合。

典型分组：阿里云（公网直连）、家里服务（内网 Agent 代理）、家庭 NAS（内网 Agent 代理）。

每个环境包含：名称（必填）+ 描述（选填）、连接方式（Agent 代理或直连）、注册令牌、一个 Agent 实例（可选）、多个资源。

### 2.2 Agent

部署在目标网络中的轻量级反向代理进程。从内网主动出站连接 Hub，建立 WebSocket 加密隧道，内网服务器无需开放入站端口。

每个 Agent 属于一个环境，代理该环境下的所有内网资源。状态：🟢 在线 / ⚫ 离线。

Agent 元信息：版本号、Agent ID、连接 IP、运行时间、延迟、传输量、代理资源数。

Agent 设备信息：操作系统、架构、主机名、系统版本——影响终端提示、平台差异提醒、二进制下载推荐、资源扫描。

### 2.3 资源 (Resource)

可连接的远程实体，属于一个环境，通过指定协议连接。支持 8 种协议：

| 协议 | 图标 | 用途 | 色值 |
|------|------|------|------|
| SSH | `$` | 远程终端 | `#3FB950` 绿色 |
| SFTP | 📁 | 文件传输 | `#8B5CF6` 紫色 |
| MySQL | `dB` | 数据库查询 | `#58A6FF` 蓝色 |
| PostgreSQL | `pg` | 数据库查询 | `#8B5CF6` 紫色 |
| Redis | `R` | 缓存管理 | `#F85149` 红色 |
| SQLite | `S` | 本地数据库 | `#D29922` 橙色 |
| S3 / MinIO | ☁ | 对象存储 | `#E8912D` 主色 |
| SIP 电话 | ☎ | 软电话 / 通话 | `#2DD4BF` 青色 |

### 2.4 连接方式

| 方式 | 标识 | 说明 |
|------|------|------|
| Agent 代理 | ⬡ `#E8912D` | 通过内网 Agent 隧道访问 |
| 直连 | ◉ `#58A6FF` | 控制台直接连接目标 |

## 3. 功能模块

### 3.1 登录

全屏登录页。用户名密码 + 「记住我」+「忘记密码？」。底部版本号。CRT 扫描线视觉（极客风）。

### 3.2 仪表盘 (Dashboard)

系统概览入口。统计卡片（环境数 / 资源数 / Agent 在线数 / 今日操作数）、快速连接（最近使用资源）、环境卡片网格。响应式：桌面侧栏 + 卡片网格；移动端底部导航 + 单列卡片。

### 3.3 环境管理 (Environments)

卡片式展示所有环境（名称、Agent 状态、描述、资源类型分布、连接方式统计、最后活跃）。支持创建/编辑/删除环境，环境详情页含 Agent 面板 + 资源表格。

### 3.4 资源创建

4 步向导：选择协议 → 基本信息+连接方式 → 连接详情（按协议不同表单，含测试连接）→ 完成。支持深度连接属性（参考 Xshell 的 per-session 属性对话框：认证方式、终端、保活、隧道等）。

### 3.5 工作空间 (Workspace) — 对标 Xshell

多面板工作区，是核心操作画布。把 Xshell 的连接管理 + 多标签 + 分屏体验搬到 Web。

**三层连接模型：**
- **可停靠连接树侧栏**（左侧，可折叠）：环境 → 资源分组，按协议彩色图标展示，可拖拽组织、可搜索。点击资源即在工作区打开对应控制台 Tab。
- **深度资源属性对话框**：单击资源「属性」打开，分类树（连接 / 认证 / 终端 / 外观 / 保活 / 隧道），复用资源创建向导的连接详情深度配置。
- **Quick Connect 栏**（顶部）：协议下拉 + 主机 + 端口 + 用户名 + 连接，用于临时即席连接（不保存）。

**标签页管理（Xshell 模式）：**
- Tab 栏位于顶部，单排可横向滚动（« » 箭头）。
- 每个 Tab 显示：协议图标 + 资源名 + 连接状态点（🟢 在线 / ⚫ 离线 / 🟠 连接中）+ 关闭按钮。
- 每 Tab 支持：**设颜色**（按环境/用途区分，如 prod=红）、**重命名**（不改资源名）、**「发送到全部」广播开关**（输入同步到所有 Tab）。
- 拖拽排序；拖拽 Tab 到另一 Pane 改变归属；双击空区域 / `+` 新建。
- 去重：相同名称+协议不重复打开。
- 右键菜单：关闭 / 关闭其他 / 关闭右侧 / 关闭左侧 / 关闭全部 / 复制标签 / 移动到面板 ▸ / 新建连接 / 全部断开。

**分屏布局（Xshell 模式）：**
- Pane 嵌套在窗口内，Tab 嵌套在 Pane 内。Pane 间分隔条可拖拽缩放。
- 布局模式（Alt+1~5）：单面板 / 左右分屏 / 上下分屏 / 四宫格 / 主+侧边。
- 双击 Tab 进入左右分屏；拖 Tab 到目标 Pane 填充或交换；拖出可分离到新窗口（可选）。
- 布局切换按 Tab 顺序自动填充面板。

**快捷键面板（F1）：** 分组展示所有快捷键。全屏切换 F11。

**状态栏（底部，紧凑可点击）：** 协议+主机+端口、连接状态、终端尺寸（cols×rows，实时更新）、编码（点击切换）、广播/锁状态指示。

### 3.6 SSH 终端 — 对标 Xshell

基于 xterm.js 的完整终端。

**工具栏：** 连接状态 + 资源名 + 延迟 · 复制 / 粘贴 / 清屏 / SFTP / 全屏 / 断开。

**终端区：**
- 可配置光标（块 / 下划线 / 竖条）+ 闪烁开关；块选 / 行选切换；大滚动缓冲可配置。
- 非模态**终端内查找栏（Ctrl+F）**：顶部查找条，匹配高亮 + 上/下 + 区分大小写/整词/正则。
- ANSI 完整仿真，256 色 + TrueColor，块状光标动画。

**右键菜单：**
- 复制 / 粘贴（含 **bracketed paste** 防止粘贴自动执行）/ 全选 / 清屏 / 查找
- 编码 ▸ 子菜单（UTF-8 / GBK / ISO-8859-1 一键切换乱码时用）
- 重连 / 复制地址 / 打开 SFTP / 断开

**内置 SFTP 抽屉（Xftp 核心做进终端）：** 工具栏「SFTP」按钮，在右侧/下方打开内嵌文件面板，复用同一 SSH 通道（不另开连接）。详见 3.8。

**主题：** ANSI 调色板（bg/fg/cursor）+ 可选透明度 + 背景图；bundle 几个预设（Default / Ubuntu / Solarized）。

**移动端浮动工具栏：** 方向键区（↑↓ 兼 bash 历史）+ Tab + Enter + ^C + ^L；功能按钮（历史 / 粘贴 / 字体缩放 / 更多）。

### 3.7 SQL 控制台 — 对标 Navicat

数据库查询管理界面。**两栏布局**：左导航树 + 右对象区（Tab 式），DDL 预览进抽屉。

**顶部导航栏：** 面包屑（环境 › 资源 › 库）· 数据库选择器 · 刷新 · 全局查询 · AI 助手。

**导航树（左栏，可拖拽调宽）：**
- 层级：连接组 → 连接 → 库/Schema → 表（可展开 字段/索引/外键）/ 视图 / 函数 / 存储过程 / 事件。
- 双击表 → 打开数据网格；双击字段 → 打开表设计器定位该字段。
- 顶部搜索框实时过滤，自动展开匹配分支。
- 右键：建表/视图/过程/函数/事件、Dump SQL、Execute SQL、Truncate、属性等（10-20 项按对象类型）。

**查询编辑器（对象区 Tab）：**
- Tab 多开，`.sql` 保存文件；未保存显示「查询 N」，已保存显示文件名。
- 语法高亮（按数据库方言高亮保留字）；输入 `.` 触发对象属性补全，ESC 手动触发补全；代码折叠（括号匹配）；查找替换栏（Ctrl+F / Ctrl+Shift+R）。
- 剪贴板栈（Ctrl+Shift+V 循环最近 10 项）。缩放（Ctrl+=/-/0）。格式化 / 大小写转换 / 注释。
- 执行模式：**Run**（全部）/ **Run Current**（光标所在语句）/ **Run Selected**（选中）/ Continue on Error / Stop。

**结果网格（对象区 Tab）：**
- 类电子表格：单元格内联编辑（日期选择器、JSON 编辑器等高级编辑器）；列头点击排序；列过滤；行选择。
- 变更追踪：修改单元格视觉标记，工具栏 Apply（应用）/ Discard（丢弃）提交或回滚。
- 表单视图（一次一条记录）+ 网格视图切换。
- 底部状态：返回行数 / 执行时间 / 当前库。操作：复制 / 导出（CSV·JSON·SQL）/ 格式切换。

**表设计器（对象区多 Tab）：** 字段（列编辑器：名/类型/长度/unsigned/默认值/自增/字符集/注释，可拖拽重排）/ 索引 / 外键（ON DELETE/UPDATE 动作）/ 约束 / 选项 / DDL（只读 CREATE TABLE 预览）。

**DDL 抽屉：** 信息面板内容进抽屉——展示选中对象的 DDL 预览、依赖关系，可最大化。

**导入/导出向导：** CSV / JSON / SQL / XML 等；配置可存为 profile 复用；拖文件到表触发导入向导。

**全局查询（Ctrl+Shift+Q）：** 跨库查询模态，多选库，提示「仅支持相同方言」。

**AI 助手（Ctrl+Shift+A）：** 右侧抽屉，上下文（库/表/查询），快捷操作（分析慢查询/优化/生成 SQL/表关系），风险提示，复制优化 SQL。

### 3.8 SFTP 文件管理 — 对标 Xftp

远程文件浏览和传输界面。**双面板：本地（左）/ 远程（右）**，每面板可多标签。

**活动面板模型（Xftp 核心）：** 每个面板有独立选中态 +「活动面板」概念（聚焦面板高亮）。Upload/Download 作用于活动面板选中项，推送到对面面板。Tab 切换面板。

**双面板布局：**
- 左面板 — 本地文件浏览；右面板 — 远程文件浏览（或对象存储 prefix）。
- 面板头：当前路径 + 可编辑路径栏（输入路径回车跳转、最近目录下拉、面包屑）。
- 文件列表（Details 表格）：名称（类型图标前缀）/ 大小 / 修改时间 / 权限（SFTP）或 Storage Class·ACL（S3）。
- 双击文件夹进入，`..` 返回上级。

**传输队列（底部常驻可折叠抽屉）：**
- 传输项：文件 / 方向（↑ 上传 ↓ 下载）/ 大小 / 进度条 / 速率 / 状态（等待/传输中/完成/失败/暂停）。
- 总吞吐聚合 + 每文件进度。暂停 / 恢复 / 取消（单个或全部）。
- 断点续传：SFTP 重开 seek；S3 multipart 续传。

**拖拽传送：** 拖选中项到对面面板传输（方向由拖拽源→目标决定）。

**右键菜单：**
- 文件/文件夹：打开 / 编辑（临时下载→编辑→保存回传）/ 下载 / 上传 / 重命名 / 删除 / 属性 / 复制路径 / 权限（SFTP chmod 复选框矩阵）。
- 文件夹：同步 / 新建文件夹。
- 空白：上传 / 新建文件 / 新建文件夹 / 粘贴 / 刷新 / 全选。

**同步浏览：** 开关——一侧进入 `foo/` 自动另一侧跳到相对 `foo/`。
**文件夹同步对话框：** 方向（上传/下载/双向）/ 比较依据（大小·时间）/ 包含排除掩码 / 删除孤儿 / 预览。

**工具栏常驻动词：** 刷新 / 新建文件夹 / 上传 / 下载 / 删除。
**移动端：** 上下分栏，隐藏权限列，底部浮动工具栏（上传/新建/刷新/更多）。

### 3.9 Redis 控制台 — 对标 ARDM

Redis 缓存管理界面。**双面板：左连接+键树 / 右固定值查看器**（支持「在新标签打开」独立成 Tab）。

**左侧连接+键树（可拖拽调宽，默认 265px）：**
- 连接列表：可搜索、颜色标签、hover 图标簇（状态 / CLI / 刷新 / more 下拉：编辑/删除/复制/内存分析/慢日志/导入/FlushDB）。
- 展开连接：DB 选择器（每 DB 显示实时键数 + 自定义名）+ 键树 + Load more 页脚。
- 键树：虚拟滚动（支持 20w+ 键）；按分隔符（默认 `:`）分命名空间文件夹，文件夹显示实时 `(count)` 徽章；SCAN 流式分页（绝不一次加载全部）；精确匹配搜索（防抖）；Shift 范围多选。
- 右键：文件夹（多选/内存分析/按前缀加载/批量删除）；键（复制/删除/多选/新标签打开/导出）。

**右侧值查看器（固定，可「在新标签打开」成 Tab）：**
- 键名 + TTL 字段（persist/历史）+ 删除 + 刷新（自动刷新开关）+ dump。
- **通用 FormatViewer**：Text / Hex / Json / Binary / Msgpack / PHPSerialize / JavaSerialize / Pickle / 压缩等 + 自动探测；不可打印显示 `[Hex]` 标签 + `Size:` 标签。
- 集合类型表格（行高紧凑、斑马纹）：
  - String：FormatViewer + 保存（恢复 TTL）。
  - Hash：# / 字段 / 值 / TTL(≥7.4) / 操作；增改对话框（字段+值+可选TTL）。
  - List：# / 值 / 操作；LRANGE 分页。
  - Set：# / 值 / 操作；SSCAN。
  - ZSet：# / 分数 / 成员 / 操作；DESC/ASC 切换。
  - Stream：# / ID / 值(JSON) / 操作；Max/Min ID 过滤 + 消费组表格。
  - 每行：复制 / 编辑 / 删除 / dump 按钮；工具栏「Add new line」+ 每类型操作 + Load more。

**CLI（工具栏「终端」按钮，独立 Tab）：** Monaco（vs-dark）只读日志 + 命令输入行；Ctrl+L 清屏；命令历史 + 自动补全提示。

**Server Status（独立 Tab）：** 卡片仪表盘——Server（版本/OS/PID）/ Memory（used/peak/lua 人性化）/ Stats（连接数/命令数）/ 键统计（每 DB 行：库/键数/过期/平均 TTL）/ 原始 INFO 表格（可搜索）+ 自动刷新（2s）。

**批量操作：** 批量删除（checkbox + 规则）/ 批量 TTL / 导入导出（选中键导出文件、导入键、导入 CMD 批量命令）。

### 3.10 SIP 电话 — 对标软电话（浏览器实时通话）

SIP 软电话资源（第 8 种协议）。Hub 侧 baresip UA（UA₁）负责信令（拨号/接听/挂断/保持/转 DTMF），Agent 侧 baresip UA（UA₂）经现有 WebSocket 隧道链式转发，让内网 SIP 服务器由 Agent 出网。

**信令与媒体：**
- 拨号盘 + 通话状态（拨号中/通话中/保持/挂断），支持 DTMF、通话保持/恢复。
- 浏览器**实时双向音频**：Hub/Agent 终止 RTP 抽出原始 S16LE PCM，经 WebSocket 媒体通道（原始 PCM 二进制帧）推流到浏览器；浏览器用 Web Audio 播放、麦克风经 `getUserMedia` 采集回传（回声抑制）。媒体为实时流，是「文件传输不经过浏览器」原则的显式例外。
- 视频（可选）：浏览器实时视频（WebCodecs + `<video>`），与音频共用隧道/WebSocket 帧。

**可观测与记录：**
- 通话记录（CDR）：起止/对端/时长/状态（SQLite 持久化）+ 前端表格（筛选/排序/详情）。
- 通话录音：Hub 落盘（mp3/wav），前端回放（进度/暂停/下载）。
- 信令抓包：UA₁/UA₂ 两侧 SIP 报文捕获导出 pcap，前端回看/下载。
- 音视频质量监控：丢包率、端到端延迟、抖动可视化。

**设计要点：** baresip 是 C 库，不能跑在浏览器，必须在 Hub/Agent 服务端；Hub/Agent 版本须一致（无跨版本兼容）。

### 3.11 Agent 管理

卡片式展示 Agent（名称+状态、环境、设备信息、元信息网格、配置/日志/重置令牌按钮）。配置弹窗（环境/Agent ID/版本只读、服务器/令牌、auto_update 开关 + 更新状态：update_phase/update_error/版本一致性）。日志查看器（级别筛选、自动滚动、终端风）。令牌重置弹窗。部署指南（二进制/Docker/Compose/配置 4 种，按 Agent OS/架构推荐下载命令）。

### 3.12 审计日志

### 3.13 个人设置

## 8. 技术架构

### 进程模型
Hub 和 Agent 均为单二进制 + supervisor + worker。父进程 supervisor（启动/监控/替换/回滚），worker 执行业务逻辑。Hub/Agent 版本一致，无跨版本兼容。

### 通信协议
| 链路 | 协议 |
|------|------|
| 控制台 ↔ 服务端 | HTTPS（REST API）+ WebSocket（终端/数据实时流） |
| Agent ↔ 服务端 | WebSocket (TLS) 加密反向隧道 |

### 加密
传输 TLS 1.3；凭据 AES-256 本地加密存储。

### 自更新机制
阶段 2：worker 检查更新→下载→校验 SHA256→备份→写 update-state→优雅退出→supervisor 替换→健康轮询（失败 3 次回滚）。Hub/Agent 同进程模型。

### 共享 Rust crate
Hub 和 Agent 共享协议与传输 crate（workspace 根 `Cargo.toml` `members = ["crates/*"]`）：
- 协议实现：`rex-ssh`（SSH/SFTP）、`rex-mysql`、`rex-postgresql`、`rex-redis`、`rex-sqlite`、`rex-s3`、`rex-sip`（baresip FFI：UA/音频桥/视频桥/抓包/CDR/录音）
- `rex-transfer`（文件传输引擎，统一 `FileConnector` 抽象）
- `rex-common`（通用类型/错误/配置解析/`supervisor` 模块/`sip_media` 媒体帧编解码/更新）
- `rex-hub`（整合所有 crate + 前端静态资源托管）、`rex-agent`（整合所有 crate）

> 注：`supervisor`（进程模型）与 `tunnel`（WebSocket 隧道）是 `rex-common` / `rex-hub` 内的**模块**，并非独立 crate。

### 文件传输架构
- 前端（Vue）：文件浏览器 UI、传输队列 UI、进度、冲突处理弹窗；只调 Hub 的 `/api/files` REST + WebSocket，不经浏览器中转。
- 后端 `rex-transfer` + `FileConnector` trait：统一抽象对接 SSH/SFTP（`SftpConnector`）、S3/MinIO（`S3Connector`）、本地（`MemConnector` 等）；支持分片上传/续传（`upload(remote_path, data, offset, progress)`、`download_range`）。
- 数据在 Hub/Agent/远端之间传输，不经过浏览器。
- 冲突处理：覆盖/跳过/另存/失败。安全：路径规范化禁 `../` 逃逸、限大小/并发/速率、审计所有文件操作。
