# 0.67.0: 前端 UX 细节打磨

## Context

0.66.0 完成了 S3/SQLite 控制台移动端优化。所有主要功能模块和移动端适配已完成，本里程碑聚焦前端交互体验细节提升，包括加载状态、空态引导、操作反馈，提升整体产品完成度。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 统一骨架屏加载状态（Dashboard、环境列表、Agent 列表）
- 空态引导优化（收藏、最近使用、环境列表为空时的引导提示）
- 操作反馈增强（按钮加载态、操作确认反馈、Toast 优化）

**不做什么：**
- 不修改后端 API
- 不改变桌面端整体布局
- 不引入新功能模块

## 子任务详细设计

### 1 统一骨架屏加载状态

- **功能目标**：为主要列表页面添加骨架屏加载动画，替代当前的纯文字 loading
- **文件结构**：
  - 新建 `packages/rex-console-web/src/components/SkeletonLoader.vue`
  - 修改 `packages/rex-console-web/src/pages/Dashboard.vue`
  - 修改 `packages/rex-console-web/src/pages/Environments.vue`
  - 修改 `packages/rex-console-web/src/pages/AgentManagement.vue`
- **功能点**：
  - 创建通用 SkeletonLoader 组件，支持 card/list/table 三种变体
  - Dashboard 加载时显示统计卡片骨架和环境卡片骨架
  - 环境列表加载时显示环境卡片骨架
  - Agent 列表加载时显示 Agent 卡片骨架
  - 骨架屏使用 CSS animation 实现渐变闪烁效果
- **提交信息**：`feat: add skeleton loader for dashboard and list pages`

### 2 空态引导优化

- **功能目标**：优化收藏、最近使用、环境列表为空时的引导提示
- **文件结构**：
  - 修改 `packages/rex-console-web/src/components/Sidebar.vue`
  - 修改 `packages/rex-console-web/src/pages/Environments.vue`
  - 修改 `packages/rex-console-web/src/pages/Dashboard.vue`
- **功能点**：
  - 侧边栏收藏为空时显示「收藏资源以快速访问」+ 图标引导
  - 侧边栏最近使用为空时显示「连接过的资源会出现在这里」+ 图标引导
  - 环境列表为空时显示「创建第一个环境」+ 创建按钮引导
  - 仪表盘快速连接为空时显示「连接过的资源会出现在这里」引导
  - 所有空态使用统一的 EmptyState 组件样式
- **提交信息**：`feat: improve empty state guidance`

### 3 操作反馈增强

- **功能目标**：增强按钮加载态、操作确认反馈和 Toast 通知体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/ResourceNew.vue`
  - 修改 `packages/rex-console-web/src/pages/EnvironmentNew.vue`
  - 修改 `packages/rex-console-web/src/components/Toast.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceSqlite.vue`
- **功能点**：
  - 资源创建向导「测试连接」按钮点击后显示加载态（spinner + 文字变化）
  - 环境创建「创建」按钮点击后显示加载态
  - SQLite 面板「连接」按钮点击后显示加载态
  - Toast 通知增加自动关闭动画（slide out）和手动关闭按钮
  - 成功 Toast 持续 3 秒，错误 Toast 持续 5 秒
- **提交信息**：`feat: enhance operation feedback and toast animations`
