# M24: SFTP 文件管理增强（同步浏览 + chmod + 编辑功能）

## Context

M0–M23 完成了从项目骨架到 Redis 控制台增强的全部开发。SFTP 文件管理已有双面板、传输队列、右键菜单基础功能。本里程碑对标 Xftp 的完整文件管理能力，补齐同步浏览、chmod 权限管理和编辑功能。

本里程碑版本类型：minor（新功能），版本号 0.24.0 → 0.25.0。

## 产品边界

**本阶段做：**
- 同步浏览：一侧进入文件夹自动另一侧跳到相对路径
- chmod 权限管理：SFTP chmod 复选框矩阵
- 编辑功能：临时下载→编辑→保存回传
- 右键菜单增强：属性、复制路径

**本阶段不做：**
- 文件夹同步对话框（复杂度高，后续里程碑）
- 拖拽传送（需要复杂的拖放逻辑）
- 移动端浮动工具栏（优先级低）

## 子任务详细设计

### 1 同步浏览（进入文件夹自动跳转）

**功能目标**

支持双面板同步浏览，一侧进入文件夹自动另一侧跳到相对路径。

**文件结构**

修改：
- `packages/rex-console-web/src/features/files/FilesPage.vue` — 添加同步浏览逻辑

**交互设计**

```
┌─ Files ──────────────────────────────────────────────┐
│ [左面板: /home/user]  │ [右面板: /var/www]          │
│                       │                              │
│ 📁 documents          │ 📁 html                     │
│ 📁 downloads          │ 📁 logs                     │
│ 📄 readme.txt         │ 📄 config.txt               │
│                       │                              │
│ [同步浏览: ON]        │                              │
└─────────────────────────────────────────────────────┘

当左面板进入 documents/ 时，右面板自动跳转到 html/
```

**实现流程**

1. 添加同步浏览开关
2. 监听面板路径变化
3. 计算相对路径
4. 跳转到对面面板的相对路径

**测试标准**

- 开启同步浏览 → 左面板进入文件夹 → 右面板自动跳转
- 关闭同步浏览 → 左面板进入文件夹 → 右面板不跳转
- type-check + build 通过

**提交信息**: `feat(files): add sync browsing between panels`

### 2 chmod 权限管理（复选框矩阵）

**功能目标**

支持 SFTP 文件权限管理，通过复选框矩阵设置权限。

**文件结构**

修改：
- `packages/rex-console-web/src/features/files/FilesPage.vue` — 添加 chmod 功能

**交互设计**

```
┌─ Permissions: /home/user/readme.txt ─────────────────┐
│ Owner    Group    Other                              │
│ ☑ Read   ☑ Read   ☐ Read                            │
│ ☑ Write  ☐ Write  ☐ Write                           │
│ ☑ Exec   ☐ Exec   ☐ Exec                            │
│                                                      │
│ Octal: 740                                           │
│                      [Cancel] [Apply]                │
└──────────────────────────────────────────────────────┘
```

**实现流程**

1. 右键菜单添加「权限」选项
2. 打开权限编辑弹窗
3. 显示复选框矩阵（Owner/Group/Other × Read/Write/Exec）
4. 计算八进制值
5. 调用 SFTP chmod API

**测试标准**

- 右键文件 → 权限 → 打开权限编辑弹窗
- 修改权限 → 显示八进制值
- 应用权限 → 权限更新
- type-check + build 通过

**提交信息**: `feat(files): add chmod permission management`

### 3 编辑功能（临时下载→编辑→保存回传）

**功能目标**

支持临时下载文件到本地编辑，保存后自动回传。

**文件结构**

修改：
- `packages/rex-console-web/src/features/files/FilesPage.vue` — 添加编辑功能

**交互设计**

```
┌─ Files ──────────────────────────────────────────────┐
│ 右键菜单:                                            │
│   📄 打开                                            │
│   ✏️ 编辑                                            │
│   📥 下载                                            │
│   📤 上传                                            │
│   ...                                                │
└─────────────────────────────────────────────────────┘
```

**实现流程**

1. 右键菜单添加「编辑」选项
2. 下载文件到临时目录
3. 使用系统默认编辑器打开
4. 监听文件变化
5. 保存后自动上传回原路径

**测试标准**

- 右键文件 → 编辑 → 文件下载并打开
- 修改文件 → 保存 → 自动上传
- type-check + build 通过

**提交信息**: `feat(files): add edit with temp download and upload back`
