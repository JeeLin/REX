# 0.76.0: 后端可靠性加固

## Context

0.75.0 完成了后端测试补充和 clippy 代码清理。当前后端 Rust 代码中存在大量生产路径上的 `unwrap()` 调用（约 420 处），在并发场景下可能导致服务 panic 崩溃。同时，6 个 WebSocket handler 文件（ws_mysql/ws_postgresql/ws_redis/ws_s3/ws_sqlite/ws_terminal）共享高度重复的结构（共 2,155 行），维护成本高。CI 流程也存在缺口：前端测试未纳入 CI 执行。

版本类型：patch（可靠性改进，无新功能）

## 产品边界

**做什么：**
- 清理生产代码中的 `unwrap()` 调用，替换为正确的错误处理（`?`、`unwrap_or`、`expect`）
- 提取 WebSocket handler 通用框架，消除 6 个文件的重复代码
- CI 补全：前端测试加入 CI、修正过时注释

**不做什么：**
- 不添加新功能
- 不修改前端业务代码
- 不改变用户可见行为
- 不引入新的外部依赖

## 子任务详细设计

### 1 清理生产代码 unwrap()

- **功能目标**：将生产路径上的 `unwrap()` 替换为安全的错误处理，消除潜在 panic
- **文件结构**：
  - 修改 `crates/rex-hub/src/queries.rs`（78 处）
  - 修改 `crates/rex-hub/src/routes.rs`（67 处）
  - 修改 `crates/rex-hub/src/history.rs`（48 处）
  - 修改 `crates/rex-hub/src/sql.rs`（33 处）
  - 修改 `crates/rex-hub/src/env.rs`（29 处）
  - 修改 `crates/rex-transfer/src/local.rs`（27 处）
  - 修改 `crates/rex-transfer/src/executor.rs`（24 处）
  - 修改 `crates/rex-hub/src/metrics.rs`（22 处）
  - 修改 `crates/rex-hub/src/db.rs`（20 处）
  - 修改 `crates/rex-hub/src/files.rs`（16 处）
  - 修改 `crates/rex-hub/src/user.rs`（8 处）
- **替换策略**：
  - 数据库查询结果：`.unwrap()` → `.map_err(|e| anyhow!("...: {}", e))?`
  - Mutex lock：`.lock().unwrap()` → `.lock().map_err(|e| anyhow!("lock poisoned: {}", e))?`
  - JSON 序列化/反序列化：`.unwrap()` → `.map_err(|e| anyhow!("json error: {}", e))?`
  - 已知安全的初始化场景：保留 `expect("明确的失败原因")`
  - 测试代码中的 `unwrap()`：保持不变
- **测试标准**：
  - `cargo clippy --workspace --all-targets` 无 warning
  - `cargo test --workspace` 全部通过
  - `cargo fmt --check` 通过
- **提交信息**：`refactor: replace unwrap() with proper error handling in production code`

### 2 提取 WebSocket handler 通用框架

- **功能目标**：提取 6 个 ws_*.rs 文件的公共结构为通用模块，消除重复代码
- **文件结构**：
  - 创建 `crates/rex-hub/src/ws_common.rs`（通用类型、工具函数）
  - 修改 `crates/rex-hub/src/ws_mysql.rs`（使用通用模块）
  - 修改 `crates/rex-hub/src/ws_postgresql.rs`（使用通用模块）
  - 修改 `crates/rex-hub/src/ws_redis.rs`（使用通用模块）
  - 修改 `crates/rex-hub/src/ws_s3.rs`（使用通用模块）
  - 修改 `crates/rex-hub/src/ws_sqlite.rs`（使用通用模块）
  - 修改 `crates/rex-hub/src/ws_terminal.rs`（使用通用模块）
- **提取内容**：
  - 公共消息类型（ClientMessage / ServerMessage 基础变体）
  - WebSocket 工具函数（`send_ws_msg`、`send_ws_error`、`send_ws_json`）
  - 通用连接生命周期（升级、认证、消息循环框架）
  - 各 handler 只保留协议特定的 action 分发和连接器类型
- **测试标准**：
  - `cargo clippy --workspace --all-targets` 无 warning
  - `cargo test --workspace` 全部通过
  - 行数减少至少 30%（当前 2,155 行）
- **提交信息**：`refactor: extract common WebSocket handler framework to reduce duplication`
