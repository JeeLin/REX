# 0.56.0: SQL 控制台体验优化

## Context

0.55.0 完成了前端 i18n 与主题系统优化。SQL 控制台是项目中最复杂的功能模块（12 个文件，3000+ 行），自 M44（SQL 存储过程/函数节点支持）以来未进行体验层面的优化。

本里程碑聚焦 SQL 控制台的细节打磨，提升日常使用体验。

版本类型：minor（体验优化，无后端变更）

## 产品边界

**做什么：**
- 未保存标签视觉提示（未保存标记点）
- SQL 标签副标题显示（显示 SQL 首行或文件名）
- 结果表格行间色增强（斑马纹）
- SQL 历史记录面板增强（显示执行耗时和行数）

**不做什么：**
- 不修改后端 API
- 不添加新的产品功能（仅增强现有功能）
- 不改变 SQL 编辑器核心行为

## 子任务详细设计

### 1 SQL 标签未保存标记与副标题

- **功能目标**：未保存的 SQL 标签显示视觉提示，标签显示 SQL 首行作为副标题
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlTabs.vue`
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **功能点**：
  - 未保存标签标题前显示蓝色圆点标记（· 查询 N）
  - 已保存标签显示文件名（filename.sql）
  - 标签副标题显示 SQL 首行内容（截断到 30 字符）
  - 鼠标悬停标签时显示完整 SQL 内容的 tooltip
- **测试标准**：
  - 未保存标签显示蓝色圆点
  - 已保存标签显示文件名
  - 标签副标题显示 SQL 首行
  - `bun run type-check` 通过
- **提交信息**：`feat: add unsaved indicator and subtitle to SQL tabs`

### 2 结果表格斑马纹与行选中高亮

- **功能目标**：提升结果表格的可读性和交互体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlResults.vue`
- **功能点**：
  - 结果表格添加斑马纹（奇偶行交替背景色）
  - 点击行时高亮选中行（浅蓝色背景）
  - 选中行时按 Ctrl+C 复制该行数据（Tab 分隔）
  - 结果表格底部状态栏增强：显示当前页码/总页数
- **测试标准**：
  - 斑马纹在奇偶行正确显示
  - 点击行高亮，再次点击取消
  - 状态栏显示页码信息
  - `bun run type-check` 通过
- **提交信息**：`feat: add zebra striping and row selection to SQL results table`

### 3 SQL 历史记录面板增强

- **功能目标**：历史记录面板显示更多执行信息，提升查询回溯效率
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlHistoryPanel.vue`
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **功能点**：
  - 历史记录项显示执行耗时（如 "12ms"）和返回行数（如 "42 rows"）
  - 历史记录项按时间分组（今天、昨天、更早）
  - 历史记录项支持右键菜单：复制 SQL、在新标签中打开、删除
  - 搜索框支持按 SQL 内容模糊搜索
- **测试标准**：
  - 历史记录项显示耗时和行数
  - 时间分组正确
  - 右键菜单功能正常
  - `bun run type-check` 通过
- **提交信息**：`feat: enhance SQL history panel with timing and grouping`
