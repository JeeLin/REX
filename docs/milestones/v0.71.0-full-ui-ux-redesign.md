# v0.71.0: 全站 UI/UX 对齐原型重设计

## Context
前序阶段（v0.70.8）完成了 Hub/Agent 服务化管理。当前前端各页面的 UI/UX 与 `prototypes/rex-1.0/` 原型存在显著差异，需要全面对齐。**侧栏和顶栏以 `01-dashboard.html` 为基准**，其他页面各自参考对应的原型文件。

版本类型：minor（UI 重构，向后兼容）

## 产品边界
**本阶段做**：
- 侧栏 + 顶栏：以 `01-dashboard.html` 为基准重设计（brand 区、搜索框、导航图标、资源树样式、底部按钮、面包屑、头像）
- Dashboard 页面：对齐 `01-dashboard.html`（统计卡片、快速连接、环境卡片网格）
- Workspace 页面：对齐 `02-workspace.html`（Tab 栏、分屏、状态栏）
- Environments 页面：对齐 `07-environments.html`（列表 + 拓扑 tab、环境卡片）
- Environment Detail 页面：对齐 `07b-environment-detail.html`（详情头部、Agent 面板、资源表格）
- Settings 页面：对齐 `09-settings.html`（左侧导航 + 右侧内容、分区块）
- Audit Log 页面：对齐 `10-audit.html`（统计行 + 筛选 + 表格 + 展开详情）
- Login / Setup 页面：对齐 `00-login.html` / `03-setup.html`
- 全局 token 对齐：侧栏背景色 `--bg-sidebar: #0A0D12`，所有颜色走 CSS token
- 导航项图标：Unicode → SVG 线条图标
- 导航项调整：移除 Agents 独立项，Audit log 移入主导航

**本阶段不做**：
- 命令面板（Cmd+K）功能实现（仅搜索盒 UI 对齐）
- 移动端底部导航调整
- 新页面开发
- 资源树功能增强（逻辑不变，仅样式调整）
- 后端 API 变更

## 子任务详细设计

### 1 全局 token 对齐 + 侧栏背景色

- **功能目标**：对齐原型 `tokens.css` 的色彩体系到前端 CSS 变量
- **文件结构**：修改 `packages/rex-console-web/src/styles/` 下的 token/variable 文件
- **接口设计**：无
- **交互设计**：
  - 新增/确认 `--bg-sidebar: #0A0D12` token（比 `--bg-surface` 更深）
  - 新增/确认 `--brand-deep: #b86d18`、`--on-brand: #1a1206`、`--on-ink: #0c0f14` token
  - 新增/确认 `--scrollbar: #2b333d`、`--scrollbar-hover: #3a444f` token
  - 新增/确认 `--st-off: #484f58`、`--info-deep: #3a7fd0`、`--info-on: #06121f` token
  - 确保所有新增组件使用 token 而非硬编码色值
- **测试标准**：`bun run build` 成功，无硬编码 hex
- **提交信息**：`feat(ui): align global CSS tokens with prototype`

### 2 侧栏 brand 区 + 工具按钮 + 搜索框重设计

- **功能目标**：将侧栏顶部从居中文字改为 glyph + 名称 + 工具按钮，搜索框改为⌘K 样式
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **交互设计**（参考 `01-dashboard.html`）：
  - Brand 区：左侧渐变方块 glyph（`R`，`linear-gradient(140deg, var(--brand), var(--brand-deep))`）+ "REX" 名称（mono 字体）；右侧两个 icon-btn（主题 + 语言），30x30px
  - 搜索框：34px 高，圆角 8px，`var(--bg-app)` 背景，左侧 ⌕ + 占位符 + 右侧 `⌘K` kbd 标签
  - 点击搜索框暂不实现命令面板，保留视觉样式
- **测试标准**：视觉对齐原型，主题切换可点击
- **提交信息**：`feat(ui): redesign sidebar brand area and search box`

### 3 侧栏导航 SVG 图标 + 布局调整 + 底部按钮

- **功能目标**：导航图标从 Unicode 替换为 SVG，调整导航项分组，底部改为按钮
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **交互设计**（参考 `01-dashboard.html`）：
  - SVG 图标：16x16，stroke-width=2，currentColor 跟随文字色
  - 主导航：Workspace（网格）、Dashboard（柱状图）、Environments（列表）、Audit log（闪电）、Design（组件）
  - 移除 Agents 独立导航项
  - 底部：两个按钮水平排列 — "+ New environment"（ghost，点击触发环境创建弹窗）+ "⚙ 设置"（ghost，链接 /settings）
- **测试标准**：导航切换正常，激活态正确
- **提交信息**：`feat(ui): replace nav unicode icons with SVG, adjust nav items and bottom buttons`
