# 0.84.3: SSH 终端复制粘贴修复

## Context

0.84.2 修复了分屏布局持久化和全局快捷键作用域问题。本里程碑聚焦 SSH 终端的复制粘贴体验：Ctrl+C/V 与浏览器快捷键冲突、粘贴文本编码不一致、缺少操作反馈。

版本类型：patch（bug 修复）

## 产品边界

**本阶段做什么：**
- 修复 Ctrl+C 在终端未聚焦时被浏览器拦截的问题
- 修复粘贴文本编码不一致（部分场景 base64 编码失败）
- 添加复制/粘贴操作的视觉反馈（toast 提示）
- 统一独立终端和工作空间终端的复制粘贴逻辑

**本阶段不做什么：**
- 不修改终端仿真核心逻辑
- 不涉及后端 WebSocket 协议变更
- 不涉及新功能开发
- 不修改非 SSH 终端（MySQL/PostgreSQL/Redis）的复制粘贴

## 子任务详细设计

### 1 修复 Ctrl+C/V 焦点问题

- **功能目标**：确保 Ctrl+C/V 在终端可见区域内始终可用，即使焦点不在 xterm 内部 textarea 上
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Terminal.vue`：在 terminal 容器上添加 keydown 监听器，作为 xterm textarea 的备用
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceTerminal.vue`：同样添加容器级 keydown 监听
- **接口设计**：无新增接口
- **交互设计**：
  - 点击终端区域（不一定是 textarea）→ Ctrl+C 复制选中文本或发送 SIGINT
  - 点击终端区域 → Ctrl+V 粘贴文本
  - 复制成功 → 右上角 toast 显示「已复制」
  - 粘贴成功 → 右上角 toast 显示「已粘贴 X 字符」
- **后端流程**：无
- **测试标准**：
  - 点击终端空白区域后按 Ctrl+C（无选中文本）→ 发送 SIGINT
  - 点击终端空白区域后按 Ctrl+C（有选中文本）→ 复制到剪贴板
  - 点击终端空白区域后按 Ctrl+V → 粘贴文本到终端
  - toast 提示正确显示
- **提交信息**：`fix: ensure Ctrl+C/V works when terminal container is focused`

### 2 统一终端复制粘贴逻辑

- **功能目标**：将独立终端（Terminal.vue）和工作空间终端（WorkspaceTerminal.vue）的复制粘贴逻辑提取为共享 composable，消除重复代码
- **文件结构**：
  - 创建 `packages/rex-console-web/src/composables/useTerminalClipboard.ts`：共享的复制粘贴逻辑
  - 修改 `packages/rex-console-web/src/pages/Terminal.vue`：使用 composable
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceTerminal.vue`：使用 composable
- **接口设计**：
  ```typescript
  function useTerminalClipboard(terminal: Ref<xterm.Terminal | null>, ws: Ref<WebSocket | null>): {
    attachKeyHandler: () => void
    attachPasteHandler: () => void
  }
  ```
- **交互设计**：无变化，仅重构
- **后端流程**：无
- **测试标准**：
  - 独立终端复制粘贴功能正常
  - 工作空间终端复制粘贴功能正常
  - `bun run type-check` 无 error
  - `bun run lint` 无 error
- **提交信息**：`refactor: extract shared terminal clipboard logic`
