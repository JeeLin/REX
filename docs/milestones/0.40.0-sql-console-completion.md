## 子任务详细设计

### 1 查询标签右键菜单

- **功能目标**：补全查询标签的右键菜单功能，包括关闭其他、关闭已保存、另存为、重命名、复制 SQL、执行 SQL
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlEditor.vue`（或相关组件）
  - 修改 `packages/rex-console-web/src/i18n/zh.ts` 和 `en.ts`（新增 i18n 键）
- **交互设计**：
  - 右键点击查询标签时，显示菜单：
    - 关闭 — 关闭当前标签
    - 关闭其他 — 关闭除当前外的所有标签
    - 关闭已保存 — 关闭所有已保存的标签（保留未保存的）
    - ─── 分隔线 ───
    - 保存 — 保存当前查询为文件
    - 另存为… — 另存为新查询文件
    - 重命名 — 重命名查询文件
    - ─── 分隔线 ───
    - 复制 SQL — 将编辑器内容复制到剪贴板
    - 执行 SQL — 执行当前编辑器中的全部 SQL
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`feat: add query tab context menu with save, rename, and execute`

### 2 查看视图/表定义（DDL）

- **功能目标**：后端 API 获取 DDL，前端视图/表节点菜单集成
- **文件结构**：
  - 修改后端 `crates/rex-hub/src/sql.rs`（新增 DDL API）
  - 修改 `packages/rex-console-web/src/api/sql.ts`（新增 API 调用）
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`（菜单集成）
- **接口设计**：
  - 后端：`POST /api/resources/:resource_id/sql/ddl`，body: `{ database, object_name, type: 'table' | 'view' }`
  - 返回：`{ ddl: string }`（CREATE TABLE/CREATE VIEW 语句）
- **交互设计**：
  - 右键点击视图/表节点 → 菜单「查看定义」→ 弹窗显示 DDL 语句
  - 支持复制 DDL 语句
- **测试标准**：`bun run type-check` 通过，后端 `cargo test` 通过
- **提交信息**：`feat: add DDL API and view definition in SQL sidebar`

### 3 数据文件导出下载

- **功能目标**：结果区导出按钮改为真实文件下载（CSV/JSON），而非剪贴板复制
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/result-export.ts`（添加下载函数）
  - 修改 `packages/rex-console-web/src/features/sql/SqlResults.vue`（更新导出按钮）
- **交互设计**：
  - 点击 CSV/JSON 导出按钮 → 下载文件到本地（文件名：`export-{database}-{table}-{timestamp}.csv/.json`）
  - 保持现有的剪贴板复制功能（作为辅助）
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`feat: add file download for SQL result export`

### 4 新建表菜单项

- **功能目标**：数据库节点右键菜单新增「新建表」菜单项
- **文件结构**：
  - 修改后端 `crates/rex-hub/src/sql.rs`（新增执行 DDL 的 API）
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`（菜单集成）
- **接口设计**：
  - 复用现有 `POST /api/resources/:resource_id/sql/execute` API 执行 DDL
- **交互设计**：
  - 右键点击数据库节点 → 菜单「新建表」→ 弹出简易 DDL 编辑器（textarea + 执行按钮）
  - 执行后刷新库表树
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`feat: add create table menu item in SQL sidebar`

### 5 i18n 和测试

- **功能目标**：补全新增功能的 i18n 键 + 确保测试通过
- **文件结构**：
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **i18n 键**：
  - `sql.tab.ctx.closeOthers` (关闭其他)
  - `sql.tab.ctx.closeSaved` (关闭已保存)
  - `sql.tab.ctx.saveAs` (另存为)
  - `sql.tab.ctx.rename` (重命名)
  - `sql.tab.ctx.copySql` (复制 SQL)
  - `sql.tab.ctx.executeSql` (执行 SQL)
  - `sql.tree.ctx.viewDefinition` (查看定义)
  - `sql.tree.ctx.createNewTable` (新建表)
  - `sql.result.exportDownload` (下载导出)
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add i18n for SQL console completion`
