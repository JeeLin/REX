# 0.47.0: Redis 控制台体验升级

## Context

0.46.0 完成了终端体验补全（延迟测量、右键菜单、i18n）。

当前 Redis 控制台（0.8.0 实现）仅有命令行界面：用户手动输入 Redis 命令，后端 connector 是 stub（返回硬编码响应），前端无键浏览器、无数据库选择器、无类型感知值查看器。

参考 Another Redis Desktop Manager（ARDM）的设计，本里程碑将 Redis 控制台从纯 CLI 升级为带键浏览器、类型感知值查看器、数据库选择器的完整 GUI。

版本类型：minor（新功能，向后兼容）

## 产品边界

**做什么：**
- 后端 Redis TCP 连接器实现（替代 stub）
- 键浏览器（树形列表 + SCAN 搜索）
- 值查看器（按类型显示，支持 JSON 格式化）
- 数据库选择器（DB 0-15）
- 命令自动补全（激活已有的 REDIS_COMMANDS）

**不做什么：**
- 不实现 Redis Cluster/Sentinel 支持
- 不实现 Pub/Sub 订阅
- 不实现内存分析/Slowlog
- 不实现导入/导出功能
- 不修改产品文档

## 子任务详细设计

### 1 后端 Redis TCP 连接器实现

- **功能目标**：将 `RedisConnectorImpl` 从 stub 替换为真实 TCP 连接
- **文件结构**：
  - 修改 `crates/rex-redis/src/connector.rs`
- **接口适配**：
  - `connect()`：建立 TCP 连接，发送 AUTH（如有密码），发送 SELECT（选择数据库）
  - `execute(command)`：通过 TCP 发送 RESP 命令并解析响应
  - `info()`：执行 INFO server 并解析为 HashMap
  - `close()`：关闭 TCP 连接
- **依赖**：tokio（已引入）用于异步 TCP
- **测试标准**：`cargo test -p rex-redis` 通过
- **提交信息**：`feat: implement real Redis TCP connector`

### 2 键浏览器（树形列表 + SCAN 搜索）

- **功能目标**：在 Redis 控制台左侧添加键浏览器面板
- **文件结构**：
  - 创建 `packages/rex-console-web/src/features/redis/RedisKeyBrowser.vue`
  - 修改 `packages/rex-console-web/src/features/redis/RedisConsole.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceRedis.vue`
- **交互设计**：
  - 左侧面板（可折叠，默认宽度 240px）
  - 顶部搜索框：输入 pattern 后按 SCAN 搜索（如 `user:*`）
  - 键列表：按分隔符（默认 `:`）分组为树形结构
  - 每个键显示类型图标（`Aa` / `{}` / `[]` / `(~)` / `< >`）和 TTL
  - 右键菜单：复制键名、查看值、删除键、设置 TTL
- **后端流程**：
  - WebSocket 新增 action：`keys`（SCAN 命令，带 pattern 和 count）
  - 响应格式：`{ keys: [{ name, type, ttl }] }`
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add Redis key browser with tree view and SCAN search`

### 3 值查看器（类型感知 + JSON 格式化）

- **功能目标**：点击键后在右侧显示类型感知的值查看器
- **文件结构**：
  - 创建 `packages/rex-console-web/src/features/redis/RedisValueViewer.vue`
  - 创建 `packages/rex-console-web/src/features/redis/RedisValueEditor.vue`
- **交互设计**：
  - **String**：文本显示，自动检测 JSON 并格式化（带折叠/展开）
  - **Hash**：表格视图（field | value），支持编辑单个 field
  - **List**：有序列表，支持 index 查看
  - **Set**：无序集合，显示所有 members
  - **ZSet**：表格视图（member | score）
  - 顶部显示：键名、类型标签、TTL（可点击编辑）
  - 底部操作栏：删除键、复制值、刷新
- **后端流程**：
  - WebSocket 新增 action：`type`（TYPE 命令）、`ttl`（TTL 命令）、`get`（GET/HGETALL/LRANGE/SMEMBERS/ZRANGE）
  - WebSocket 新增 action：`set_ttl`（EXPIRE 命令）、`del`（DEL 命令）
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add type-aware Redis value viewer with JSON formatting`

### 4 数据库选择器 + 命令自动补全

- **功能目标**：添加数据库切换和命令自动补全
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/RedisConsole.vue`
  - 修改 `packages/rex-console-web/src/features/redis/useRedisSession.ts`
- **交互设计**：
  - 工具栏新增数据库下拉选择器（DB 0 到 DB 15）
  - 切换数据库时发送 SELECT 命令，刷新键列表
  - 命令输入框激活自动补全：输入时弹出匹配的命令列表（复用 `REDIS_COMMANDS`）
  - Tab 键补全选中项
- **后端流程**：
  - WebSocket 新增 action：`select_db`（SELECT 命令）
  - 切换后所有后续命令都在新数据库上下文中执行
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add database selector and command autocomplete to Redis console`
