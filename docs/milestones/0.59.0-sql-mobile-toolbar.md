# 0.59.0: SQL 控制台移动端浮动工具栏

## Context

0.57.0 完成了 SSH 终端移动端浮动工具栏，0.58.0 完成了 SFTP 文件管理移动端浮动工具栏。SQL 控制台（PRODUCT.md 3.7）是第三个全屏操作页面，目前缺少移动端适配。移动端用户在 SQL 页面无法方便地执行 SQL、格式化、保存等常用操作。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 实现 SQL 控制台移动端浮动工具栏
- 第一行：执行、格式化、清空编辑器
- 第二行：保存、历史记录、全局查询、更多选项
- 仅在移动端显示（桌面端隐藏）

**不做什么：**
- 不修改后端 SQL API
- 不改变桌面端 SQL 控制台行为
- 不修改编辑器核心逻辑

## 子任务详细设计

### 1 SQL 移动端浮动工具栏组件实现

- **功能目标**：创建 SqlMobileToolbar 组件，提供 SQL 控制台移动端操作的浮动工具栏
- **文件结构**：
  - 创建 `packages/rex-console-web/src/features/sql/SqlMobileToolbar.vue`
- **功能点**：
  - 第一行操作按钮区：
    - ▶ 执行 — 执行当前 SQL
    - ✨ 格式化 — 格式化 SQL
    - 🗑 清空 — 清空编辑器
  - 第二行更多选项区：
    - 💾 保存 — 保存当前查询
    - 📜 历史 — 打开历史记录面板
    - ⊞ 全局查询 — 打开全局查询弹窗
    - ⚙ 更多 — 更多操作菜单（打开查询文件、数据库选择器）
  - 组件 props：`visible`（boolean）
  - 组件 emits：`execute`、`format`、`clear`、`save`、`history`、`globalQuery`、`openQuery`
  - CSS：底部固定定位，半透明背景，按钮网格布局（复用 TerminalMobileToolbar / FileMobileToolbar 的 CSS 模式）
  - 仅在 `window.innerWidth < 768` 时显示
- **交互设计**：
  - 按钮点击时添加视觉反馈（短暂高亮）
  - 操作按钮与桌面端工具栏功能对应
  - 更多菜单使用绝对定位弹出
- **测试标准**：
  - 组件渲染正确的按钮布局
  - 按钮点击触发正确的 emit 事件
  - 响应式：窄屏显示，宽屏隐藏
  - `bun run type-check` 通过
- **提交信息**：`feat: add mobile floating toolbar for SQL console`

### 2 工具栏集成与 i18n

- **功能目标**：将浮动工具栏集成到 SqlConsole 页面，添加移动端检测和 i18n 支持
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/SqlConsole.vue`
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **功能点**：
  - 在 SqlConsole.vue 中引入 SqlMobileToolbar
  - 添加 `isMobile` ref 和 `checkMobile()` 函数（复用 Files.vue 的 `window.innerWidth < 768` 模式）
  - 传递 visible 状态
  - 实现各按钮对应的处理函数（复用现有 execute、clearEditor、handleToolbarSave 等）
  - i18n key：`sql.mobile.execute`、`sql.mobile.format`、`sql.mobile.clear`、`sql.mobile.save`、`sql.mobile.history`、`sql.mobile.globalQuery`、`sql.mobile.openQuery`、`sql.mobile.more`
  - 移动端隐藏桌面端工具栏（通过 `v-if="!isMobile"` 控制）
- **测试标准**：
  - 移动端可见，桌面端隐藏
  - 所有按钮功能正常
  - `bun run type-check` 通过
- **提交信息**：`feat: integrate SQL mobile toolbar with i18n support`
