# 0.70.0: 安全加固与错误处理

## Context

0.69.0 完成了后端测试覆盖提升（527 个测试）。目前项目功能完整，所有 PRODUCT.md 定义的功能均已实现。本里程碑补齐安全防护和前端韧性方面的缺口：登录无速率限制、无安全头、无 Vue 错误边界、WebSocket 断线需手动重连。

版本类型：minor（新增安全和韧性功能）

## 产品边界

**做什么：**
- 后端登录速率限制（防暴力破解）
- HTTP 安全响应头（CSP、HSTS、X-Frame-Options、X-Content-Type-Options）
- 健康检查端点增强（返回数据库连接状态和版本信息）
- Vue 全局错误边界（捕获未处理异常，显示友好错误页）
- API 错误统一处理（网络错误、超时、服务端错误的统一提示）
- WebSocket 自动重连（指数退避，最多 5 次）
- 网络状态监听（离线/在线 Toast 提示）

**不做什么：**
- 不做多因素认证（MFA）
- 不做 IP 白名单
- 不做 CSP 报告端点
- 不修改现有认证逻辑（JWT + Argon2 保持不变）
- 不引入新的外部依赖（速率限制用内存 HashMap 实现）

## 子任务详细设计

### 1 后端安全加固

- **功能目标**：为登录接口添加速率限制，为所有 HTTP 响应添加安全头，增强健康检查端点
- **文件结构**：
  - 修改 `crates/rex-hub/src/auth.rs`（添加速率限制逻辑）
  - 新建 `crates/rex-hub/src/security.rs`（安全头中间件 + 速率限制器）
  - 修改 `crates/rex-hub/src/routes.rs`（集成安全头中间件、增强 healthz）
- **接口设计**：
  - 登录限流：同一 IP 5 分钟内最多 5 次失败登录，超出返回 `429 Too Many Requests`
  - 安全头：所有 HTTP 响应添加 `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Strict-Transport-Security: max-age=31536000; includeSubDomains`（仅 HTTPS 时）
  - CSP：`default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self' ws: wss:; font-src 'self'`
  - 健康检查：保留 `GET /healthz` 返回 `"ok"`（向后兼容 Docker/K8s），新增 `GET /api/health` 返回 JSON `{"status":"ok","version":"0.70.0","db":"connected"}`
- **后端流程**：
  1. `RateLimiter` 结构体：`HashMap<IpAddr, Vec<Instant>>`，每次登录失败记录时间戳，清理过期记录
  2. `SecurityHeaders` 中间件：在响应上设置安全头
  3. `healthz` 增强：查询数据库连接 + 读取版本号
- **测试标准**：
  - RateLimiter 单元测试：正常通过、达到限制、时间窗口过期后重置
  - SecurityHeaders 测试：验证所有安全头存在
  - healthz 测试：`/healthz` 返回 "ok"，`/api/health` 返回 JSON 包含 version 和 db 字段
- **提交信息**：`feat: add login rate limiting, security headers, and enhanced health check`

### 2 前端错误处理

- **功能目标**：添加 Vue 全局错误边界，统一 API 错误处理
- **文件结构**：
  - 新建 `packages/rex-console-web/src/components/ErrorBoundary.vue`（错误边界组件）
  - 修改 `packages/rex-console-web/src/App.vue`（包裹 ErrorBoundary）
  - 修改 `packages/rex-console-web/src/api/client.ts`（增强错误拦截器）
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`（添加错误提示文案）
  - 修改 `packages/rex-console-web/src/i18n/en.ts`（添加错误提示文案）
- **接口设计**：
  - `ErrorBoundary.vue`：`<slot>` 包裹子组件，`onerror` 捕获渲染错误，显示错误页 + 重试按钮
  - API 拦截器增强：
    - 网络错误（无 response）：Toast 提示「网络连接失败，请检查网络」
    - 超时（code ECONNABORTED）：Toast 提示「请求超时，请稍后重试」
    - 5xx 错误：Toast 提示「服务器错误（5xx），请稍后重试」
    - 429 限流：Toast 提示「操作过于频繁，请稍后重试」
- **交互设计**：
  - 错误边界：全屏深色背景，⚠ 图标 + 错误摘要 + 「重试」按钮（刷新页面）
  - Toast 错误：右上角滑入，红色边框，3 秒后自动关闭
- **测试标准**：
  - ErrorBoundary 组件测试：模拟子组件抛出错误，验证错误页显示
  - API 拦截器测试：模拟网络错误、超时、5xx、429，验证 Toast 提示
- **提交信息**：`feat: add Vue error boundary and unified API error handling`

### 3 离线检测与 WebSocket 自动重连

- **功能目标**：监听网络状态变化，WebSocket 断线自动重连（指数退避）
- **文件结构**：
  - 新建 `packages/rex-console-web/src/composables/useNetworkStatus.ts`（网络状态监听）
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceTerminal.vue`（集成自动重连）
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceSqlite.vue`（集成自动重连）
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceRedis.vue`（如有，集成自动重连）
  - 修改 `packages/rex-console-web/src/App.vue`（集成 useNetworkStatus）
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`（添加离线提示文案）
  - 修改 `packages/rex-console-web/src/i18n/en.ts`（添加离线提示文案）
- **接口设计**：
  - `useNetworkStatus()`：返回 `{ isOnline: Ref<boolean> }`，监听 `navigator.onLine` + `online`/`offline` 事件
  - WebSocket 重连策略：断线后自动重连，间隔 1s → 2s → 4s → 8s → 16s（最大 5 次），成功后重置
  - App.vue：网络状态变化时显示 Toast（离线：红色「网络已断开」，恢复：绿色「网络已恢复」）
- **交互设计**：
  - 离线时：Toast 提示 + 连接状态点变为 ⚫
  - 恢复在线：Toast 提示 + 自动触发重连
  - 重连失败（5 次后）：显示手动重连按钮（保留现有 UI）
- **测试标准**：
  - useNetworkStatus 测试：模拟 online/offline 事件，验证状态变化
  - WebSocket 重连测试：模拟断线，验证重连间隔和最大次数
- **提交信息**：`feat: add offline detection and WebSocket auto-reconnect`
