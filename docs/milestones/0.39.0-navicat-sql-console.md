# 0.39.0: Navicat 风格 SQL 终端改造

## Context

0.38.0 完成了代码质量清理。当前 SQL 控制台采用简单的 textarea + 固定侧边栏结构。本里程碑按 Navicat 页面结构进行全面改造，提升 SQL 工作体验。

版本类型：major（编辑器升级 + 布局重构 + 功能补全）

## 产品边界

**做什么：**
- 侧边栏重构：可拖拽宽度 + 数据库选择器移入树顶 + 库表树持久展示 + 查询文件在下方分区
- 右侧编辑器/结果可拖拽分割线
- 编辑器从 textarea 升级为 CodeMirror（语法高亮 + 行号 + 自动补全）
- 库表树右键菜单补全（行数统计、列约束、导出表数据、查看定义）

**不做什么：**
- 不新建表（DDL 执行风险高，单独里程碑）
- 不修改产品文档
- 不引入新的后端 API（复用现有 endpoints）

## 子任务详细设计

### 1 安装 CodeMirror 依赖 + 基础集成

- **功能目标**：将 SqlEditor 从 textarea 升级为 CodeMirror 6
- **文件结构**：
  - 修改 `packages/rex-console-web/package.json`：新增 @codemirror/* 依赖
  - 创建 `packages/rex-console-web/src/features/sql/SqlCodeMirror.vue`：CodeMirror 封装组件
  - 修改 `packages/rex-console-web/src/features/sql/SqlEditor.vue`：替换 textarea 为 SqlCodeMirror
- **依赖安装**：
  ```
  bun add @codemirror/state @codemirror/view @codemirror/lang-sql @codemirror/theme-one-dark @codemirror/autocomplete @codemirror/search @codemirror/lint
  ```
- **功能清单**：
  - SQL 语法高亮
  - 行号显示
  - 深色主题适配（使用 @codemirror/theme-one-dark 或自定义）
  - 基础自动补全（表名、列名、SQL 关键字）
  - 搜索替换（Ctrl+F）
  - 括号匹配
  - 代码折叠
- **测试标准**：bun run type-check 通过
- **提交信息**：`feat: integrate CodeMirror 6 for SQL editor with syntax highlighting and autocomplete`

### 2 侧边栏重构

- **功能目标**：重构 SqlSidebar，实现 Navicat 风格左侧库表树
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`
  - 修改 `packages/rex-console-web/src/pages/SqlConsole.vue`
- **布局设计**：
  ```
  +----------------------------------------------------+
  | SqlSidebar (可拖拽宽度 200-400px, localStorage持久化) |
  +----------------------------------------------------+
  | [Database: v dropdown]      [Refresh]              |
  +----------------------------------------------------+
  | 库表结构树 (flex:1, 可滚动)                          |
  |   ├ Database A                                    |
  |   │  ├ Table 1                                   |
  |   │  │  ├ PK col    INT                          |
  |   │  │  └ col2      VARCHAR                      |
  |   │  └ Table 2                                   |
  |   └ Database B                                    |
  +----------------------------------------------------+
  | 查询文件 (可折叠区域, 底部固定)                       |
  |   ├ query1.sql                                    |
  |   └ query2.sql                                    |
  +----------------------------------------------------+
  ```
- **功能清单**：
  - 侧边栏宽度可拖拽调整（200-400px），localStorage 持久化
  - 数据库选择器移入侧边栏顶部（下拉框）
  - 库表树默认展开当前数据库
  - 查询文件列表在底部，可折叠
  - 双击表名插入 `SELECT * FROM <table> LIMIT 100;`
- **测试标准**：bun run type-check 通过
- **提交信息**：`feat: refactor SQL sidebar with resizable width and database selector`

### 3 右侧可拖拽分割线

- **功能目标**：编辑器和结果区域可拖拽调整高度
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/SqlConsole.vue`
  - 修改 `packages/rex-console-web/src/features/sql/SqlResults.vue`
- **交互设计**：
  ```
  +----------------------------------------------------+
  | Tabs + Toolbar                                     |
  +----------------------------------------------------+
  | SqlEditor (可拖拽高度, 默认 40%)                      |
  | [CodeMirror]                                       |
  +------------------- 3px 分割线 ---------------------+
  | SqlResults (可拖拽高度, 默认 60%)                    |
  | [Results | Message | Explain]                      |
  | <data table>                                       |
  +----------------------------------------------------+
  ```
- **功能清单**：
  - 分割线可拖拽，最小高度 120px
  - 拖拽状态 localStorage 持久化
  - 分割线 hover 视觉反馈（颜色变化 + 光标改变）
- **测试标准**：bun run type-check 通过
- **提交信息**：`feat: add resizable split between SQL editor and results`
