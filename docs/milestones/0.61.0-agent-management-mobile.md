# 0.61.0: Agent 管理移动端优化

## Context

0.60.0 完成了前端代码质量清理。Agent 管理页面（PRODUCT.md 3.9）的网格布局已有基本响应式，但移动端交互体验仍需优化：Agent 卡片的操作按钮在小屏上可能拥挤，日志查看器的筛选栏在移动端需要更好的布局，配置弹窗在窄屏下需要适配。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- Agent 卡片移动端布局优化（操作按钮排列、信息密度调整）
- Agent 日志查看器移动端适配（筛选栏换行、日志行水平滚动）
- Agent 配置弹窗移动端适配（表单单列布局）

**不做什么：**
- 不修改后端 Agent API
- 不改变桌面端 Agent 管理行为
- 不新增 Agent 管理功能

## 子任务详细设计

### 1 Agent 卡片移动端布局优化

- **功能目标**：优化 Agent 卡片在移动端的显示效果和交互体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/agents/AgentCard.vue`
  - 修改 `packages/rex-console-web/src/pages/Agents.vue`
- **功能点**：
  - Agent 网格在移动端（< 768px）切换为单列布局
  - Agent 卡片操作按钮在移动端改为图标按钮（隐藏文字标签），减少占用空间
  - 设备信息区域在移动端简化显示（仅显示 OS + 架构）
  - Agent 状态徽章在移动端保持可见
- **测试标准**：
  - 桌面端布局不变
  - 移动端卡片单列、按钮紧凑
  - `bun run type-check` 通过
- **提交信息**：`feat: optimize agent card layout for mobile`

### 2 Agent 日志查看器移动端适配

- **功能目标**：优化 Agent 日志查看器在移动端的可读性和操作体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/agents/AgentLogModal.vue`
- **功能点**：
  - 日志面板在移动端全屏显示（`width: 100vw; height: 100vh`）
  - 筛选按钮在移动端换行为两行排列
  - 日志行支持水平滚动（`overflow-x: auto`）
  - 日志时间戳在移动端缩短格式（仅显示 HH:MM:SS）
- **测试标准**：
  - 桌面端日志查看器不变
  - 移动端全屏、可滚动
  - `bun run type-check` 通过
- **提交信息**：`feat: adapt agent log viewer for mobile`

### 3 Agent 配置弹窗移动端适配

- **功能目标**：优化 Agent 配置弹窗在移动端的表单布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/agents/AgentConfigModal.vue`
- **功能点**：
  - 配置弹窗在移动端全屏显示
  - 表单字段在移动端改为单列布局
  - 令牌区域在移动端支持长按复制
- **测试标准**：
  - 桌面端配置弹窗不变
  - 移动端全屏、表单可读
  - `bun run type-check` 通过
- **提交信息**：`feat: adapt agent config modal for mobile`
