# 0.37.0: 设置页功能补全

## Context

0.36.2 完成了设置页持久化和部署指南补全。PRODUCT.md 3.11 节定义的设置页功能中有三项尚未实现：密码修改、侧边栏可折叠设置、配置加密开关。本里程碑补全这些功能，使设置页与产品文档完全对齐。

版本类型：minor（新增功能）

## 产品边界

**做什么：**
- 密码修改功能：后端 API（PUT /api/user/password）+ 前端弹窗（当前密码验证 + 新密码输入）
- 侧边栏固定/可折叠设置：外观设置区新增 toggle，控制侧边栏是否自动折叠
- 配置加密开关激活：去掉禁用状态，接入后端 PATCH /api/settings/toggle-encryption

**不做什么：**
- 忘记密码（需要邮件服务，不在本里程碑范围）
- 多用户认证（单用户设计，不引入 RBAC）
- 配置加密的实际实现（仅激活开关，底层加密逻辑已在 rex-common 中）

## 子任务详细设计

### 1 密码修改功能

- **功能目标**：用户可在设置页修改密码，需验证当前密码后输入新密码
- **文件结构**：
  - 修改 `crates/rex-hub/src/settings.rs`：新增 `change_password` handler
  - 修改 `crates/rex-hub/src/routes.rs`：注册 PUT `/api/user/password`
  - 修改 `packages/rex-console-web/src/features/settings/ProfileSection.vue`：新增修改密码弹窗
  - 修改 `packages/rex-console-web/src/api/settings.ts`：新增 changePassword API
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`、`en.ts`：新增 i18n 键
- **接口设计**：
  ```
  PUT /api/user/password
  Body: { current_password: string, new_password: string }
  Response: { success: true } | { error: "..." }
  ```
- **后端流程**：
  - 读取 settings 表中的 password_hash
  - 验证当前密码（bcrypt 比对）
  - 校验新密码强度（≥8 字符）
  - 哈希新密码并更新 settings 表
  - 返回成功或错误
- **前端交互**：
  - ProfileSection 中「修改」按钮点击后弹出 Modal
  - Modal 包含：当前密码输入、新密码输入、确认新密码输入
  - 前端校验：新密码 ≥8 字符、两次输入一致
  - 提交成功后 Toast 提示，关闭弹窗
- **测试标准**：cargo test 通过，前端 type-check 通过
- **提交信息**：`feat: add password change with current password verification`

### 2 侧边栏可折叠设置

- **功能目标**：外观设置区新增「侧边栏」设置项，支持固定/可折叠切换
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/settings/AppearanceSection.vue`：新增侧边栏 toggle
  - 修改 `packages/rex-console-web/src/stores/settings.ts`：新增 sidebarCollapsible 设置项
  - 修改 `packages/rex-console-web/src/layouts/AppLayout.vue`：读取设置控制侧边栏行为
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`、`en.ts`：新增 i18n 键
  - 后端 `UserSettings` 结构体需新增 `sidebar_collapsible: Option<bool>` 字段
- **接口设计**：复用现有 `/api/user/settings` GET/PUT，新增 `sidebar_collapsible` 字段
- **交互设计**：
  - AppearanceSection 新增一行：左侧「侧边栏」标签 + 右侧 toggle
  - toggle 状态：固定（false）/ 可折叠（true），默认固定
  - 切换后立即生效：AppLayout 监听设置变化，调整侧边栏折叠行为
- **测试标准**：cargo test 通过，前端 type-check 通过
- **提交信息**：`feat: add sidebar collapsible toggle to appearance settings`

### 3 配置加密开关激活

- **功能目标**：激活 SecuritySection 中的配置加密 toggle，接入后端
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/settings/SecuritySection.vue`：去掉禁用状态，接入 toggle
  - 修改 `packages/rex-console-web/src/stores/settings.ts`：新增 configEncryption 设置项
  - 修改 `packages/rex-console-web/src/api/settings.ts`：新增 toggleEncryption API
  - 后端 `UserSettings` 结构体需新增 `config_encryption: Option<bool>` 字段
- **接口设计**：
  ```
  PUT /api/user/settings
  Body: { config_encryption: bool }
  ```
- **后端流程**：
  - 读取/更新 settings 表中的 config_encryption 字段
  - toggle 开启时触发凭据重新加密（如果之前未加密）
  - toggle 关闭时显示确认弹窗（解密后密码将明文存储）
- **交互设计**：
  - 去掉 `opacity: 0.5; pointer-events: none` 禁用状态
  - 点击 toggle 调用后端 API
  - 关闭时弹出确认弹窗：「关闭配置加密后，资源密码将以明文存储。确认关闭？」
  - 操作成功后 Toast 提示
- **测试标准**：cargo test 通过，前端 type-check 通过
- **提交信息**：`feat: activate config encryption toggle in security settings`
