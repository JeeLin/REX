# 0.43.0: SQL 视图节点支持

## Context

0.42.0 完成了 SQL 侧边栏导出完善（菜单项改为真实 CSV 下载）。本里程碑补全 PRODUCT.md 3.7 节中另一个未完成的功能：SQL 侧边栏视图节点支持。

0.42.0 明确提到"不实现视图节点支持（需新增 listViews API，留待后续里程碑）"。

版本类型：minor（新增后端 API + 前端功能）

## 产品边界

**做什么：**
- 后端新增 listViews API（返回视图列表）
- 前端 SQL 侧边栏显示视图节点（与表节点并列）
- 视图节点右键菜单（查看定义、复制视图名）
- 视图节点展开显示列信息（可选）

**不做什么：**
- 不实现视图创建/编辑功能（PRODUCT.md 未定义）
- 不修改产品文档
- 不实现存储过程/函数节点（留待后续）

## 子任务详细设计

### 1 后端 listViews API

- **功能目标**：新增 API 返回指定数据库的视图列表
- **文件结构**：
  - 修改 `crates/rex-hub/src/sql.rs`（新增 API 端点）
  - 修改 `packages/rex-console-web/src/api/sql.ts`（新增前端 API 调用）
- **接口设计**：
  - `GET /api/resources/:resource_id/sql/views?database={database}`
  - 返回：`{ views: [{ name: string, row_count: number | null }] }`
- **测试标准**：`cargo test` 通过
- **提交信息**：`feat: add list views API for SQL sidebar`

### 2 前端视图节点渲染

- **功能目标**：在 SQL 侧边栏中显示视图节点（与表节点并列）
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`
  - 修改 `packages/rex-console-web/src/api/sql.ts`（添加 ViewInfo 类型）
- **交互设计**：
  - 侧边栏树形结构中，视图节点显示在表节点下方
  - 视图节点图标使用 📐 或类似图标区分
  - 点击视图节点可展开显示列信息（复用 listColumns API）
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`feat: add view nodes in SQL sidebar tree`

### 3 视图右键菜单

- **功能目标**：视图节点右键菜单支持查看定义、复制视图名
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`
- **交互设计**：
  - 右键点击视图节点 → 菜单：
    - 查看定义（复用现有 getDdl API，object_type='view'）
    - 复制视图名
    - 刷新
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`feat: add view node context menu in SQL sidebar`

### 4 i18n 补全

- **功能目标**：补全视图相关的 i18n 键
- **文件结构**：
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **i18n 键**：
  - `sql.tree.ctx.viewName` (视图名)
  - `sql.tree.viewLabel` (视图)
  - `sql.toast.viewListFailed` (获取视图列表失败)
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add i18n keys for SQL view nodes`
