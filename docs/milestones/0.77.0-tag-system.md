# 0.77.0: 标签系统与资源分组增强

## Context

0.76.0 完成了后端可靠性加固（unwrap 清理、WebSocket 框架提取、CI 补全）。当前资源管理仅支持按环境分组，当资源数量增多时，跨环境的逻辑分组（如"生产数据库"、"开发服务器"）缺乏有效组织方式。标签系统为资源提供灵活的多维分类能力。

版本类型：minor（新增功能）

## 产品边界

**做什么：**
- 资源标签模型（数据库表 + CRUD API）
- 标签管理 UI（资源创建/编辑中添加标签）
- 连接菜单标签筛选
- 标签颜色预设

**不做什么：**
- 不修改现有环境分组逻辑
- 不改变用户可见的页面布局结构
- 不引入新的外部依赖

## 子任务详细设计

### 1 后端：标签数据模型与 API

- **功能目标**：创建标签相关的数据库表和 REST API
- **文件结构**：
  - 修改 `docs/reference/data-models.md`（新增 tags 和 resource_tags 表）
  - 修改 `crates/rex-hub/src/db.rs`（新增标签初始化和查询方法）
  - 修改 `crates/rex-hub/src/routes.rs`（新增标签 API 路由）
  - 创建 `crates/rex-hub/src/tags.rs`（标签业务逻辑）
- **数据模型**：
  ```sql
  CREATE TABLE tags (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL UNIQUE,
    color TEXT NOT NULL DEFAULT '#58A6FF',
    created_at TEXT NOT NULL
  );

  CREATE TABLE resource_tags (
    resource_id TEXT NOT NULL,
    tag_id TEXT NOT NULL,
    PRIMARY KEY (resource_id, tag_id),
    FOREIGN KEY (resource_id) REFERENCES resources(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
  );
  ```
- **API 端点**：
  | 方法 | 路径 | 说明 |
  |------|------|------|
  | GET | `/api/tags` | 获取所有标签 |
  | POST | `/api/tags` | 创建标签（name, color） |
  | PUT | `/api/tags/:id` | 更新标签 |
  | DELETE | `/api/tags/:id` | 删除标签 |
  | PUT | `/api/resources/:id/tags` | 设置资源标签（tag_ids 数组） |
  | GET | `/api/resources/:id/tags` | 获取资源的标签列表 |
- **后端流程**：
  1. 数据库初始化时创建 tags 和 resource_tags 表
  2. 标签 CRUD 操作通过 routes.rs 路由到 tags.rs 处理
  3. 资源标签关联通过 resource_tags 表维护
  4. 删除标签时自动清理 resource_tags 关联
  5. 删除资源时自动清理 resource_tags 关联（ON DELETE CASCADE）
- **测试标准**：
  - `cargo test --workspace` 全部通过
  - 标签 CRUD API 单元测试
  - 资源标签关联 API 单元测试
- **提交信息**：`feat: add tag data model and CRUD API for resources`

### 2 前端：标签管理 UI

- **功能目标**：在资源创建/编辑流程中支持标签选择，提供标签管理界面
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/ResourceNew.vue`（第3步添加标签选择）
  - 修改 `packages/rex-console-web/src/components/ResourceEditModal.vue`（添加标签编辑）
  - 创建 `packages/rex-console-web/src/components/TagSelector.vue`（标签选择组件）
  - 修改 `packages/rex-console-web/src/api/resources.ts`（标签相关 API 调用）
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`（中文翻译）
  - 修改 `packages/rex-console-web/src/i18n/en.ts`（英文翻译）
- **接口设计**：
  ```typescript
  // TagSelector.vue props
  interface Props {
    selectedTags: string[]       // 已选标签 ID 列表
    mode?: 'create' | 'edit'    // 创建模式下可新建标签
  }

  // Tag 类型
  interface Tag {
    id: string
    name: string
    color: string
  }
  ```
- **交互设计**：
  - 资源创建向导第3步（连接详情）底部增加"标签"区域
  - 标签选择器：已选标签显示为彩色胶囊，点击 × 移除
  - 下拉搜索框：输入名称搜索已有标签，支持新建
  - 标签颜色：12 种预设色值（品牌色体系），选择标签时可选颜色
  - 资源编辑弹窗中同样集成标签选择器
- **后端流程**：
  1. 页面加载时获取所有标签列表
  2. 保存资源时同时提交 tag_ids 数组
  3. 编辑资源时预加载当前资源的标签
- **测试标准**：
  - `bun run type-check` 通过
  - `bun run lint` 通过
  - TagSelector 组件单元测试
- **提交信息**：`feat: add tag selector UI to resource creation and editing`
