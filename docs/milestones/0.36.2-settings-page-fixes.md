# 0.36.2: 设置页修复与部署指南补全

## Context

0.36.1 完成了移动端底部导航修正。设置页面存在两类问题：
1. 环境详情页无 Agent 时显示「参考下方部署指南」但下方没有部署指南组件
2. 安全设置（会话超时、审计日志开关）和终端设置（字体、光标、keepalive）全部存 localStorage，无后端持久化，换设备或清缓存后设置丢失

版本类型：patch（bug 修复 + 功能补全）

## 产品边界

**做什么：**
- 环境详情页无 Agent 时在提示下方显示 DeployGuide 组件
- 新增后端 `/api/user/settings` API（GET/PUT），将**所有用户设置**持久化到 SQLite `settings` 表
- 前端 settings store 改为从后端加载 + 回写 localStorage 作为 fallback
- 涵盖：安全设置、终端设置、外观设置（主题/语言）

## 子任务详细设计

### 1 环境详情页添加 DeployGuide 组件

- **功能目标**：环境详情页无 Agent 时，在 AgentStatusPanel 的「参考下方部署指南」提示下方显示 DeployGuide 组件
- **文件结构**：修改 `packages/rex-console-web/src/pages/EnvironmentDetail.vue`
- **接口设计**：无 API 改动，DeployGuide 已有 `agentToken` prop
- **交互设计**：
  - 在 AgentStatusPanel 的 empty-state 提示下方渲染 DeployGuide
  - 传入当前环境的注册令牌作为 agentToken prop
  - 需要从环境数据中获取 agent token（通过 agents API 或环境详情 API）
- **测试标准**：环境详情页无 Agent 时显示完整部署指南
- **提交信息**：`fix: add deploy guide to environment detail when no agents`

### 2 用户设置后端 API + 前端 store 持久化

- **功能目标**：将安全设置和终端设置持久化到后端，支持多设备同步
- **文件结构**：
  - 修改 `crates/rex-hub/src/settings.rs`：新增 GET/PUT `/api/user/settings`
  - 修改 `crates/rex-hub/src/routes.rs`：注册新路由
  - 修改 `packages/rex-console-web/src/api/settings.ts`：新增 API 调用
  - 修改 `packages/rex-console-web/src/stores/settings.ts`：从后端加载 + 回写
  - 修改 `packages/rex-console-web/src/stores/user.ts`：主题/语言切换后同步到后端
- **接口设计**：
  ```
  GET /api/user/settings → { session_timeout, audit_enabled, theme, lang, terminal_font_size, terminal_font_family, terminal_cursor_blink, terminal_keepalive }
  PUT /api/user/settings { session_timeout?, audit_enabled?, theme?, lang?, terminal_font_size?, terminal_font_family?, terminal_cursor_blink?, terminal_keepalive? }
  ```
- **后端流程**：
  - 读取/写入 SQLite `settings` 表，key 为 `user_settings`，value 为 JSON
  - GET 返回 JSON 或默认值（无记录时返回服务端合理默认）
  - PUT 合并更新（只覆盖提供的字段）
  - 涵盖：安全设置、终端设置、外观设置（主题/语言）
- **测试标准**：cargo test 通过，前端 type-check 通过
- **提交信息**：`feat: persist user settings to backend`
