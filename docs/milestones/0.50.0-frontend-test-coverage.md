# 0.50.0: 前端测试覆盖提升

## Context

0.49.0 完成了 Redis 值编辑。当前前端有 70+ Vue 组件，但仅 4 个测试文件（useProtocol、useRecent、useTouchGestures、client API）。CLAUDE.md 要求测试覆盖率达标，当前前端测试覆盖严重不足。

本里程碑补齐关键组件和 composable 的单元测试，提升前端代码质量和可维护性。

版本类型：minor（新功能——测试本身也是交付物）

## 产品边界

**做什么：**
- 核心 composable 单元测试（useRedisSession、useTabs、useContextMenu）
- Redis 功能域组件测试（RedisKeyBrowser、RedisValueViewer、RedisConsole）
- SQL 功能域组件测试（SqlResults、SqlSidebar）
- 通用组件测试（TabBar、context menu 系统）

**不做什么：**
- 不修改产品功能代码
- 不修改产品文档
- 不添加 E2E 测试（仅单元测试）
- 不追求 100% 覆盖率（聚焦核心逻辑路径）

## 子任务详细设计

### 1 Composable 单元测试

- **功能目标**：为核心 composable 编写单元测试，覆盖状态管理和业务逻辑
- **文件结构**：
  - 新增 `packages/rex-console-web/src/features/redis/__tests__/useRedisSession.test.ts`
  - 新增 `packages/rex-console-web/src/features/workspace/__tests__/useTabs.test.ts`
  - 新增 `packages/rex-console-web/src/composables/__tests__/useContextMenu.test.ts`
- **测试范围**：
  - `useRedisSession`：连接/断开/执行命令/历史记录/错误处理
  - `useTabs`：创建/关闭/切换/重排标签/面板管理
  - `useContextMenu`：显示/隐藏/位置计算
- **测试标准**：`bun run test` 通过
- **提交信息**：`test: add unit tests for core composables`

### 2 Redis 组件测试

- **功能目标**：为 Redis 控制台关键组件编写测试
- **文件结构**：
  - 新增 `packages/rex-console-web/src/features/redis/__tests__/RedisKeyBrowser.test.ts`
  - 新增 `packages/rex-console-web/src/features/redis/__tests__/RedisValueViewer.test.ts`
- **测试范围**：
  - `RedisKeyBrowser`：树形分组逻辑、类型图标渲染、右键菜单交互、搜索触发
  - `RedisValueViewer`：各类型值渲染、编辑模式切换、保存回调触发
- **测试标准**：`bun run test` 通过
- **提交信息**：`test: add unit tests for Redis console components`

### 3 SQL 与通用组件测试

- **功能目标**：为 SQL 结果表格和通用组件编写测试
- **文件结构**：
