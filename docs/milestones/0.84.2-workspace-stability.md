# 0.84.2: 分屏与工作空间稳定性修复

## Context

0.84.1 修复了 SQLite 错误提示和 Agent 状态显示两个 bug。本里程碑聚焦工作空间核心体验：分屏布局不持久化、全局快捷键在非工作空间页面失效、终端聚焦时快捷键被全面阻断。这些问题严重影响日常使用。

版本类型：patch（bug 修复）

## 产品边界

**本阶段做什么：**
- 修复分屏布局刷新后丢失（不持久化）
- 修复 F1/Ctrl+K/Ctrl+N 在仪表盘、环境、设置等页面失效
- 修复终端聚焦时全局快捷键被阻断
- 修复工作空间终端缺少 Ctrl+Shift+F 快捷键
- 清理 globalShortcutsEnabled 死代码
- 修复 Alt+key 浏览器菜单栏干扰

**本阶段不做什么：**
- 不新增布局模式或分屏类型
- 不修改 SSH 终端本身的复制粘贴逻辑（0.85.0 规划）
- 不涉及后端代码
- 不涉及新功能开发

## 子任务详细设计

### 1 分屏布局持久化

- **功能目标**：布局模式（单面板/左右分屏/上下分屏/四宫格/主侧布局）切换后，刷新页面或重新打开工作空间时自动恢复
- **文件结构**：
  - 修改 `packages/rex-console-web/src/composables/useWorkspacePersistence.ts`：增加 `currentLayout` 的保存和恢复
  - 修改 `packages/rex-console-web/src/pages/Workspace.vue`：在 `onMounted` 中从持久化恢复布局
- **接口设计**：
  - `useWorkspacePersistence` 增加 `layout` 字段（string 类型，值为 `currentLayout`）
  - localStorage key 保持不变（`rex-workspace-state`），增加 `layout` 属性
- **交互设计**：
  - 切换布局时立即保存到 localStorage
  - 恢复时优先使用 localStorage 中的值，无值时默认 `single`
- **后端流程**：无
- **测试标准**：
  - 切换到左右分屏 → 刷新页面 → 仍为左右分屏
  - 切换到四宫格 → 关闭标签 → 重新打开 → 仍为四宫格
  - 清除 localStorage → 默认单面板
- **提交信息**：`fix: persist workspace layout mode across page reloads`

### 2 全局快捷键作用域修复

- **功能目标**：
  - F1/Ctrl+K/Ctrl+N 在所有页面（仪表盘、环境、设置等）均可正常触发
  - 终端聚焦时，全局快捷键（Ctrl+K、Ctrl+N、F1）仍然可用，仅工作空间特定快捷键（Alt+1~5、Ctrl+W 等）被抑制
  - 修复工作空间终端缺少 Ctrl+Shift+F
  - 清理 globalShortcutsEnabled 死代码
  - 修复 Alt+key 浏览器干扰
- **文件结构**：
  - 修改 `packages/rex-console-web/src/layouts/AppLayout.vue`：
    - 将 `rex:shortcut` 事件处理逻辑从 dispatch 改为直接处理（command-palette、new-connection、shortcuts-panel）
    - 移除未使用的 `globalShortcutsEnabled` provide
    - 全局快捷键（Ctrl+K、Ctrl+N、F1）不检查 TEXTAREA 守卫
  - 修改 `packages/rex-console-web/src/pages/Workspace.vue`：
    - 保留工作空间特定快捷键的 TEXTAREA 守卫
    - 移除已迁移到 AppLayout 的 `rex:shortcut` 监听器
    - Alt+1~5 处理增加 `e.preventDefault()` 防止浏览器菜单栏干扰
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceTerminal.vue`：
    - 在 `attachCustomKeyEventHandler` 中增加 Ctrl+Shift+F 处理（调用 `toggleSftp()`）
- **接口设计**：
  - AppLayout 直接通过 `provide` 提供 commandPalette/newConnection/shortcutsPanel 的显示状态
  - 子组件通过 `inject` 获取状态
- **交互设计**：
  - 在仪表盘页面按 Ctrl+K → 命令面板弹出（当前静默失败，修复后正常工作）
  - 在设置页面按 F1 → 快捷键帮助弹出
  - 终端输入框聚焦时按 Ctrl+K → 命令面板仍弹出
  - 终端输入框聚焦时按 Alt+1 → 无响应（保持现有行为）
- **后端流程**：无
- **测试标准**：
  - 在仪表盘页面按 Ctrl+K → 命令面板弹出
  - 在设置页面按 F1 → 快捷键帮助弹出
  - 在终端 textarea 聚焦时按 Ctrl+K → 命令面板弹出
  - 在终端 textarea 聚焦时按 Alt+1 → 无响应
  - 在工作空间终端按 Ctrl+Shift+F → SFTP 面板切换
  - 无 console error 或 warning
- **提交信息**：`test: verify 0.84.2 workspace stability fixes`
