# 0.65.0: 剩余页面移动端打磨

## Context

0.64.0 完成了工作空间移动端触控优化。项目还有多个管理页面缺少移动端 CSS 适配：仪表盘、环境列表、环境详情、资源创建向导。本里程碑补齐这些页面的移动端体验。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 仪表盘移动端布局优化（统计卡片、环境卡片、快速连接）
- 环境列表和详情移动端适配
- 资源创建向导移动端适配

**不做什么：**
- 不修改后端 API
- 不改变桌面端行为

## 子任务详细设计

### 1 仪表盘移动端适配

- **功能目标**：优化仪表盘在移动端的布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Dashboard.vue`
- **功能点**：
  - 统计卡片在移动端 2 列网格
  - 环境卡片在移动端单列
  - 快速连接列表在移动端紧凑显示
- **提交信息**：`feat: adapt dashboard for mobile`

### 2 环境管理页面移动端适配

- **功能目标**：优化环境列表和详情页在移动端的布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Environments.vue`
  - 修改 `packages/rex-console-web/src/pages/EnvironmentDetail.vue`
- **功能点**：
  - 环境卡片在移动端单列
  - 环境详情中的资源表格在移动端水平滚动
  - Agent 面板在移动端简化显示
- **提交信息**：`feat: adapt environment pages for mobile`

### 3 资源创建向导移动端适配

- **功能目标**：优化资源创建 4 步向导在移动端的体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/ResourceNew.vue`
- **功能点**：
  - 步骤指示器在移动端简化
  - 协议选择网格在移动端 2 列
  - 表单在移动端全宽
  - 按钮在移动端全宽
- **提交信息**：`feat: adapt resource creation wizard for mobile`
