# v0.72.0: Environments Topology View

## Context

v0.71.3（Bugfix & i18n 补全）已完成，56 个 bug 修复 + 全站 i18n 补全。当前 Environments 页面已实现 List 视图（卡片网格），Topology 标签页有 "Coming soon" 占位符。本里程碑在 Topology 标签下实现网络拓扑可视化视图，以图形化方式展示环境、资源、Agent 之间的连接关系。

版本类型：minor（新功能）

## 产品边界

**本阶段做什么：**
- 环境/资源/Agent 的拓扑图可视化（节点 + 边）
- 节点交互（点击跳转、状态叠加）
- 缩放/平移/拖拽重排
- 实时状态刷新
- 响应式与移动端适配

**不做什么：**
- 不做复杂的网络路径计算（仅展示逻辑关系）
- 不做跨环境的 Agent 代理链路可视化（当前 Agent 只属于一个环境）
- 不引入第三方拓扑编辑器（拖拽仅限节点位置调整）

## 子任务详细设计

### 1 拓扑数据模型与后端 API

- **功能目标**：定义拓扑图数据结构，后端提供 `/api/topology` 接口返回图节点与边
- **文件结构**：
  - 修改：`crates/rex-hub/src/env_api.rs`（新增 topology 端点）
  - 修改：`crates/rex-common/src/models.rs`（如需新增拓扑数据结构）
  - 修改：`packages/rex-console-web/src/api/environments.ts`（新增 topology API 调用）
- **接口设计**：
  - `GET /api/topology` → 返回拓扑图数据
  - 数据结构：
    ```json
    {
      "nodes": [
        { "id": "env-{id}", "type": "environment", "label": "...", "status": "online", "metadata": {...} },
        { "id": "agent-{id}", "type": "agent", "label": "...", "status": "online", "metadata": {...} },
        { "id": "resource-{id}", "type": "resource", "label": "...", "protocol": "ssh", "status": "connected", "metadata": {...} }
      ],
      "edges": [
        { "id": "e1", "source": "env-{id}", "target": "agent-{id}", "type": "has_agent" },
        { "id": "e2", "source": "env-{id}", "target": "resource-{id}", "type": "has_resource" }
      ]
    }
    ```
  - 节点类型：`environment` | `agent` | `resource`
  - 边类型：`has_agent`（环境→Agent）| `has_resource`（环境→资源）
- **交互设计**：无（纯 API，子任务 2/3 处理前端交互）
- **后端流程**：复用 `env_api.rs` 已有环境/Agent/资源查询，组装拓扑图结构返回
- **测试标准**：API 返回合法拓扑数据，包含所有环境、Agent、资源及其关系
- **提交信息**：`feat: add topology API endpoint for environment visualization`

### 2 拓扑图渲染引擎（vue-flow 集成）

- **功能目标**：在 EnvironmentsPage.vue 的 Topology 标签下集成 vue-flow 渲染拓扑图
- **文件结构**：
  - 新建：`packages/rex-console-web/src/features/topology/TopologyView.vue`（主拓扑视图组件）
  - 新建：`packages/rex-console-web/src/features/topology/TopologyNode.vue`（自定义节点组件）
  - 新建：`packages/rex-console-web/src/features/topology/useTopology.ts`（拓扑数据获取与状态管理 composable）
  - 修改：`packages/rex-console-web/src/pages/EnvironmentsPage.vue`（替换 Coming soon 占位符）
  - 新增依赖：`@vue-flow/core`、`@vue-flow/background`、`@vue-flow/controls`、`@vue-flow/minimap`
- **接口设计**：
  - `TopologyView.vue` props：`nodes`、`edges`
  - `TopologyNode.vue` props：`data`（节点数据，含 type/label/status/protocol）
  - `useTopology.ts`：`useTopology()` → `{ nodes, edges, loading, error, refresh }`
- **交互设计**：
  - 拓扑图居中布局，环境节点在中心，Agent/资源围绕
  - 节点按类型着色（环境=品牌色，Agent=accent，资源=按协议色）
  - 默认使用 dagre 或 elkjs 自动布局算法
- **后端流程**：无（纯前端渲染）
- **测试标准**：`bun run type-check`、`bun run lint`、`bun run build` 全绿
- **提交信息**：`feat: integrate vue-flow topology rendering engine`

### 3 交互与 UI 集成（节点点击、状态刷新、图例）

- **功能目标**：拓扑图支持节点点击跳转、实时状态刷新、拖拽重排、图例说明
- **文件结构**：
  - 修改：`packages/rex-console-web/src/features/topology/TopologyView.vue`（交互逻辑）
  - 修改：`packages/rex-console-web/src/features/topology/TopologyNode.vue`（点击、状态叠加）
  - 新建：`packages/rex-console-web/src/features/topology/TopologyLegend.vue`（图例组件）
  - 新建：`packages/rex-console-web/src/features/topology/TopologyControls.vue`（控制面板：重置布局、缩放）
- **接口设计**：
  - `TopologyNode.vue` events：`@click`（跳转到资源/环境详情）
  - `TopologyLegend.vue` props：`items`（图例项）
  - `TopologyControls.vue` events：`@reset-layout`、`@zoom-in`、`@zoom-out`
- **交互设计**：
  - 点击环境节点 → 跳转到 `/environments/{id}`
  - 点击 Agent 节点 → 跳转到 `/environments/{id}`（Agent 展开）
  - 点击资源节点 → 打开工作空间对应 Tab（跳转 `/workspace` 并自动连接）
  - 拖拽节点重排（vue-flow 原生支持）
  - 滚轮缩放 + 控制按钮缩放
  - 节点状态叠加（🟢 在线 / ⚫ 离线）
  - 顶部图例：环境 / Agent / 各协议资源的图标和颜色说明
  - 状态自动刷新（30s 轮询或 WebSocket 推送，复用现有 Agent 状态机制）
- **后端流程**：无
- **测试标准**：节点点击可跳转、状态显示正确、拖拽/缩放流畅
- **提交信息**：`feat: add topology node interactions and controls`

## 设计核对点

- [ ] 不引入多用户/RBAC/企业协作概念
- [ ] 文件传输数据不经过浏览器（拓扑图仅展示关系，不涉及传输）
- [ ] 架构一致：单二进制 + supervisor + worker
- [ ] 前端命令一律用 `bun`
- [ ] 依赖声明在根 `Cargo.toml`，子 crate 用 `workspace = true`
- [ ] 拓扑图是 Environments 页面的 Topology 标签页内容，不独立成页
- [ ] 不引入不必要第三方依赖（vue-flow 是拓扑图的标准选择，合理引入）
