# 0.68.0: 前端测试覆盖提升

## Context

0.67.0 完成了前端 UX 细节打磨（骨架屏、空态引导、操作反馈）。目前前端有 18 个测试文件，覆盖了 MobileToolbar、Redis 组件、SQL 组件、workspace 组件和部分 composable，但缺少通用组件（SkeletonLoader、EmptyState、ErrorState、LoadingSpinner）和 useToast composable 的测试，以及页面级组件（Dashboard、Environments、Agents）的测试。本里程碑补齐这些测试，提升代码质量和可维护性。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 为通用组件添加单元测试（SkeletonLoader、EmptyState、ErrorState、LoadingSpinner）
- 为 useToast composable 添加单元测试
- 为页面组件添加单元测试（Dashboard、Environments、Agents）

**不做什么：**
- 不修改后端 API
- 不修改现有测试通过的组件
- 不引入新功能模块
- 不做 E2E 测试

## 子任务详细设计

### 1 通用组件测试

- **功能目标**：为 SkeletonLoader、EmptyState、ErrorState、LoadingSpinner 四个通用组件添加单元测试
- **文件结构**：
  - 创建 `packages/rex-console-web/src/components/__tests__/SkeletonLoader.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/EmptyState.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/ErrorState.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/LoadingSpinner.test.ts`
- **测试内容**：
  - SkeletonLoader：variant prop（card/list/table）渲染正确结构、shimmer 动画类存在、count prop 控制数量
  - EmptyState：title 渲染、hint 可选渲染、action 按钮点击触发 handler、icon 渲染
  - ErrorState：message 渲染、retry 按钮存在且点击触发回调
  - LoadingSpinner：size prop（sm/md/lg）影响渲染、text prop 显示文本
- **提交信息**：`feat: add unit tests for common components`

### 2 useToast composable 单元测试

- **功能目标**：为 useToast composable 添加单元测试
- **文件结构**：
  - 创建 `packages/rex-console-web/src/composables/__tests__/useToast.test.ts`
- **测试内容**：
  - 初始状态：toasts 为空数组
  - success()：添加 success 类型 toast，持续 3 秒后自动移除
  - error()：添加 error 类型 toast，持续 5 秒后自动移除
  - warning()：添加 warning 类型 toast，持续 4 秒后自动移除
  - info()：添加 info 类型 toast，持续 3 秒后自动移除
  - remove()：手动移除指定 toast
  - 多个 toast 共存时移除不影响其他
- **提交信息**：`feat: add useToast composable unit tests`

### 3 页面组件测试

- **功能目标**：为 Dashboard、Environments、Agents 三个页面组件添加单元测试
- **文件结构**：
  - 创建 `packages/rex-console-web/src/pages/__tests__/Dashboard.test.ts`
  - 创建 `packages/rex-console-web/src/pages/__tests__/Environments.test.ts`
  - 创建 `packages/rex-console-web/src/pages/__tests__/Agents.test.ts`
- **测试内容**：
  - Dashboard：加载状态显示 SkeletonLoader、统计卡片渲染、快速连接列表/空态渲染
  - Environments：加载状态显示 SkeletonLoader、环境卡片列表渲染、空态显示 EmptyState
  - Agents：加载状态显示 SkeletonLoader、Agent 卡片列表渲染、空态显示 EmptyState
  - 注意：页面组件使用 vue-router 和 i18n，测试时需 mock 这些依赖
- **提交信息**：`feat: add page component unit tests`
