# 0.53.0: 前端性能与可访问性优化

## Context

0.52.0 完成了移动端体验优化。当前前端应用已具备完整功能，但存在以下可优化点：
- 路由已使用懒加载，但组件级别的代码分割可进一步优化
- 部分组件缺少 ARIA 标签和键盘导航支持
- 测试覆盖率 65%，低于 90% 目标，且存在测试失败

本里程碑聚焦前端性能优化、可访问性改进和测试覆盖率提升。

版本类型：minor（新功能/优化）

## 产品边界

**做什么：**
- 组件级别的代码分割优化
- 关键组件的可访问性修复（ARIA、键盘导航、对比度）
- 补充单元测试，修复失败测试，提升覆盖率

**不做什么：**
- 不修改后端 API
- 不添加新的产品功能
- 不改变现有用户可见行为

## 子任务详细设计

### 1 组件懒加载与代码分割优化

- **功能目标**：优化大型组件的加载策略，减少首屏包体积
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Workspace.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/panels/*.vue`
  - 修改 `packages/rex-console-web/vite.config.ts`
- **功能点**：
  - 工作空间面板组件（WorkspaceTerminal、WorkspaceSql、WorkspaceFiles、WorkspaceRedis、WorkspaceSqlite、WorkspaceS3）使用 `defineAsyncComponent` 懒加载
  - 检查 vite.config.ts 的 chunk 拆分策略
  - 添加 prefetch 提示优化首屏体验
- **测试标准**：
  - 构建产物体积减少 10%+
  - 首屏加载时间无退化
- **提交信息**：`feat: optimize component lazy loading`

### 2 可访问性审计与修复

- **功能目标**：修复关键组件的可访问性问题
- **文件结构**：
  - 修改 `packages/rex-console-web/src/components/ContextMenu.vue`
  - 修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/TabBar.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/panels/*.vue`
- **功能点**：
  - ContextMenu：添加 role="menu"、aria-expanded、键盘导航（↑↓选择、Esc关闭、Enter激活）
  - AppLayout：侧边栏 aria-label 完善、底部导航 aria-current
  - TabBar：标签 role="tablist"/"tab"、aria-selected、键盘切换
  - 焦点管理：模态框打开时焦点陷阱、关闭时焦点恢复
  - 色彩对比度：检查并修复不达标的文本/背景组合
- **测试标准**：
  - 关键交互组件可通过键盘完整操作
  - 使用 axe-core 或手动检查无 critical 级别问题
- **提交信息**：`feat: improve accessibility for key components`

### 3 测试覆盖补充与修复

- **功能目标**：修复失败测试，补充关键组件测试，提升覆盖率
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/__tests__/RedisValueViewer.test.ts`
  - 创建 `packages/rex-console-web/src/layouts/__tests__/AppLayout.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/ContextMenu.test.ts`
  - 创建 `packages/rex-console-web/src/features/workspace/__tests__/TabBar.test.ts`
- **功能点**：
  - 修复 RedisValueViewer 测试的 Vue Test Utils 兼容性问题
  - 补充 AppLayout 测试（移动端检测、侧边栏切换）
  - 补充 ContextMenu 测试（打开/关闭、键盘导航）
  - 补充 TabBar 测试（标签切换、关闭）
- **测试标准**：
  - 所有测试通过
  - 覆盖率达到 70%+
- **提交信息**：`test: improve test coverage and fix failing tests`
