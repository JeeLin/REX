# 0.64.0: 工作空间移动端触控优化

## Context

0.63.0 完成了设置页移动端优化。工作空间（PRODUCT.md 3.5）已有基本移动端 CSS，但触控交互可以进一步优化：连接菜单的搜索和选择、标签栏的触摸目标大小、面板拖拽在移动端的替代方案。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 连接菜单移动端搜索和选择优化
- 标签栏触摸目标增大
- 快捷键面板移动端适配

**不做什么：**
- 不修改后端 API
- 不改变桌面端工作空间行为

## 子任务详细设计

### 1 连接菜单移动端优化

- **功能目标**：优化连接菜单在移动端的搜索和选择体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Workspace.vue`
- **功能点**：
  - 连接菜单搜索框在移动端全宽
  - 资源列表项在移动端增大触摸区域（min-height: 48px）
  - 资源列表项在移动端显示更多地址信息
  - 键盘导航提示在移动端隐藏
- **提交信息**：`feat: optimize connection menu for mobile touch`

### 2 标签栏触摸目标优化

- **功能目标**：增大标签栏的触摸目标，改善移动端标签切换体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/TabBar.vue`
- **功能点**：
  - 标签项在移动端增大高度（min-height: 44px）
  - 关闭按钮在移动端增大触摸区域
  - 新建标签按钮在移动端增大
  - 布局切换指示器在移动端隐藏（已有）
- **提交信息**：`feat: enlarge tab bar touch targets for mobile`

### 3 快捷键面板移动端适配

- **功能目标**：优化快捷键帮助面板在移动端的显示
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Workspace.vue`
- **功能点**：
  - 快捷键面板在移动端全屏显示
  - 快捷键列表在移动端单列排列
  - 按键标签在移动端增大
- **提交信息**：`feat: adapt shortcuts panel for mobile`
