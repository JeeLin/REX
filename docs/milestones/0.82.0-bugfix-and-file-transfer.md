## 子任务详细设计

### 1 SQLite 自动连接修复
- **问题描述**：SQLite 资源打开后不会自动连接，需要手动点击连接按钮
- **功能目标**：SQLite 资源打开时自动建立连接，提升用户体验
- **文件结构**：
  - 修改：`packages/rex-console-web/src/features/workspace/panels/WorkspaceSqlite.vue`
- **交互设计**：
  - 打开 SQLite 标签页时自动调用连接 API
  - 显示连接状态（连接中/已连接/连接失败）
  - 连接失败时显示错误提示，支持重试

### 2 文件传输并发数量控制
- **功能目标**：允许用户配置同时进行的最大文件传输数量，避免资源占用过高
- **文件结构**：
  - 修改：`packages/rex-hub/src/transfer.rs`（后端传输队列）
  - 修改：`packages/rex-console-web/src/features/workspace/panels/WorkspaceFiles.vue`（前端传输队列）
  - 修改：`packages/rex-console-web/src/stores/transfer.ts`（传输状态管理）
- **接口设计**：
  - 后端：`GET /api/settings` 返回 `transfer_max_concurrent` 字段
  - 后端：`PUT /api/settings` 更新 `transfer_max_concurrent` 字段
  - 前端：传输队列管理并发任务，超出限制的任务进入等待状态
- **交互设计**：
  - 设置页面新增「文件传输」区块，包含「最大并发数」选项（1/2/3/5/10）
  - 传输队列显示当前进行中的任务数和等待中的任务数
  - 等待中的任务显示「等待中」状态，可拖拽调整优先级

### 3 sqlx-postgres future-incompat 警告修复
- **问题描述**：sqlx-postgres 0.8.0 存在 future-incompat 警告，未来 Rust 版本可能拒绝编译
- **功能目标**：升级 sqlx 依赖或应用官方修复，消除警告
- **文件结构**：
  - 修改：`Cargo.toml`（更新 sqlx-postgres 版本）
  - 修改：`crates/rex-postgresql/src/connector.rs`（适配新 API）
- **验证方法**：
  - `cargo check --workspace` 无 future-incompat 警告
  - `cargo test --workspace` 通过
