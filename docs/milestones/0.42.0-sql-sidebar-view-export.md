## 子任务详细设计

### 1 导出表数据菜单项改为真实导出

- **功能目标**：将"导出表数据"菜单项改为触发真实的数据导出（CSV/JSON 下载）
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`
  - 修改 `packages/rex-console-web/src/pages/SqlConsole.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceSql.vue`
- **接口设计**：
  - 新增 `emit('export-table', tableName)` 事件
  - 父组件处理：执行 `SELECT * FROM {table}` 并触发下载
- **交互设计**：
  - 点击"导出表数据" → 执行查询 → 自动下载 CSV/JSON 文件
  - 文件名格式：`export-{database}-{table}-{timestamp}.csv`
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`fix: implement real data export for export table menu item`

### 2 i18n 补全

- **功能目标**：补全导出相关的 i18n 键
- **文件结构**：
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **i18n 键**：
  - `sql.toast.exportSuccess` (导出成功)
  - `sql.toast.exportFailed` (导出失败)
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`fix: add missing i18n keys for SQL export`
