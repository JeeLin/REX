# 0.58.0: SFTP 移动端浮动工具栏

## Context

0.57.0 完成了 SSH 终端移动端浮动工具栏，为移动端终端操作提供了方向键、功能键等必需的交互控件。PRODUCT.md 3.8 节定义了 SFTP 文件管理的移动端布局和浮动工具栏，但目前 Files.vue 没有任何移动端适配。

移动端用户在 SFTP 页面无法方便地执行上传、新建、刷新等常用操作，浮动工具栏是移动端文件管理体验的关键缺失。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 实现 SFTP 文件管理移动端浮动工具栏
- 第一行：上传、新建文件、新建文件夹、刷新
- 第二行：更多选项（下载、删除、全选）
- 仅在移动端显示（桌面端隐藏）

**不做什么：**
- 不修改后端 SFTP 协议
- 不改变桌面端文件管理行为
- 不实现跨连接传输（已在 0.15.0 完成）

## 子任务详细设计

### 1 SFTP 移动端浮动工具栏组件实现

- **功能目标**：创建 FileMobileToolbar 组件，提供 SFTP 移动端操作的浮动工具栏
- **文件结构**：
  - 创建 `packages/rex-console-web/src/features/files/FileMobileToolbar.vue`
- **功能点**：
  - 第一行操作按钮区：
    - ⬆ 上传 — 触发文件上传
    - 📄 新建文件 — 打开新建文件对话框
    - 📁 新建文件夹 — 打开新建文件夹对话框
    - ↻ 刷新 — 刷新当前目录
  - 第二行更多选项区：
    - ⬇ 下载 — 下载选中文件
    - 🗑 删除 — 删除选中文件
    - ☑ 全选 — 选中/取消全选
    - ⚙ 更多 — 更多操作菜单
  - 组件 props：`visible`（boolean）、`selectedCount`（number）
  - 组件 emits：`upload`、`newFile`、`newFolder`、`refresh`、`download`、`delete`、`selectAll`
  - CSS：底部固定定位，半透明背景，按钮网格布局
  - 仅在 `window.innerWidth < 768` 时显示
- **交互设计**：
  - 按钮点击时添加视觉反馈（短暂高亮）
  - 操作按钮与桌面端工具栏功能对应
- **测试标准**：
  - 组件渲染正确的按钮布局
  - 按钮点击触发正确的 emit 事件
  - 响应式：窄屏显示，宽屏隐藏
  - `bun run type-check` 通过
- **提交信息**：`feat: add mobile floating toolbar for SFTP file manager`

- **测试标准**：
