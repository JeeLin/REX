# v0.71.0: 侧栏 + 顶栏 UI/UX 重设计

## Context
前序阶段（v0.70.8）完成了 Hub/Agent 服务化管理。当前前端 `AppLayout.vue` 的侧栏和顶栏与 `prototypes/rex-1.0/01-dashboard.html` 原型存在显著差异，需要对齐到新的设计系统。

版本类型：minor（UI 重构，向后兼容）

## 产品边界
**本阶段做**：
- 侧栏重新设计（brand 区、搜索框、导航、资源树、底部按钮）
- 顶栏重新设计（面包屑、搜索、用户信息）
- 侧栏背景色对齐原型（`--bg-sidebar: #0A0D12`）
- 导航项图标从 Unicode 替换为 SVG 线条图标
- 导航项调整（移除 Agents 独立项，Audit log 移入主导航）

**本阶段不做**：
- 资源树功能增强（ResourcePanel 逻辑不变，仅样式调整）
- 命令面板（Cmd+K）功能实现（仅搜索盒 UI 对齐）
- 移动端底部导航调整
- 新页面开发

## 子任务详细设计

### 1 侧栏 brand 区 + 工具按钮重设计

- **功能目标**：将侧栏顶部从居中文字改为左侧 glyph + 名称、右侧工具按钮的布局
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **接口设计**：无新增接口
- **交互设计**（参考原型 `01-dashboard.html`）：
  - 左侧：渐变色方块 glyph（`R` 字母，`linear-gradient(140deg, var(--brand), var(--brand-deep))`）+ "REX" 名称（mono 字体，`b` 标签包裹 `X` 用 brand 色）
  - 右侧：两个 icon-btn（主题切换 + 语言切换），30x30px，圆角 7px
  - 整体高度与顶栏一致（var(--topbar-height)）
  - `justify-content: space-between`（左右分布）
- **后端流程**：无
- **测试标准**：视觉对齐原型，主题切换按钮可点击
- **提交信息**：`feat(ui): redesign sidebar brand area with glyph + tool buttons`

### 2 侧栏搜索框对齐原型

- **功能目标**：将搜索输入框改为可点击的搜索盒样式，显示 ⌕ 图标和 `⌘K` 快捷键提示
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **接口设计**：无新增接口
- **交互设计**（参考原型）：
  - 外观：34px 高度，圆角 8px，`var(--bg-app)` 背景，`var(--border)` 边框
  - 内容：左侧 ⌕ 图标 + "Search resources" 占位符 + 右侧 `⌘K` kbd 标签
  - 点击行为：暂不实现命令面板，仅保持视觉样式（未来接 Cmd+K）
  - 搜索输入逻辑保持不变（当前的 `v-model="searchQuery"` 行为保留）
- **后端流程**：无
- **测试标准**：视觉对齐原型，搜索功能正常
- **提交信息**：`feat(ui): restyle sidebar search box with kbd shortcut hint`

### 3 导航项 SVG 图标 + 布局调整

- **功能目标**：将导航项图标从 Unicode 字符替换为 SVG 线条图标，调整导航项分组
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **接口设计**：无新增接口
- **交互设计**（参考原型）：
  - 图标使用 SVG inline（与原型一致的线条风格，16x16，stroke-width=2）
  - 导航项调整：
    - 主导航：Workspace（网格图标）、Dashboard（柱状图图标）、Environments（列表图标）、Audit log（闪电图标）、Design（组件图标）
    - 移除 Agents 独立导航项（Agent 管理保留在环境详情页内）
    - 底部导航：仅 Settings（齿轮图标）
  - 图标颜色跟随文字色（`currentColor`），激活态用 `var(--brand)` 色
- **后端流程**：无
- **测试标准**：所有导航项可点击、激活态正确、图标清晰
- **提交信息**：`feat(ui): replace unicode nav icons with SVG, adjust nav items`

### 4 侧栏底部按钮区

- **功能目标**：将侧栏底部从导航链接改为"新建环境" + "设置"按钮
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **接口设计**：无新增接口
- **交互设计**（参考原型）：
  - 布局：两个按钮水平排列，各占一半宽度
  - "+ New environment" 按钮：ghost 样式，点击触发 `REX.newEnvironment()` 或等效的环境创建弹窗
  - "⚙ 设置" 按钮：ghost 样式，链接到 `/settings`
  - 样式：30px 高度，12.5px 字号，`var(--border-strong)` 边框
- **后端流程**：无
- **测试标准**：按钮可点击，新建环境弹窗正常弹出
- **提交信息**：`feat(ui): replace sidebar bottom nav with action buttons`

### 5 顶栏重设计

- **功能目标**：将顶栏从"标题 + 按钮"改为"面包屑 + 搜索 + 用户信息"布局
- **文件结构**：修改 `packages/rex-console-web/src/layouts/AppLayout.vue`
- **接口设计**：无新增接口
- **交互设计**（参考原型）：
  - 左侧：面包屑导航（`REX Hub / 当前页面`），灰色文字，当前页加粗
  - 中间：flex spacer
  - 右侧：搜索框（260px 宽，`var(--bg-surface)` 背景）+ 用户头像（30px 圆形，渐变蓝色背景，白色文字）
  - 高度保持 `var(--topbar-height)`
  - 移除当前的全屏按钮和退出按钮（退出改到用户头像下拉菜单或保留为图标）
- **后端流程**：无
- **测试标准**：面包屑显示正确，头像可点击
- **提交信息**：`feat(ui): redesign topbar with breadcrumbs, search, and avatar`

### 6 侧栏背景色 + 全局 token 微调

- **功能目标**：对齐原型的色彩体系
- **文件结构**：修改 CSS token 文件（`packages/rex-console-web/src/styles/` 下的 token/variable 文件）
- **接口设计**：无
- **交互设计**：
  - 侧栏背景色：从 `var(--bg-surface)` 改为 `var(--bg-sidebar)`（`#0A0D12`，更深）
  - 确保 `--bg-sidebar` token 在前端 CSS 变量中定义
  - 侧栏 brand 区 border-bottom 保持
  - 检查并确保所有新增组件使用 token 而非硬编码色值
- **后端流程**：无
- **测试标准**：侧栏颜色与原型一致，无硬编码色值
- **提交信息**：`feat(ui): align sidebar background color with prototype tokens`

## 设计核对点

1. 侧栏布局与 `01-dashboard.html` 原型一致（brand 区、搜索、导航、资源树、底部按钮）
2. 顶栏布局与原型一致（面包屑、搜索、头像）
3. 所有颜色使用 CSS token，无硬编码 hex
4. 导航项图标使用 SVG 线条风格
5. 侧栏背景色为 `--bg-sidebar`（#0A0D12）
6. 移动端侧栏抽屉行为不变
7. 不引入新的外部依赖
