# 0.66.0: S3/SQLite 控制台移动端优化

## Context

0.65.0 完成了剩余页面移动端打磨。S3/MinIO 控制台和 SQLite 控制台是最后两个没有专门移动端适配的协议控制台。本里程碑补齐这两个控制台的移动端体验。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- S3/MinIO 控制台移动端布局优化（桶列表、对象浏览器）
- SQLite 控制台移动端适配（在工作空间面板中）
- 工作空间面板通用移动端样式

**不做什么：**
- 不修改后端 API
- 不改变桌面端行为

## 子任务详细设计

### 1 S3/MinIO 控制台移动端适配

- **功能目标**：优化 S3/MinIO 控制台在移动端的布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/s3/S3Console.vue`
  - 修改 `packages/rex-console-web/src/features/s3/BucketList.vue`
  - 修改 `packages/rex-console-web/src/features/s3/ObjectBrowser.vue`
- **功能点**：
  - 桶列表在移动端单列
  - 对象浏览器工具栏在移动端紧凑排列
  - 面包屑路径在移动端可水平滚动
- **提交信息**：`feat: adapt S3 console for mobile`

### 2 SQLite 控制台移动端适配

- **功能目标**：优化 SQLite 控制台在移动端的布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/WorkspaceSqlite.vue`
- **功能点**：
  - SQLite 面板在移动端全宽
  - SQL 编辑器在移动端调整高度
  - 结果表格在移动端水平滚动
- **提交信息**：`feat: adapt SQLite console for mobile`

### 3 工作空间面板通用移动端样式

- **功能目标**：为工作空间面板添加通用移动端基础样式
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/WorkspaceTerminal.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/WorkspaceSql.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/WorkspaceFiles.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/WorkspaceRedis.vue`
- **功能点**：
  - 所有工作空间面板在移动端添加基础 padding 调整
  - 面板内工具栏在移动端紧凑显示
- **提交信息**：`feat: add mobile base styles to workspace panels`
