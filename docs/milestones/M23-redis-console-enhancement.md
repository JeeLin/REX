# M23: Redis 控制台增强（批量操作 + 值查看器增强 + 导入导出）

## Context

M0–M22 完成了从项目骨架到 SQL 控制台完善的全部开发。Redis 控制台已有键树、值查看器、CLI、Server Status。本里程碑对标 ARDM 的完整 Redis 管理能力，补齐批量操作、值查看器增强和导入导出。

本里程碑版本类型：minor（新功能），版本号 0.23.0 → 0.24.0。

## 产品边界

**本阶段做：**
- 批量操作：批量删除（checkbox + 规则）/ 批量 TTL / 导入导出（选中键导出文件、导入键、导入 CMD 批量命令）
- 值查看器「在新标签打开」：支持将值查看器独立成 Tab
- 键树增强：内存分析、慢日志、FlushDB
- 连接管理增强：编辑/删除/复制连接

**本阶段不做：**
- 虚拟滚动优化（当前实现已足够）
- 高级 FormatViewer（Msgpack/PHPSerialize 等）— 优先级低
- Stream 消费组表格 — 复杂度高，后续里程碑

## 子任务详细设计

### 1 批量操作（删除/TTL/导入导出）

**功能目标**

支持对多个键进行批量操作，包括删除、设置 TTL、导入导出。

**文件结构**

修改：
- `packages/rex-console-web/src/features/redis/RedisPage.vue` — 添加批量操作 UI 和逻辑

**交互设计**

```
┌─ Redis Console ──────────────────────────────────────┐
│ [连接列表] │ [键树]                    │ [值查看器]   │
│            │ ☐ key1                   │              │
│            │ ☑ key2                   │              │
│            │ ☑ key3                   │              │
│            │                          │              │
│            │ [批量操作工具栏]          │              │
│            │ [删除] [TTL] [导出] [导入]│              │
└─────────────────────────────────────────────────────┘
```

**批量删除流程**

1. 选中多个键（checkbox 或 Shift 范围选择）
2. 点击「删除」按钮
3. 确认弹窗显示选中键数量
4. 确认后执行 DEL 命令
5. 刷新键树

**批量 TTL 流程**

1. 选中多个键
2. 点击「TTL」按钮
3. 输入 TTL 值（秒）
4. 确认后执行 EXPIRE 命令
5. 刷新键树

**导出流程**

1. 选中多个键
2. 点击「导出」按钮
3. 选择导出格式（JSON/CSV）
4. 生成文件并下载

**导入流程**

1. 点击「导入」按钮
2. 选择文件（JSON/CSV）
3. 预览导入数据
4. 确认后执行 SET 命令
5. 刷新键树

**测试标准**

- 选中多个键 → 批量删除 → 键被删除
- 选中多个键 → 批量 TTL → TTL 设置成功
- 选中多个键 → 导出 → 文件下载
- 导入文件 → 键被创建
- type-check + build 通过

**提交信息**: `feat(redis): add batch operations for delete/TTL/import/export`

### 2 值查看器「在新标签打开」

**功能目标**

支持将值查看器独立成 Tab，方便同时查看多个键。

**文件结构**

修改：
- `packages/rex-console-web/src/features/redis/RedisPage.vue` — 添加「在新标签打开」按钮和 Tab 管理

**交互设计**

```
┌─ Redis Console ──────────────────────────────────────┐
│ [连接列表] │ [键树]     │ [Tab1] [Tab2] [Tab3]     │
│            │ ☑ key1     │                           │
│            │ ☑ key2     │ ┌─ 值查看器 (Tab1) ──────┐│
│            │            │ │ key: user:123          ││
│            │            │ │ type: hash             ││
│            │            │ │ ...                    ││
│            │            │ └────────────────────────┘│
└─────────────────────────────────────────────────────┘
```

**实现流程**

1. 值查看器工具栏添加「在新标签打开」按钮
2. 点击后创建新 Tab，显示该键的值
3. Tab 栏显示所有打开的值查看器 Tab
4. 支持关闭 Tab

**测试标准**

- 点击「在新标签打开」→ 新建 Tab 显示值
- Tab 栏显示所有打开的值查看器
- 关闭 Tab → Tab 消失
- type-check + build 通过

**提交信息**: `feat(redis): add open-in-new-tab for value viewer`

### 3 连接管理增强（编辑/删除/复制）

**功能目标**

增强连接管理功能，支持编辑、删除、复制连接。

**文件结构**

修改：
- `packages/rex-console-web/src/features/redis/RedisPage.vue` — 添加连接管理 UI

**交互设计**

```
┌─ Redis Console ──────────────────────────────────────┐
│ [连接列表]                                         │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 📡 Redis Local                    [编辑][删除] │ │
│ │ 📡 Redis Production   [复制]    [编辑][删除] │ │
│ └─────────────────────────────────────────────────┘
└─────────────────────────────────────────────────────┘
```

**编辑流程**

1. 点击连接的「编辑」按钮
2. 打开编辑弹窗
3. 修改连接信息
4. 保存后刷新连接

**删除流程**

1. 点击连接的「删除」按钮
2. 确认弹窗
3. 确认后删除连接
4. 刷新连接列表

**复制流程**

1. 点击连接的「复制」按钮
2. 复制连接配置到新连接
3. 打开编辑弹窗
4. 修改名称后保存

**测试标准**

- 编辑连接 → 信息更新
- 删除连接 → 连接消失
- 复制连接 → 新连接创建
- type-check + build 通过

**提交信息**: `feat(redis): add connection management (edit/delete/copy)`
