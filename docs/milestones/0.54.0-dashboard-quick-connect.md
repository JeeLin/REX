# 0.54.0: 仪表盘增强与快速连接优化

## Context

0.53.0 完成了前端性能与可访问性优化。当前仪表盘已具备基本功能（统计卡片、环境卡片、快速连接），但存在以下可优化点：
- 快速连接显示全部资源而非最近使用的资源，缺少地址和环境名信息
- 统计数据不支持自动刷新
- 环境卡片缺少"在工作区打开所有资源"的快捷操作
- 统计卡片缺少手动刷新能力

本里程碑聚焦仪表盘体验改进，提升日常操作效率。

版本类型：minor（新功能/优化）

## 产品边界

**做什么：**
- 优化快速连接：改为显示最近使用的资源，补充地址和环境名
- 仪表盘自动刷新：定时更新统计数据
- 环境卡片操作增强：右键菜单增加"在工作区打开所有资源"
- 统计卡片支持手动刷新

**不做什么：**
- 不修改后端 API
- 不添加新的产品功能
- 不改变现有用户可见行为（仅增强现有功能）

## 子任务详细设计

### 1 快速连接改为最近使用并补充信息

- **功能目标**：快速连接区域改为显示最近使用的资源，卡片补充地址和环境名信息
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Dashboard.vue`
- **功能点**：
  - 快速连接区域改为显示最近使用的资源（最多8个）
  - 每个卡片显示：协议图标 + 资源名称 + 地址 + 环境名
  - 点击直接跳转到工作空间并建立连接
- **测试标准**：
  - 快速连接显示最近使用的资源
  - 卡片包含地址和环境名
- **提交信息**：`feat: enhance dashboard quick connect with recent resources`

### 2 仪表盘自动刷新

- **功能目标**：仪表盘统计数据自动定期刷新
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Dashboard.vue`
- **功能点**：
  - 页面加载后每60秒自动刷新统计数据
  - 切换到其他页面后停止刷新，返回时重新开始
- **测试标准**：
  - 统计数据每60秒自动更新
- **提交信息**：`feat: add dashboard auto-refresh`

### 3 环境卡片右键菜单增强

- **功能目标**：环境卡片右键菜单增加"在工作区打开所有资源"操作
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Dashboard.vue`
- **功能点**：
  - 环境卡片右键菜单增加"在工作区打开所有资源"选项
  - 点击后将该环境下的所有资源在工作空间中打开
- **测试标准**：
  - 右键菜单包含"在工作区打开所有资源"
  - 点击后所有资源在工作空间打开
- **提交信息**：`feat: add open-all-in-workspace to environment card`

### 4 统计卡片手动刷新

- **功能目标**：统计卡片支持手动刷新
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Dashboard.vue`
- **功能点**：
  - 统计卡片右键菜单已支持刷新（`onStatCardCtx`）
  - 确保刷新逻辑正确调用 `loadData()`
- **测试标准**：
  - 右键统计卡片可手动刷新
- **提交信息**：`feat: improve stat card refresh`
