# 0.49.0: Redis 值编辑

## Context

0.48.0 完成了 Redis 键浏览器增强：树形视图、类型图标、右键菜单（复制键名、查看值、删除键、设置 TTL）。

当前 Redis 控制台已具备完整的浏览能力（键浏览 + 值查看），但缺少写入能力。用户无法通过 GUI 创建新键或修改值，只能通过命令行输入 SET/HSET 等命令。本里程碑补齐这些差距。

版本类型：minor（新功能，向后兼容）

## 产品边界

**做什么：**
- 新建键对话框（选择类型、输入键名、输入值）
- String 值内联编辑（修改值 + SET 保存）
- Hash 字段编辑（添加/修改/删除字段）
- List 元素编辑（添加/删除元素）
- Set 成员编辑（添加/删除成员）
- ZSet 成员编辑（添加/删除成员 + 分数）

**不做什么：**
- 不修改键浏览器组件
- 不修改后端 WebSocket 协议
- 不实现批量编辑功能
- 不修改产品文档

## 子任务详细设计

### 1 新建键对话框

- **功能目标**：在键浏览器顶部添加「+ 新建键」按钮，点击弹出对话框创建新的 Redis 键
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/RedisConsole.vue`（添加新建按钮 + 弹窗）
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
- **交互设计**：
  - 按钮位置：键浏览器搜索框下方
  - 弹窗内容：
    - 键名输入框
    - 类型选择（String/Hash/List/Set/ZSet，下拉框或单选按钮组）
    - 值输入区（根据类型动态变化）：
      - String：文本域（textarea）
      - Hash：键值对表格（可添加多行）
      - List：列表输入（可添加多行）
      - Set：集合输入（可添加多行）
      - ZSet：键值对表格（成员 + 分数）
  - 确认后发送对应命令：
    - String → `SET {key} {value}`
    - Hash → 逐个 `HSET {key} {field} {value}`
    - List → 逐个 `RPUSH {key} {value}`
    - Set → 逐个 `SADD {key} {value}`
    - ZSet → 逐个 `ZADD {key} {score} {member}`
  - 创建成功后刷新键浏览器
- **后端流程**：复用现有 Redis 命令执行，无变更
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add create key dialog to Redis console`

### 2 值编辑器组件

- **功能目标**：根据 Redis 值类型提供对应的内联编辑界面
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/RedisValueViewer.vue`（添加编辑模式）
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
- **交互设计**：
  - **String**：
    - 当前：只读显示值
    - 改为：textarea 可编辑，底部「保存」按钮
    - 保存发送 `SET {key} {new_value}`
  - **Hash**：
    - 当前：只读键值对表格
    - 改为：每行可编辑，行尾有删除按钮（删除字段发送 `HDEL {key} {field}`）
    - 表格底部有「添加字段」行（field + value 输入框 + 添加按钮）
    - 保存修改发送 `HSET {key} {field} {value}`
  - **List**：
    - 当前：只读列表
    - 改为：每行可编辑，行尾有删除按钮（删除元素发送 `LREM {key} 1 {value}`）
    - 底部有「添加元素」输入框
    - 保存添加发送 `RPUSH {key} {value}`
  - **Set**：
    - 当前：只读成员列表
    - 改为：每行可编辑，行尾有删除按钮（删除成员发送 `SREM {key} {member}`）
    - 底部有「添加成员」输入框
    - 保存添加发送 `SADD {key} {member}`
  - **ZSet**：
    - 当前：只读成员+分数
    - 改为：每行可编辑成员和分数，行尾有删除按钮（删除发送 `ZREM {key} {member}`）
    - 底部有「添加成员」行（member + score 输入框）
    - 保存添加发送 `ZADD {key} {score} {member}`
  - **删除键**：保持现有的「删除键」按钮
  - **通用**：编辑后标记为「已修改」状态，保存后清除标记
- **后端流程**：复用现有 Redis 命令执行，无变更
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add inline value editor to Redis value viewer`

### 3 值编辑器集成

- **功能目标**：在 RedisConsole.vue 中集成新建键按钮和值编辑器的编辑回调
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/RedisConsole.vue`（添加新建键按钮 + 编辑回调）
- **交互设计**：
  - 键浏览器搜索框下方添加「+ 新建键」按钮
  - 点击按钮弹出新建键对话框
  - 值查看器的编辑操作通过 emit 回调到 RedisConsole，由父组件执行命令
- **后端流程**：无变更
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: integrate value editor into Redis console`
