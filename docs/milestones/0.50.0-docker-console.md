# 0.50.0: Docker 控制台

## Context

0.49.0 完成了 Redis 值编辑，Redis 控制台现已具备完整的浏览和编辑能力。

检查发现0.9.0里程碑声称完成了 Docker 容器管理，但实际没有任何前端代码（无 `features/docker/` 目录、无 `WorkspaceDocker.vue`）或后端 crate（`crates/` 中无 `rex-docker`）。本里程碑从头实现 Docker 控制台，补齐这一重要差距。

版本类型：minor（新功能，向后兼容）

## 产品边界

**做什么：**
- Docker 容器列表（显示名称、状态、镜像、端口映射）
- 容器状态操作（启动/停止/重启/删除）
- 容器详情面板（Inspect 信息）
- 容器日志实时查看
- Docker 资源创建向导（Unix socket / TCP 连接配置）
- 工作空间 Docker 面板集成

**不做什么：**
- 不实现 Docker Compose 集成
- 不实现 Docker Swarm 集群管理
- 不实现镜像管理（仅容器操作）
- 不实现网络、卷、构建等功能
- 不实现容器内文件浏览（通过 SSH/SFTP 替代）

## 子任务详细设计

### 1 后端 Docker 连接器（rex-docker crate）

- **功能目标**：实现 Docker Engine API 通信，支持容器列表、启停、日志、inspect 等操作
- **文件结构**：
  - 新增 `crates/rex-docker/Cargo.toml`
  - 新增 `crates/rex-docker/src/lib.rs`
  - 新增 `crates/rex-docker/src/connector.rs` — Docker 连接器实现
  - 修改 `Cargo.toml`（workspace）— 添加 `rex-docker` 成员
  - 修改 `crates/rex-hub/Cargo.toml` — 添加 `rex-docker` 依赖
- **接口设计**：
  ```rust
  pub struct DockerConfig {
      pub host: String,           // unix:///var/run/docker.sock 或 tcp://host:port
      pub tls: Option<TlsConfig>,
  }

  #[async_trait]
  pub trait DockerConnector: Send + Sync {
      async fn list_containers(&self, all: bool) -> Result<Vec<ContainerInfo>>;
      async fn inspect_container(&self, id: &str) -> Result<ContainerDetail>;
      async fn start_container(&self, id: &str) -> Result<()>;
      async fn stop_container(&self, id: &str) -> Result<()>;
      async fn restart_container(&self, id: &str) -> Result<()>;
      async fn remove_container(&self, id: &str, force: bool) -> Result<()>;
      async fn logs(&self, id: &str, tail: &str) -> Result<String>;
  }
  ```
- **后端流程**：通过 reqwest 调用 Docker Engine REST API（`/containers/json`、`/containers/{id}/json` 等）
- **测试标准**：`cargo test -p rex-docker` 通过
- **提交信息**：`feat: add rex-docker crate with Docker Engine API connector`

### 2 Hub Docker WebSocket 会话管理

- **功能目标**：在 Hub 中实现 Docker WebSocket 端点，支持容器操作的消息协议
- **文件结构**：
  - 新增 `crates/rex-hub/src/ws_docker.rs`
  - 修改 `crates/rex-hub/src/main.rs` — 注册 Docker WebSocket 路由
- **接口设计**：
  WebSocket 消息格式：
  ```json
  // 请求
  { "type": "list", "id": "uuid", "all": true }
  { "type": "inspect", "id": "uuid", "container_id": "abc123" }
  { "type": "start", "id": "uuid", "container_id": "abc123" }
  { "type": "stop", "id": "uuid", "container_id": "abc123" }
  { "type": "restart", "id": "uuid", "container_id": "abc123" }
  { "type": "remove", "id": "uuid", "container_id": "abc123", "force": false }
  { "type": "logs", "id": "uuid", "container_id": "abc123", "tail": "100" }

  // 响应
  { "type": "response", "id": "uuid", "value": [...], "elapsed_ms": 12 }
  { "type": "error", "id": "uuid", "message": "..." }
  ```
- **后端流程**：复用现有 WebSocket 模式，通过 DockerConnector 执行操作
- **测试标准**：`cargo test -p rex-hub` 通过
- **提交信息**：`feat: add Docker WebSocket session handler to Hub`

### 3 前端 Docker 容器控制台

- **功能目标**：实现 Docker 容器管理 GUI，包括容器列表、详情、日志、操作
- **文件结构**：
  - 新增 `packages/rex-console-web/src/features/docker/DockerConsole.vue`
  - 新增 `packages/rex-console-web/src/features/docker/DockerContainerList.vue`
  - 新增 `packages/rex-console-web/src/features/docker/DockerContainerDetail.vue`
  - 新增 `packages/rex-console-web/src/features/docker/DockerLogViewer.vue`
  - 新增 `packages/rex-console-web/src/features/docker/useDockerSession.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
- **交互设计**：
  - **容器列表**：表格显示名称、状态（运行中/已停止/已退出）、镜像、端口、创建时间
  - **状态操作**：行尾操作按钮（启动/停止/重启/删除），删除需确认
  - **容器详情**：点击容器显示 inspect 信息（ID、镜像、命令、环境变量、挂载卷、网络配置）
  - **日志查看**：实时流式显示容器日志，支持搜索过滤、自动滚动、暂停/恢复
  - **刷新**：手动刷新按钮 + 自动轮询（5秒间隔）
- **后端流程**：复用现有 WebSocket 消息模式
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add Docker container console with list, detail, and logs`

- **后端流程**：无变更
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: integrate Docker console into workspace and resource wizard`
