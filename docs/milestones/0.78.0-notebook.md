# 0.78.0: 交互式 Notebook

## Context

0.77.0 实现了标签系统与资源分组增强。本阶段新增交互式 Notebook 功能，让用户可以在富文本编辑器中编写运维文档，在对应资源上执行命令，并将结果写回文档。类似 Jupyter Notebook，但面向基础设施运维场景。

版本类型：minor（新功能，向后兼容）

## 产品边界

**做什么：**
- Notebook 创建、编辑、删除、列表管理
- Block-based 富文本编辑器（标题、段落、代码块、命令块）
- 命令块绑定资源，支持所有 7 种协议（SSH、MySQL、PostgreSQL、Redis、SQLite、SFTP、S3）
- 命令执行后内联展示结果
- 结果历史保留，支持多次执行
- Notebook 导入/导出（JSON 格式）
- Notebook 在侧边栏显示入口

**不做什么：**
- 不做 Notebook 共享/协作（单用户产品）
- 不做 Notebook 模板系统（后续里程碑）
- 不做 Notebook 内嵌终端交互模式（结果内联展示为主）
- 不做 Notebook 版本历史/撤销树
- 不做 Notebook 搜索内容（仅支持标题列表筛选）

## 子任务详细设计

### 1 后端：Notebook 数据模型与 API

- **功能目标**：实现 Notebook 的 SQLite 数据模型和 RESTful API
- **文件结构**（创建/修改哪些文件）
  - `crates/rex-hub/src/migrations.sql` — 新增 notebooks、notebook_blocks、notebook_executions 三张表
  - `crates/rex-hub/src/notebook.rs` — Notebook 数据模型、CRUD 函数
  - `crates/rex-hub/src/routes.rs` — Notebook API 路由（在现有文件中添加）
  - `crates/rex-hub/src/main.rs` — 注册路由
- **接口设计**（API 端点 / 组件 props / 数据模型）

  数据模型：
  ```rust
  struct Notebook {
      id: String,
      title: String,
      description: Option<String>,
      tags: Vec<String>,         // JSON 数组存储
      created_at: String,
      updated_at: String,
  }

  struct NotebookBlock {
      id: String,
      notebook_id: String,
      block_type: String,        // "heading" | "paragraph" | "code" | "command"
      content: String,
      resource_id: Option<String>,
      protocol: Option<String>,  // "ssh" | "mysql" | "postgresql" | "redis" | "sqlite" | "sftp" | "s3"
      order_index: i32,
      created_at: String,
      updated_at: String,
  }

  struct NotebookExecution {
      id: String,
      block_id: String,
      status: String,            // "running" | "success" | "error" | "timeout"
      output: String,
      duration_ms: Option<i64>,
      executed_at: String,
  }
  ```

  API 端点：
  | 方法 | 路径 | 说明 |
  |------|------|------|
  | GET | `/api/notebooks` | 列出所有 Notebook |
  | POST | `/api/notebooks` | 创建 Notebook |
  | GET | `/api/notebooks/:id` | 获取 Notebook（含 blocks） |
  | PUT | `/api/notebooks/:id` | 更新 Notebook 元信息 |
  | DELETE | `/api/notebooks/:id` | 删除 Notebook（级联删除 blocks + executions） |
  | POST | `/api/notebooks/:id/blocks` | 批量更新 blocks（整篇保存） |
  | POST | `/api/notebooks/:id/export` | 导出为 JSON |
  | POST | `/api/notebooks/import` | 从 JSON 导入 |
  | POST | `/api/notebook-executions` | 执行命令块（返回 execution 结果） |
  | GET | `/api/notebook-blocks/:id/executions` | 获取某个 block 的执行历史 |

- **后端流程**
  1. notebooks 表存储元信息，tags 用 JSON TEXT 字段
  2. blocks 按 order_index 排序，前端提交时整体替换（全量更新）
  3. 命令执行：后端根据 block 的 protocol + resource_id 调用对应协议 crate 执行，返回结果
  4. 执行结果写入 notebook_executions 表

- **测试标准**：CRUD API 全覆盖、命令执行覆盖 7 种协议、导入/导出正确性
- **提交信息**：`feat(notebook): add backend data model and API for notebook`

  - `packages/rex-console-web/src/components/notebook/blocks/` — 各块类型组件
    - `HeadingBlock.vue` — 标题块（H1/H2/H3）
    - `ParagraphBlock.vue` — 段落块（富文本）
    - `CodeBlock.vue` — 代码块（语法高亮，只读）
    - `CommandBlock.vue` — 命令块（核心，见子任务 4）
  - `packages/rex-console-web/src/components/notebook/BlockToolbar.vue` — 块操作工具栏
  - `packages/rex-console-web/src/components/notebook/SlashMenu.vue` — 斜杠命令菜单
- **接口设计**（API 端点 / 组件 props / 数据模型）
  - Editor Props：`notebook: Notebook`, `blocks: NotebookBlock[]`
  - 块间操作：Enter 创建新块、Backspace 空块删除、拖拽排序
  - `/` 命令菜单：输入 `/` 弹出菜单，可选插入段落、标题、代码块、命令块

- **测试标准**：块创建/删除/排序、标题级别切换、自动保存
- **提交信息**：`feat(notebook): implement block-based rich text editor`

### 4 前端：命令块资源绑定与执行

- **功能目标**：命令块是 Notebook 的核心，绑定资源并执行命令
- **文件结构**（创建/修改哪些文件）
  - `packages/rex-console-web/src/components/notebook/blocks/CommandBlock.vue` — 命令块组件
  - `packages/rex-console-web/src/components/notebook/ResourcePicker.vue` — 资源选择器
  - `packages/rex-console-web/src/stores/notebook.ts` — Notebook 状态管理
- **接口设计**（API 端点 / 组件 props / 数据模型）
  - CommandBlock 状态：
    ```
    未绑定资源 → 灰色提示「选择资源」
    已绑定资源 → 显示资源名称 + 协议图标 + 命令输入框
    执行中 → 加载动画
    执行完成 → 结果展示区域
    ```
  - 资源选择器：下拉搜索，按环境分组，显示协议图标 + 资源名称 + 地址
- **交互设计**
  - 点击「选择资源」打开资源选择下拉框
  - 资源选择后，协议图标和颜色自动切换
  - `Ctrl+Enter` 执行命令
  - 命令输入区支持多行（SSH 命令），SQL 块支持语法高亮
  - 协议感知：SSH 块显示终端风格，SQL 块显示 SQL 语法高亮，Redis 块显示 Redis 命令格式
- **后端流程**：调用 `/api/notebook-executions` 执行命令，返回结果
- **测试标准**：资源绑定、命令执行、协议切换、错误处理
- **提交信息**：`feat(notebook): add command block with resource binding and execution`

### 5 前端：结果内联展示与历史

- **功能目标**：命令执行后在块下方内联展示结果，保留历史
- **文件结构**（创建/修改哪些文件）
  - `packages/rex-console-web/src/components/notebook/ResultPanel.vue` — 结果展示面板
  - `packages/rex-console-web/src/components/notebook/ExecutionHistory.vue` — 执行历史
- **接口设计**（API 端点 / 组件 props / 数据模型）
  - ResultPanel Props：`execution: NotebookExecution`
  - 结果展示：
    - SSH 命令：终端风格，monospace 字体，深色背景
    - SQL 查询：表格展示（与 SQL 控制台结果表一致）
    - Redis 命令：命令 + 结果的 key-value 展示
    - S3 命令：列表/状态展示
  - 执行历史：时间线形式，显示每次执行的时间、状态、耗时
- **交互设计**
  - 结果区域可折叠/展开
  - 结果文本支持复制
  - 历史记录可切换查看
  - 最新结果默认展开，历史默认折叠
- **后端流程**：调用 `/api/notebook-blocks/:id/executions` 获取历史
- **测试标准**：结果渲染、历史切换、复制功能
- **提交信息**：`feat(notebook): add inline result display and execution history`

### 6 导入/导出功能

- **功能目标**：支持 Notebook 导入/导出为 JSON 文件
- **文件结构**（创建/修改哪些文件）
  - `packages/rex-console-web/src/utils/notebook-io.ts` — 导入/导出逻辑
- **接口设计**（API 端点 / 组件 props / 数据模型）
  - 导出格式：
    ```json
    {
      "rex-notebook": "1.0",
      "title": "部署手册",
      "description": "...",
      "blocks": [
        { "type": "heading", "content": "步骤 1", "level": 2 },
        { "type": "paragraph", "content": "先检查版本..." },
        { "type": "command", "protocol": "ssh", "resource_name": "云服务器", "command": "nginx -v" }
      ]
    }
    ```
  - 导入时：resource_name 匹配现有资源，找不到则置空提示用户重新绑定
- **交互设计**
  - 导出：菜单「导出为 JSON」，触发文件下载
  - 导入：菜单「从 JSON 导入」，选择文件，创建新 Notebook
- **后端流程**：调用导入/导出 API
- **测试标准**：导出格式正确、导入后块完整性、资源名匹配
