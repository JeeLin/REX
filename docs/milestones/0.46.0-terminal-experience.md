## 子任务详细设计

### 1 延迟测量与工具栏显示

- **功能目标**：在终端工具栏显示实时 SSH 连接延迟
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceTerminal.vue`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`（新增延迟 i18n 键）
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`（新增延迟 i18n 键）
- **接口设计**：
  - WebSocket 消息：向 SSH WebSocket 发送 `{"type": "ping", "timestamp": <ms>}`，服务端回复 `{"type": "pong", "timestamp": <ms>}`
  - 延迟计算：`latency = now - pingTimestamp`（ms）
  - 测量频率：每 5 秒一次（参考 PRODUCT.md 3.6 "每 5 秒 ping 测量"）
- **交互设计**：
  - 工具栏左侧：`{resourceName} · {latency}ms`（延迟显示在资源名后）
  - 延迟颜色：< 100ms 绿色，100-300ms 黄色，> 300ms 红色
  - 工具栏右键菜单"复制延迟信息"：改为复制实际延迟值
- **后端流程**：
  - 需在 `crates/rex-hub/src/ws_ssh.rs` 中添加 ping/pong 消息处理
  - 收到 ping 后立即回复 pong（原样返回 timestamp）
  - 前端在 xterm onMessage 中识别 pong 类型消息
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add latency measurement and display to terminal toolbar`

### 3 Terminal.vue i18n 修复

- **功能目标**：将 Terminal.vue（独立页面）中的硬编码中文替换为 i18n t() 函数
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Terminal.vue`
- **需替换的字符串**（5 处）：
  1. `错误: ${msg.payload.message}` → `t('ws.terminal.termError', { message: msg.payload.message })`
  2. `连接已关闭` → `t('ws.terminal.termClosed')`
  3. `WebSocket 连接失败` → `t('ws.terminal.wsFailed')`
  4. `会话创建失败: ...` / `未知错误` → `t('ws.terminal.sessionFailed', { message: ... })`
  5. `提示: 请使用 Ctrl+V 粘贴内容` → `t('ws.terminal.mobile.pastePlaceholder')` 或新增专用键
- **依赖**：复用 WorkspaceTerminal.vue 已有的 i18n 键（ws.terminal.*）
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`fix: internationalize hardcoded Chinese strings in Terminal.vue`
