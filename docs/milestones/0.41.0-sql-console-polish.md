# 0.41.0: SQL 控制台体验精化

## Context

0.40.0 完成了 SQL 控制台功能补全（DDL 查看、新建表、标签右键菜单、导出下载、i18n）。本里程碑修复 0.40.0 遗留的 UX 问题：`alert()` 替换为 Toast 通知、新建表模板方言适配、DDL 错误处理优化。

版本类型：patch（bug 修复/体验优化）

## 产品边界

- 替换 SQL 侧边栏中 3 处 `alert()` 为 Toast 通知

**不做什么：**

- 不修改产品文档
- 不引入新的后端 API

## 子任务详细设计

### 1 Toast 替换 alert

- **功能目标**：将 SQL 侧边栏和控制台中的 `alert()` 调用替换为 Toast 通知，提升用户体验
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`
  - 修改 `packages/rex-console-web/src/pages/SqlConsole.vue`
- **交互设计**：
  - `viewRowCount`：alert → Toast（成功样式）
  - `viewConstraints`：alert → Toast（成功样式）
  - `handleViewDefinition` 错误：alert → Toast（错误样式）
  - SqlConsole execute 错误回调：alert → Toast（错误样式）
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`fix: replace alert() with toast notifications in SQL console`

### 2 新建表模板方言适配

- **功能目标**：新建表标签页中的 CREATE TABLE 模板根据当前数据库协议自动选择合适的语法
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`
- **交互设计**：
  - 新增 `database` prop 的监听，或在 `handleCreateNewTable` 中根据数据库名推断方言
  - MySQL：`id INT PRIMARY KEY AUTO_INCREMENT`
  - PostgreSQL：`id SERIAL PRIMARY KEY`
  - SQLite：`id INTEGER PRIMARY KEY AUTOINCREMENT`
  - 其他：使用 MySQL 风格（默认）
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`fix: adapt create table template to database dialect`

### 3 i18n 补全

- **功能目标**：补全缺失的 i18n 键
- **文件结构**：
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **i18n 键**：
  - `sql.tree.ctx.copyDatabaseName` (复制数据库名)
  - `sql.toast.viewRowCount` (查看行数)
  - `sql.toast.viewConstraints` (查看约束)
  - `sql.toast.definitionFailed` (获取定义失败)
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`fix: add missing i18n keys for SQL console polish`
