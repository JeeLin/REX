# 0.57.0: 终端移动端浮动工具栏

## Context

0.56.0 完成了 SQL 控制台体验优化。PRODUCT.md 3.6 节定义了 SSH 终端的移动端浮动工具栏，包含方向键、功能键和字体缩放等移动端必需的交互控件，但目前尚未实现。

移动端用户无法使用物理键盘的方向键、Tab、Ctrl+C 等按键，浮动工具栏是移动端终端体验的关键缺失。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 实现 SSH 终端移动端浮动工具栏
- 第一行：方向键（↑↓←→）、Tab、Enter、^C、^L
- 第二行：历史记录、粘贴、字体缩放（A-/A+）、更多选项
- 仅在移动端显示（桌面端隐藏）

**不做什么：**
- 不修改后端 SSH 协议
- 不添加新的终端功能（仅添加移动端交互入口）
- 不改变桌面端终端行为

## 子任务详细设计

### 1 移动端浮动工具栏组件实现

- **功能目标**：创建 TerminalMobileToolbar 组件，提供移动端终端操作的浮动工具栏
- **文件结构**：
  - 创建 `packages/rex-console-web/src/features/terminal/TerminalMobileToolbar.vue`
- **功能点**：
  - 第一行方向键区：
    - ↑↓←→ 四个方向键（发送 ANSI 转义序列）
    - Tab 按钮（发送 `\t`）
    - Enter 按钮（发送 `\r`）
    - ^C 按钮（发送 `\x03`）
    - ^L 按钮（发送 `\x0c`）
  - 第二行功能按钮区：
    - 📜 历史 — 打开 bash 历史记录选择面板
    - 📋 粘贴 — 打开文本输入弹窗
    - A- / A+ — 终端字体缩放
    - ⚙ 更多 — 更多选项菜单
  - 组件 props：`terminal`（xterm Terminal 实例）、`visible`（是否显示）
  - 组件 emits：`openHistory`、`openPaste`、`fontSizeChange`
  - CSS：底部固定定位，半透明背景，按钮网格布局
  - 仅在 `window.innerWidth < 768` 或触摸设备时显示
- **交互设计**：
  - 方向键按下时发送对应的 ANSI 转义序列（如 `\x1b[A` 表示上箭头）
  - ↑↓ 同时用于 bash 历史记录切换（标准终端行为）
  - 按钮点击时添加视觉反馈（短暂高亮）
  - 长按方向键可连续发送（repeat）
- **测试标准**：
  - 组件渲染正确的按钮布局
  - 方向键发送正确的 ANSI 转义序列
  - ^C 发送 `\x03`
  - 响应式：窄屏显示，宽屏隐藏
  - `bun run type-check` 通过
- **提交信息**：`feat: add mobile floating toolbar for SSH terminal`

### 2 工具栏集成与 i18n

- **功能目标**：将浮动工具栏集成到 Terminal 页面，添加国际化支持
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/terminal/Terminal.vue`
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
- **功能点**：
  - 在 Terminal.vue 中引入 TerminalMobileToolbar
  - 传递 terminal 实例和 visible 状态
  - 实现历史记录面板（简单的 bash history 列表）
  - 实现粘贴文本弹窗（textarea 输入框 + 确认按钮）
  - 字体缩放：emit 事件到 Terminal.vue 处理 xterm fontSize 调整
  - 更多选项菜单：清屏、重连、断开连接等
  - i18n key：`terminal.mobile.history`、`terminal.mobile.paste`、`terminal.mobile.more`
- **测试标准**：
  - 移动端可见，桌面端隐藏
  - 历史记录面板正确显示
  - 粘贴弹窗正常工作
  - 字体缩放生效
  - `bun run type-check` 通过
- **提交信息**：`feat: integrate mobile toolbar with history and paste support`
