## 子任务详细设计

### 1 提取 MobileToolbar 共享组件

- **功能目标**：将 TerminalMobileToolbar、FileMobileToolbar、SqlMobileToolbar 的重复 CSS 和基础结构提取为共享组件
- **文件结构**：
  - 创建 `packages/rex-console-web/src/components/MobileToolbar.vue`（共享基础组件）
  - 修改 `packages/rex-console-web/src/features/terminal/TerminalMobileToolbar.vue`
  - 修改 `packages/rex-console-web/src/features/files/FileMobileToolbar.vue`
  - 修改 `packages/rex-console-web/src/features/sql/SqlMobileToolbar.vue`
- **功能点**：
  - MobileToolbar 提供：底部固定定位、半透明背景、toolbar-row、toolbar-btn、func-btn、btn-icon、btn-label、more-menu 等共享样式
  - 各业务组件保留自己的按钮布局和事件，使用 MobileToolbar 作为容器
  - Props：`visible`（boolean）
  - Slots：`default`（按钮内容）
- **测试标准**：
  - 三个现有工具栏的功能和测试不受影响
  - `bun run type-check` 通过
  - `bun run test` 通过
- **提交信息**：`refactor: extract shared MobileToolbar component`

### 2 Lint 警告清理

- **功能目标**：清理 39 个 Lint 警告，目标降至 0
- **文件结构**：
  - 修改多个前端文件（按 Lint 输出逐个修复）
- **功能点**：
  - 17 个可自动修复的警告：`bun run lint --fix`
  - 22 个手动修复的警告：
    - `@typescript-eslint/no-unused-vars`：移除未使用的变量/导入
    - `vue/attributes-order`：调整属性顺序
    - `vue/v-on-event-hyphenation`：事件名改为连字符格式
    - `vue/attribute-hyphenation`：属性名改为连字符格式
    - `vue/no-template-shadow`：重命名模板中的变量
    - `vue/require-default-prop`：添加默认值
    - `vue/multiline-html-element-content-newline`：调整换行
- **测试标准**：
  - `bun run lint` 0 errors, 0 warnings
  - `bun run type-check` 通过
- **提交信息**：`fix: resolve all lint warnings`

### 3 补充缺失的单元测试
