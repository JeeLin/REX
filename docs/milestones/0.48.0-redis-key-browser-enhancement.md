# 0.48.0: Redis 键浏览器增强

## Context

0.47.0 完成了 Redis 控制台基础 GUI：后端 TCP 连接器、平铺键列表、类型感知值查看器、DB 选择器、命令自动补全。

当前键浏览器为平铺列表，缺少 PRODUCT.md 3.5 规格中的树形结构、类型图标和右键菜单。本里程碑补齐这些差距。

版本类型：minor（新功能，向后兼容）

## 产品边界

**做什么：**
- 键列表按分隔符分组为可折叠树形结构
- 每个键显示 Redis 类型图标（`Aa`/`{}`/`[]`/`(~)`/`< >`）
- 键右键菜单（复制键名、查看值、删除键、设置 TTL）

**不做什么：**
- 不修改值查看器
- 不修改后端 WebSocket 协议
- 不实现键编辑功能
- 不修改产品文档

## 子任务详细设计

### 1 树形键列表（按分隔符分组）

- **功能目标**：将平铺键列表改为按 `:` 分隔符分组的可折叠树形结构
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/RedisKeyBrowser.vue`
- **交互设计**：
  - 键按第一个 `:` 分隔符分组为一级目录
  - 目录节点可折叠/展开，显示子键数量
  - 目录节点点击展开/折叠，叶子节点点击查看值
  - 默认全部展开
- **后端流程**：
  - 无变更，复用现有 SCAN 响应
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add tree view grouping to Redis key browser`

### 2 类型图标（SCAN 返回 TYPE）

- **功能目标**：每个键显示对应的 Redis 类型图标
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/RedisKeyBrowser.vue`
  - 修改 `crates/rex-hub/src/ws_redis.rs`（SCAN 响应增加类型字段）
- **交互设计**：
  - 类型图标替代当前 emoji：
    - String → `Aa`（绿色）
    - Hash → `{}`（橙色）
    - List → `[]`（蓝色）
    - Set → `(~)`（紫色）
    - ZSet → `< >`（粉色）
  - 图标显示在键名左侧
- **后端流程**：
  - SCAN 迭代中对每个键执行 TYPE 命令获取类型
  - 响应格式从 `Array(Bulk(key))` 改为 `Array(Array(Bulk(key), Bulk(type)))`
- **测试标准**：`bun run type-check && bun run lint` 通过；`cargo test -p rex-hub` 通过
- **提交信息**：`feat: add Redis key type icons to key browser`

### 3 键右键菜单

- **功能目标**：右键点击键显示上下文菜单
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/redis/RedisKeyBrowser.vue`
- **交互设计**：
  - 右键菜单项：
    - 复制键名
    - 查看值（等同左键点击）
    - 删除键（需确认）
    - 设置 TTL（弹出输入框）
  - 菜单样式复用项目现有右键菜单组件
- **后端流程**：
  - 删除键：发送 `DEL {key}` 命令
  - 设置 TTL：发送 `EXPIRE {key} {seconds}` 命令
- **测试标准**：`bun run type-check && bun run lint` 通过
- **提交信息**：`feat: add right-click context menu to Redis key browser`
