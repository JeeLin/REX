# 0.83.0: 前端 UI/UX 重新设计

## Context
0.82.0 完成了 Bug 修复与文件传输增强。本阶段将对前端进行 UI/UX 重新设计，提升用户体验和视觉一致性。

## 产品边界
本阶段做什么：
- 设计系统重构：统一设计语言、组件规范
- 页面布局优化：响应式设计、移动端适配
- 交互体验提升：动画、过渡、反馈
- 组件库完善：统一按钮、表单、表格样式

本阶段不做什么：
- 新功能开发
- 后端 API 变更
- 数据库 schema 变更

## 子任务详细设计

### 1 设计系统重构
- **目标**：建立统一的设计语言，提升视觉一致性
- **文件结构**：
  - 修改：`packages/rex-console-web/src/styles/variables.css`
  - 修改：`packages/rex-console-web/src/styles/base.css`
  - 新增：`packages/rex-console-web/src/styles/components.css`
- **设计规范**：
  - 颜色系统：主色、辅助色、语义色（成功、警告、错误、信息）
  - 间距系统：基于 4px 网格的间距规范
  - 排版系统：字体大小、行高、字重规范
  - 圆角系统：统一圆角值（sm: 4px, md: 6px, lg: 8px, xl: 12px）
  - 阴影系统：统一阴影层次（sm, md, lg, glow）
  - 动画系统：统一过渡时间（fast: 150ms, normal: 250ms, slow: 300ms）

### 2 页面布局优化
- **目标**：优化页面布局，提升响应式设计
- **文件结构**：
  - 修改：`packages/rex-console-web/src/layouts/AppLayout.vue`
  - 修改：`packages/rex-console-web/src/pages/*.vue`
- **优化内容**：
  - 侧边栏：可折叠、移动端抽屉式
  - 标签栏：滚动、溢出处理
  - 内容区：自适应布局
  - 移动端：底部导航、卡片式布局

### 3 交互体验提升
- **目标**：提升交互体验，增加动画和反馈
- **文件结构**：
  - 修改：`packages/rex-console-web/src/components/*.vue`
  - 修改：`packages/rex-console-web/src/pages/*.vue`
- **优化内容**：
  - 页面过渡：路由切换动画
  - 组件动画：按钮点击、表单提交、加载状态
  - 反馈机制：Toast 通知、确认对话框、错误处理
  - 快捷键：全局快捷键提示

### 4 组件库完善
- **目标**：完善组件库，统一组件样式
- **文件结构**：
  - 修改：`packages/rex-console-web/src/components/*.vue`

- **组件规范**：

  - 表单：input, select, checkbox, radio, switch

- 更新文档

## 设计核对点

依据 `AGENTS.md` 与产品文档，本阶段关键检查项：
- 设计令牌一致性：消除 phantom tokens（`--bg-secondary`/`--bg-tertiary`/`--border-primary` 未定义）、重复语义令牌（`--accent`/`--primary`、`--danger`/`--error`）
- 响应式断点完整性：移动端（<768px）、平板（768–1024px）、桌面（>1024px）三档覆盖
- 移动端 100vh 溢出：独立路由页（`/terminal`、`/files`、`/sql`）须用 `height: 100%` 而非 `100vh`，避免与底部导航栏重叠
- 交互一致性：模态框动画统一（进出场）、错误反馈不静默吞噬、Toast 通知统一
- 组件库规范：按钮/表单/表格/卡片/模态框样式统一
- 无障碍：焦点陷阱、Esc 关闭、reduced-motion 守卫
