## 子任务详细设计

### 1 后端 listProcedures API

- **功能目标**：新增 API 返回指定数据库的存储过程/函数列表
- **文件结构**：
  - 修改 `crates/rex-common/src/sql.rs`（新增 ProcedureInfo 类型）
  - 修改 `crates/rex-mysql/src/connector.rs`（MySQL 实现）
  - 修改 `crates/rex-postgresql/src/connector.rs`（PostgreSQL 实现）
  - 修改 `crates/rex-hub/src/sql.rs`（新增 API 端点）
  - 修改 `crates/rex-hub/src/routes.rs`（注册路由）
  - 修改 `packages/rex-console-web/src/api/sql.ts`（新增前端 API 调用）
- **接口设计**：
  - `GET /api/resources/:resource_id/sql/procedures?database={database}`
  - 返回：`{ procedures: [{ name: string, type: string }] }`
  - type: 'procedure' | 'function'
- **MySQL 实现**：`SHOW PROCEDURE STATUS WHERE Db = ?` 或查询 `information_schema.ROUTINES`
- **PostgreSQL 实现**：`SELECT routine_name, routine_type FROM information_schema.ROUTINES WHERE routine_schema = 'public'`
- **测试标准**：`cargo test` 通过
- **提交信息**：`feat: add list procedures API for SQL sidebar`

### 2 前端存储过程/函数节点渲染

- **功能目标**：在 SQL 侧边栏中显示存储过程/函数节点（与视图节点并列）
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/sql/SqlSidebar.vue`
  - 修改 `packages/rex-console-web/src/api/sql.ts`（添加 ProcedureInfo 类型）
- **交互设计**：
  - 侧边栏树形结构中，存储过程/函数节点显示在视图节点下方

  - 不支持展开（存储过程/函数无列信息）
- **测试标准**：`bun run type-check` 通过
- **提交信息**：`feat: add procedure nodes in SQL sidebar tree`

### 3 存储过程/函数右键菜单

- **功能目标**：存储过程/函数节点右键菜单支持查看定义、复制名称
- **文件结构**：

- **交互设计**：

- **测试标准**：`bun run type-check` 通过
- **提交信息**：`feat: add procedure context menu in SQL sidebar`

### 4 i18n 补全

- **功能目标**：补全存储过程/函数相关的 i18n 键
- **文件结构**：

- **i18n 键**：

- **测试标准**：`bun run type-check && bun run lint` 通过
