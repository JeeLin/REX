# 0.63.0: 设置页移动端优化

## Context

0.62.0 完成了审计日志移动端优化。设置页（PRODUCT.md 3.11）包含多个设置区块，每个区块有多行设置项。移动端需要优化内边距和布局。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 设置页布局移动端适配（减小内边距、全宽）
- 设置区块内设置行在复杂内容时垂直排列
- 更新区块移动端适配

**不做什么：**
- 不修改后端设置 API
- 不改变桌面端设置页行为

## 子任务详细设计

### 1 设置页布局移动端适配

- **功能目标**：优化设置页整体布局在移动端的显示
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/Settings.vue`
- **功能点**：
  - settings-layout 在移动端全宽（移除 max-width 限制或设为 100%）
  - settings-section 在移动端减小内边距
- **提交信息**：`feat: adapt settings page layout for mobile`

### 2 设置区块内容移动端适配

- **功能目标**：优化设置区块内设置行在移动端的布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/settings/ProfileSection.vue`
  - 修改 `packages/rex-console-web/src/features/settings/AppearanceSection.vue`
  - 修改 `packages/rex-console-web/src/features/settings/TerminalSection.vue`
  - 修改 `packages/rex-console-web/src/features/settings/SecuritySection.vue`
- **功能点**：
  - 所有 settings-section 共享移动端样式（通过全局 CSS 或各组件添加）
  - 设置行中的 toggle/select 在移动端全宽
  - 设置行中的按钮组在移动端垂直排列
- **提交信息**：`feat: adapt settings sections for mobile`

### 3 更新区块移动端适配

- **功能目标**：优化更新区块在移动端的显示
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/settings/UpdateSection.vue`
- **功能点**：
  - 版本总览列表在移动端紧凑显示
  - 更新按钮在移动端全宽
- **提交信息**：`feat: adapt update section for mobile`
