# 0.88.0: 前端 UI/UX 统一设计与更新状态完善

## Context

0.87.0 完成了 Agent 自动更新可靠性加固（重试/回滚/版本门禁）与部署守护（supervisor 模式）。但前端层面存在两个遗留缺口：

1. **Agent 更新状态展示不完整**：0.87.0 仅添加了 SHA256 指纹展示，但 `update_phase`（idle/downloading/replacing/rolled_back）、`update_error`、`auto_update` 开关等字段的前端展示被推迟。用户无法在设置页感知 Agent 更新的实时进度与结果。
2. **前端 UI/UX 不一致**：经过 0.83.0 设计系统重构后，后续里程碑（0.84.0–0.87.0）持续新增功能但未统一视觉风格。各页面的组件样式、间距、颜色使用存在差异，需要一次集中的 UI/UX 统一打磨。
3. **i18n 缺失**：部分新增功能（Agent 更新状态、Redis 批量操作等）缺少中文/英文翻译条目。

本里程碑聚焦：**补齐 Agent 更新状态的前端完整展示、统一全站 UI/UX 风格、补全 i18n 翻译**。

版本类型：minor（前端增强 + UI 统一 + i18n 补全，向后兼容），版本号 0.88.0。

## 产品边界

**做什么：**
- Agent 更新状态完整展示：后端 `AgentVersionInfo` 补充 `update_phase`/`update_error`/`auto_update` 字段；前端展示更新中/已回滚/版本不一致动画与文案、`auto_update` 开关徽章
- UI/UX 统一：组件风格对齐（按钮、徽章、卡片、表格）、间距规范、颜色一致性
- i18n 补全：新增功能的中英文翻译条目
- 前端代码质量：消除 unused imports、修复 TypeScript 类型问题

- 不实现新的后端业务功能（仅补充现有 API 的状态字段）
- 不改动更新机制的核心逻辑（0.87.0 已完成）
- 不涉及多用户/RBAC/企业协作（AGENTS.md 硬性约束）

## 子任务详细设计

### 1 Agent 更新状态前端展示

- **功能目标**：在设置页版本总览中完整呈现 Agent 自动更新的实时状态，让用户感知更新进度与结果。
- **文件结构**：
  - 修改：`crates/rex-hub/src/update.rs`（`AgentVersionInfo` struct 补充 `update_phase`/`update_error`/`auto_update` 字段；`list_agent_versions` 查询补充对应数据）
  - 修改：`packages/rex-console-web/src/api/update.ts`（前端 `AgentVersionInfo` 新增对应字段）
  - 修改：`packages/rex-console-web/src/features/settings/UpdateSection.vue`（Agent 版本行展示：更新中/已回滚/版本不一致；`auto_update` 开关状态徽章）
  - 修改：`packages/rex-console-web/src/api/agent.ts`（Agent config 已含 `auto_update`，补充状态读取）
  - 修改：`packages/rex-console-web/src/i18n/{en,zh}.ts`（新增 `settings.update.agentUpdating`、`agentRolledBack`、`agentVersionMismatch`、`autoUpdateOn/Off` 等）
- **接口设计**：复用 `GET /api/update/agents`；`AgentVersionInfo` 新增 `update_phase: 'idle'|'downloading'|'replacing'|'rolled_back'|'mismatch' | null`。
- **交互设计**：
  - Agent 版本列表中，在线且 `needs_update` 时显示「更新中」动画（旋转图标）
  - `rolled_back` 显示红色「已回滚」徽章
  - `mismatch` 显示「版本不一致，请同步 Hub」提示
- **测试标准**：`bun run type-check` / `lint` / `build` 通过
- **提交信息**：`feat: surface agent auto-update status and auto_update toggle in UI`

### 2 UI/UX 统一打磨

- **功能目标**：统一全站组件风格、间距、颜色使用，消除视觉不一致。
- **文件结构**：
  - 修改：`packages/rex-console-web/src/styles/`（design tokens 微调）
  - 修改：`packages/rex-console-web/src/components/`（统一组件样式）
  - 修改：各页面 `.vue` 文件（间距、颜色统一）
- **设计原则**：
  - 按钮：主操作 = 橙色实心，次操作 = 灰色边框，危险 = 红色
  - 徽章：在线=绿色，离线=灰色，警告=橙色，错误=红色
  - 卡片：统一 border-radius、padding、shadow
  - 表格：统一行高、hover 效果、边框样式
  - 间距：使用 design token 中的 spacing scale
- **测试标准**：`bun run type-check` / `lint` / `build` 通过；视觉回归检查（手动）
- **提交信息**：`style: unify UI components and spacing across all pages`

### 3 i18n 翻译补全

- **功能目标**：补全所有新增功能的中英文翻译条目。
- **文件结构**：

- **测试标准**：`bun run type-check` / `lint` / `build` 通过
