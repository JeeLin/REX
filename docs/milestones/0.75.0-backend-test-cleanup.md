# 0.75.0: 后端测试与代码清理

## Context

0.74.0 完成了前端代码质量与测试覆盖（6 个新测试文件，234 个前端测试用例）。当前前端测试覆盖良好，但后端 Rust crate 部分模块缺少单元测试。同时，代码中存在一些未使用的导入和重复模式需要清理。

版本类型：patch（质量改进，无新功能）

## 产品边界

**做什么：**
- 补充后端 Rust crate 未覆盖模块的单元测试（rex-hub/ws_agent.rs、rex-transfer/executor.rs、rex-ssh/auth.rs）
- 补充边缘情况测试和错误处理路径测试
- 代码清理（未使用导入、重复模式、函数长度优化）

**不做什么：**
- 不添加新功能
- 不修改前端代码（0.74.0 已完成前端清理）
- 不改变用户可见行为
- 不引入新的外部依赖

## 子任务详细设计

### 1 补充后端模块测试

- **功能目标**：为缺少测试的后端模块补充单元测试
- **文件结构**：
  - 创建/修改 `crates/rex-hub/src/ws_agent.rs` 内测试模块
  - 创建/修改 `crates/rex-transfer/src/executor.rs` 内测试模块
  - 创建/修改 `crates/rex-ssh/src/auth.rs` 内测试模块
- **测试标准**：
  - 每个模块至少 3 个测试用例
  - 覆盖核心逻辑和主要分支
  - 所有测试通过
- **提交信息**：`test: add unit tests for ws_agent, executor, and auth modules`

### 2 补充边缘情况与错误处理测试

- **功能目标**：补充已有测试模块的边缘情况和错误处理路径测试
- **文件结构**：
  - 修改现有测试文件，添加边缘情况用例
- **检查维度**：
  - 空输入/无效输入处理
  - 错误路径覆盖
  - 并发安全测试（如适用）
  - 序列化/反序列化边界
- **测试标准**：
  - 新增测试覆盖至少 5 个边缘情况
  - 所有测试通过
- **提交信息**：`test: add edge case and error handling tests`

### 3 代码清理

- **功能目标**：清理后端代码中的不规范写法
- **文件结构**：
  - 修改 `crates/` 下相关文件
- **检查维度**：
  - 未使用的导入和变量（`cargo clippy` warning）
  - 重复的错误处理模式
  - 过长的函数（>50 行考虑拆分）
  - 不一致的命名风格
- **测试标准**：
  - `cargo clippy --workspace --all-targets` 无 warning
  - `cargo test --workspace` 全部通过
  - `cargo fmt --check` 通过
- **提交信息**：`refactor: clean up code duplicates and unused imports`
