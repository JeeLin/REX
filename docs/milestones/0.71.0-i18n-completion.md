# 0.71.0: 国际化完善

## Context

0.70.0 完成了安全加固与错误处理。项目所有核心功能已实现，前端 i18n 覆盖率约 95%，但仍有少量硬编码中文字符串遗留。本里程碑补全 i18n 覆盖，确保切换语言时所有用户可见文本正确翻译。

版本类型：minor（完善现有功能）

## 子任务详细设计

### 1 i18n 基础设施

- **功能目标**：创建可在 Vue 组件外使用的 i18n 实例，解决 `api/client.ts` 等模块级代码无法使用 `useI18n()` 的问题
- **文件结构**：
  - 新建 `src/i18n/index.ts`（导出 i18n 实例和 `t()` 辅助函数）
  - 修改 `src/main.ts`（使用新的 i18n 实例）
- **接口设计**：
  - `export const i18n` — vue-i18n 实例，供 Vue 插件使用
  - `export function t(key: string, params?: Record<string, any>): string` — 独立的翻译函数，读取当前语言设置并返回翻译
- **实现方案**：
  - 创建 i18n 实例，配置 zh/en 两种语言
  - 导出 `t()` 函数，内部读取 `localStorage('rex-lang')` 获取当前语言
  - 语言切换时更新 i18n 实例的 locale
- **测试标准**：
  - `t()` 函数在不同语言设置下返回正确翻译
  - 参数插值正常工作（如 `t('sql.rows', { count: 10 })`）
- **提交信息**：`feat: create standalone i18n instance for non-Vue modules`

### 2 修复 api/client.ts 硬编码中文

- **功能目标**：将错误拦截器中的 4 处硬编码中文替换为 i18n 翻译
- **文件结构**：
  - 修改 `src/api/client.ts`（导入 `t()` 替换硬编码）
  - 修改 `src/i18n/zh.ts`（添加 api 错误消息键）
  - 修改 `src/i18n/en.ts`（添加对应英文翻译）
- **接口设计**：
  - 新增 i18n 键：
    - `api.error.rateLimit` — `'操作过于频繁，请稍后重试'` / `'Too many requests. Please try again later.'`
    - `api.error.serverError` — `'服务器错误（{status}），请稍后重试'` / `'Server error ({status}). Please try again later.'`
    - `api.error.timeout` — `'请求超时，请稍后重试'` / `'Request timed out. Please try again later.'`
    - `api.error.network` — `'网络连接失败，请检查网络'` / `'Network connection failed. Please check your network.'`
- **实现细节**：
  - 在 `client.ts` 顶部导入 `import { t } from '@/i18n'`
  - 替换硬编码字符串为 `t('api.error.rateLimit')` 等
  - 保持 401 跳转逻辑不变（无用户可见文本）
- **测试标准**：
  - client.ts 无硬编码中文
  - i18n 文件包含所有 api.error.* 键
- **提交信息**：`fix: internationalize API error messages in client.ts`
