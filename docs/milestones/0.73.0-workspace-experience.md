# 0.73.0: 工作空间体验增强

## Context

0.72.0 完成了前端性能优化和可访问性改进。当前工作空间支持多标签、分屏布局、面板拖拽等核心功能，但布局偏好不持久化，刷新页面后状态丢失，标签操作效率有提升空间。

本里程碑聚焦于提升工作空间的使用效率和个性化能力。

版本类型：minor（完善现有功能）

## 产品边界

**做什么：**
- 工作空间布局持久化（记住用户的布局偏好）
- 标签操作增强（批量关闭、快速切换）
- 快捷键系统完善（自定义快捷键、快捷键面板优化）
- 工作空间状态恢复（刷新页面后恢复已打开的标签和布局）

**不做什么：**
- 不添加新的协议支持
- 不修改后端 API
- 不引入新的外部依赖
- 不改变现有用户可见的核心工作流

## 子任务详细设计

### 1 工作空间布局持久化

- **功能目标**：记住用户的分屏布局偏好，刷新页面或重新打开工作空间时恢复上次的布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/useLayout.ts`
  - 修改 `packages/rex-console-web/src/stores/workspace.ts`
- **功能点**：
  - **布局保存**：布局切换时自动保存到 localStorage（key: `rex-workspace-layout`），包含当前布局模式和各面板尺寸
  - **布局恢复**：工作空间初始化时从 localStorage 读取上次布局
  - **面板尺寸记忆**：拖拽分割线调整面板大小后，尺寸也持久化
  - **默认布局**：首次访问使用单面板布局
- **测试标准**：
  - 切换布局后刷新页面，布局保持一致
  - 调整面板尺寸后刷新，尺寸保持
  - 清除 localStorage 后恢复默认布局
- **提交信息**：`feat: persist workspace layout preference`

### 2 标签操作增强

- **功能目标**：提升标签管理效率，支持批量操作和快速切换
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/TabBar.vue`
  - 修改 `packages/rex-console-web/src/features/workspace/useTabs.ts`
  - 修改 `packages/rex-console-web/src/components/ContextMenu.vue`（如需）
- **功能点**：
  - **批量关闭**：已有的右键菜单"关闭其他"/"关闭全部"功能增强，支持多选标签关闭
  - **快速切换菜单**：Ctrl+Tab 或 Ctrl+Shift+Tab 弹出标签列表，快速切换（类似 IDE 的 Ctrl+Tab 行为）
  - **标签位置记忆**：记住每个标签在分屏布局中的位置
  - **新标签默认位置**：新标签在当前活动面板打开，而非总是第一个面板
- **测试标准**：
  - 右键菜单批量操作正确执行
  - Ctrl+Tab 弹出标签列表并可切换
  - 新标签在正确位置打开
- **提交信息**：`feat: enhance tab operations with batch close and quick switch`

### 3 快捷键系统完善

- **功能目标**：完善快捷键系统，支持自定义快捷键和更好的快捷键面板
- **文件结构**：
  - 修改 `packages/rex-console-web/src/composables/useKeyboardShortcuts.ts`
  - 修改 `packages/rex-console-web/src/features/workspace/ShortcutHelpModal.vue`
  - 修改 `packages/rex-console-web/src/stores/settings.ts`（如需）
- **功能点**：
  - **快捷键面板优化**：F1 快捷键面板分类显示，支持搜索，显示当前绑定的快捷键
  - **快捷键冲突检测**：检测并提示快捷键冲突
  - **常用操作快捷键补充**：
    - `Ctrl+Shift+D`：复制当前标签
    - `Ctrl+Shift+W`：关闭其他标签
    - `Ctrl+\`：切换侧边栏
  - **快捷键提示**：悬停按钮时显示对应快捷键
- **测试标准**：
  - F1 面板正确显示所有快捷键
  - 新增快捷键可正常触发
  - 快捷键冲突被正确检测
- **提交信息**：`feat: improve keyboard shortcuts with search and conflict detection`

### 4 工作空间状态恢复

- **功能目标**：刷新页面或重新打开工作空间后，恢复之前打开的标签和连接状态
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/useTabs.ts`
  - 修改 `packages/rex-console-web/src/features/workspace/useWorkspace.ts`
  - 创建 `packages/rex-console-web/src/composables/useWorkspacePersistence.ts`
- **功能点**：
  - **标签状态保存**：工作空间状态变化时（打开/关闭标签、切换布局）自动保存到 localStorage
  - **标签恢复**：刷新页面后自动重新打开之前打开的标签（资源 ID + 协议类型）
  - **连接恢复**：标签恢复后自动尝试重新连接
  - **状态过期**：超过 24 小时的状态自动清除
  - **手动清除**：提供"清除工作空间状态"选项
- **测试标准**：
  - 打开多个标签后刷新，标签全部恢复
  - 恢复后自动发起连接
  - 超过 24 小时的状态自动清除
- **提交信息**：`feat: restore workspace state after page refresh`
