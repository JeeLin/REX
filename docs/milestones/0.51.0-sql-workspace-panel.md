# 0.51.0: SQL 工作空间面板增强

## Context

0.50.0 完成了前端测试覆盖提升。当前工作空间中的 SQL 面板是简化版本，缺少保存查询、格式化、历史记录等功能。完整 SQL 控制台页面（sql.html）功能齐全，但工作空间面板（app.html）中的 SQL 面板功能不完整，影响多标签工作流体验。

本里程碑将工作空间 SQL 面板的功能补全到与完整 SQL 控制台相当的水平。

版本类型：minor（新功能）

## 产品边界

**做什么：**
- SQL 工作空间面板保存查询文件功能
- SQL 格式化按钮和快捷键支持
- SQL 历史记录面板集成
- 结果区复制和导出功能
- 右键菜单功能完善

**不做什么：**
- 不修改完整 SQL 控制台页面
- 不修改后端 API
- 不添加新的数据库协议支持

## 子任务详细设计

### 1 SQL 工作空间面板保存和格式化功能

- **功能目标**：在工作空间 SQL 面板中实现保存查询文件和 SQL 格式化功能
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceSql.vue`
  - 修改 `packages/rex-console-web/src/features/sql/SqlEditor.vue`
- **功能点**：
  - 添加保存按钮（💾），支持保存当前查询为 .sql 文件
  - 添加格式化按钮（✨），调用 SQL 格式化功能
  - 保存时弹出文件名输入对话框
  - 保存成功后显示 Toast 提示
- **交互设计**：
  - 保存按钮点击后弹出模态框，输入文件名
  - 格式化按钮点击后直接格式化编辑器内容
  - 保存状态在标签名上显示（已保存/未保存）
- **提交信息**：`feat: add save and format to SQL workspace panel`

### 2 SQL 工作空间快捷键和右键菜单

- **功能目标**：为工作空间 SQL 面板添加快捷键和右键菜单支持
- **文件结构**：
  - 修改 `packages/rex-console-web/src/features/workspace/panels/WorkspaceSql.vue`
- **功能点**：
  - `Ctrl+S` 保存查询
  - `Ctrl+Shift+F` 格式化 SQL
  - 编辑器右键菜单（执行、格式化、剪切、复制、粘贴）
  - 结果表格右键菜单（复制行、导出）
- **交互设计**：
  - 快捷键在工具栏显示提示
  - 右键菜单与完整 SQL 控制台一致
- **提交信息**：`feat: add keyboard shortcuts and context menu to SQL workspace panel`

### 3 SQL 工作空间 i18n 和测试

- **功能目标**：补充国际化文本并添加单元测试
- **文件结构**：
  - 修改 `packages/rex-console-web/src/i18n/zh.ts`
  - 修改 `packages/rex-console-web/src/i18n/en.ts`
  - 新增 `packages/rex-console-web/src/features/workspace/__tests__/WorkspaceSql.test.ts`
- **功能点**：
  - 补充所有新增按钮和菜单的 i18n 文本
  - 为保存、格式化、快捷键功能编写单元测试
- **测试标准**：`bun run test` 通过
- **提交信息**：`test: add unit tests for SQL workspace panel`
