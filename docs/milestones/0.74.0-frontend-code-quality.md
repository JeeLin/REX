# 0.74.0: 前端代码质量与测试覆盖

## Context

0.73.0 完成了工作空间体验增强（布局持久化、状态恢复、快捷键完善）。当前前端有 127 个源文件，但仅 26 个测试文件，大量组件和 composable 缺少单元测试。部分组件存在重复模式和未使用的导入。

本里程碑聚焦于提升前端代码质量和测试覆盖率，不引入新功能。

版本类型：patch（质量改进，无新功能）

## 产品边界

**做什么：**
- 补充缺失的组件单元测试（TabBar、ContextMenu、ConfirmDialog、AppLayout 等）
- 补充缺失的 composable 单元测试（useWorkspacePersistence、useSidebar、useGlobalQuery 等）
- 代码精简（提取重复模式、清理未使用导入、统一错误处理）

**不做什么：**
- 不添加新功能
- 不修改后端代码
- 不改变用户可见行为
- 不引入新的外部依赖

## 子任务详细设计

### 1 补充组件测试

- **功能目标**：为核心组件补充单元测试，提升测试覆盖率
- **文件结构**：
  - 创建 `packages/rex-console-web/src/features/workspace/__tests__/TabBar.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/ContextMenu.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/ConfirmDialog.test.ts`
  - 创建 `packages/rex-console-web/src/layouts/__tests__/AppLayout.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/CommandPalette.test.ts`
  - 创建 `packages/rex-console-web/src/components/__tests__/GlobalQueryModal.test.ts`
- **测试标准**：
  - 每个组件至少 5 个测试用例
  - 覆盖渲染、交互、props 响应、边界情况
  - 所有测试通过
- **提交信息**：`test: add unit tests for core components`

### 2 补充 composable 测试

- **功能目标**：为关键 composable 补充单元测试
- **文件结构**：
  - 创建 `packages/rex-console-web/src/composables/__tests__/useWorkspacePersistence.test.ts`
  - 创建 `packages/rex-console-web/src/composables/__tests__/useSidebar.test.ts`
  - 创建 `packages/rex-console-web/src/composables/__tests__/useGlobalQuery.test.ts`
  - 创建 `packages/rex-console-web/src/composables/__tests__/useNetworkStatus.test.ts`
  - 创建 `packages/rex-console-web/src/composables/__tests__/useContextMenu.test.ts`
- **测试标准**：
  - 每个 composable 至少 4 个测试用例
  - 覆盖核心逻辑、边界情况、错误处理
  - 所有测试通过
- **提交信息**：`test: add unit tests for composables`

### 3 代码精简

- **功能目标**：清理代码重复和不规范写法
- **文件结构**：
  - 修改 `packages/rex-console-web/src/` 下相关文件
- **检查维度**：
  - 未使用的导入和变量
  - 重复的 CSS 类或工具函数
  - 不一致的错误处理模式
  - 过长的函数（>50 行考虑拆分）
- **测试标准**：
  - 精简后所有测试仍然通过
  - `bun run lint` 无 error
  - `bun run type-check` 无 error
- **提交信息**：`refactor: clean up code duplicates and unused imports`
