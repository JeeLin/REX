# 0.79.0: Redis 操作界面增强

## Context
0.78.0 完成了交互式 Notebook 功能，支持 block-based 富文本编辑、命令块绑定资源执行、结果内联展示和导入/导出。本阶段将增强 Redis 操作界面，参考 Another Redis Desktop Manager 的设计理念，提供更强大的 Redis 数据管理能力。

## 产品边界
本阶段做什么：
- Redis 数据类型可视化查看器（Hash/Set/List/ZSet/Stream）
- 批量操作支持（批量删除、批量修改 TTL、批量导入/导出）
- 实时监控面板（内存使用、Key 统计、连接数、命令统计）
- 高级搜索与过滤（按 pattern 搜索、按类型过滤、按 TTL 过滤）

本阶段不做什么：
- Redis 集群管理
- Redis 发布/订阅功能
- Redis 脚本执行（Lua）

## 子任务详细设计

### 1 前端：Redis 数据类型可视化

- **功能目标**：为 Hash/Set/List/ZSet/Stream 五种数据类型提供专用查看器，支持直观的数据浏览和编辑
- **文件结构**：
  - 修改：`packages/rex-console-web/src/features/redis/RedisConsole.vue`
  - 修改：`packages/rex-console-web/src/features/redis/RedisValueViewer.vue`
  - 新增：`packages/rex-console-web/src/features/redis/types/HashViewer.vue`
  - 新增：`packages/rex-console-web/src/features/redis/types/SetViewer.vue`
  - 新增：`packages/rex-console-web/src/features/redis/types/ListViewer.vue`
  - 新增：`packages/rex-console-web/src/features/redis/types/SortedSetViewer.vue`
  - 新增：`packages/rex-console-web/src/features/redis/types/StreamViewer.vue`
- **接口设计**：
  - HashViewer: `{ key: string, data: Record<string, string> }`
  - SetViewer: `{ key: string, data: string[] }`
  - ListViewer: `{ key: string, data: string[] }`
  - SortedSetViewer: `{ key: string, data: Array<{ score: number, value: string }> }`
  - StreamViewer: `{ key: string, data: Array<{ id: string, fields: Record<string, string> }> }`
- **交互设计**：
  - 点击 Key 后根据类型自动选择对应的 Viewer
  - Hash: 表格显示 field/value，支持行内编辑
  - Set: 列表显示成员，支持添加/删除成员
  - List: 列表显示元素，支持头部/尾部插入
  - ZSet: 表格显示 score/value，支持修改 score
  - Stream: 表格显示消息 ID 和字段
- **测试标准**：
  - 每种数据类型的 Viewer 能正确渲染数据
  - 编辑操作能正确调用 Redis 命令
- **提交信息**：`feat(redis): add data type visualizers for Hash/Set/List/ZSet/Stream`

### 2 前端：批量操作支持

- **功能目标**：支持对多个 Key 进行批量操作，提升管理效率
- **文件结构**：
  - 修改：`packages/rex-console-web/src/features/redis/RedisKeyBrowser.vue`
  - 新增：`packages/rex-console-web/src/features/redis/BatchOperationDialog.vue`
- **接口设计**：
  - BatchOperationDialog: `{ keys: string[], operation: 'delete' | 'ttl' | 'export', onComplete: () => void }`
- **交互设计**：
  - Key 列表支持多选（复选框）
  - 选中多个 Key 后显示批量操作按钮
  - 批量删除：确认对话框，显示将删除的 Key 数量
  - 批量修改 TTL：输入框设置统一的 TTL 值
  - 批量导出：选择导出格式（JSON/CSV），下载文件
- **测试标准**：
  - 多选功能正常工作
  - 批量删除能正确执行并更新列表
  - 批量 TTL 修改能正确应用
  - 批量导出能生成正确的文件
- **提交信息**：`feat(redis): add batch operations for multiple keys`

### 3 前端：实时监控面板

- **功能目标**：提供 Redis 服务器实时状态监控，帮助用户了解资源使用情况
- **文件结构**：
  - 新增：`packages/rex-console-web/src/features/redis/RedisMonitor.vue`
- **接口设计**：
  - RedisMonitor: `{ refreshInterval?: number }`
  - 数据结构：`{ memory: { used, peak,碎片率 }, keys: { total, byType }, connections: { active, blocked }, commands: { total, perSecond } }`
- **交互设计**：
  - 顶部显示 4 个统计卡片：内存使用、Key 总数、连接数、命令/秒
  - 内存使用显示进度条和百分比
  - Key 统计显示各类型分布饼图
  - 自动刷新（可配置间隔，默认 5 秒）
- **测试标准**：
  - 监控面板能正确显示 Redis INFO 信息
  - 自动刷新功能正常
  - 数据格式化显示正确
- **提交信息**：`feat(redis): add real-time monitoring panel`

### 4 前端：高级搜索与过滤

- **功能目标**：提供强大的 Key 搜索和过滤能力，快速定位目标数据
- **文件结构**：
  - 修改：`packages/rex-console-web/src/features/redis/RedisKeyBrowser.vue`
  - 新增：`packages/rex-console-web/src/features/redis/SearchFilter.vue`
- **接口设计**：
  - SearchFilter: `{ onSearch: (filter: KeyFilter) => void }`
  - KeyFilter: `{ pattern?: string, type?: string, ttlRange?: { min?: number, max?: number } }`
- **交互设计**：
  - 搜索框支持 Redis pattern 语法（*、?、[]）
  - 类型过滤下拉框：String/Hash/Set/List/ZSet/Stream
  - TTL 过滤：最小值和最大值输入框
  - 搜索结果实时更新 Key 列表
- **测试标准**：
  - Pattern 搜索能正确过滤 Key
  - 类型过滤能正确显示对应类型的 Key
  - TTL 过滤能正确筛选
  - 组合过滤条件能正确工作
- **提交信息**：`feat(redis): add advanced search and filter for keys`
