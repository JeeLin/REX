# 0.69.0: 后端测试覆盖提升

## Context

0.68.0 完成了前端测试覆盖提升（26 个测试文件，194 个测试）。目前 Rust 后端已有约 493 个测试分布在各 crate 中（rex-common 55、rex-redis 38、rex-sqlite 17、rex-mysql 10、rex-postgresql 12、rex-transfer 38、rex-ssh 8、rex-s3 18、rex-hub 271、rex-agent 26），但部分 crate 的关键路径仍缺少测试覆盖。本里程碑补齐这些测试，提升代码质量和可维护性。

版本类型：minor（无新功能，纯测试补充）

## 产品边界

**做什么：**
- 补充 rex-common 中缺失的序列化和边界测试（ViewInfo、ProcedureInfo、CLI TLS flags、版本号边缘情况）
- 补充 rex-sqlite/rx-mysql/rx-postgresql 协议连接器的配置序列化往返测试和纯逻辑函数测试
- 补充 rex-transfer 传输引擎的边缘情况测试（TransferManager 状态转换、executor 错误路径）
- 补充 rex-redis 的 RESP 编解码器边缘情况测试

**不做什么：**
- 不修改生产代码逻辑
- 不添加需要外部服务的集成测试（MySQL、PostgreSQL、Redis 服务器）
- 不引入新的 dev-dependencies（如 HTTP mock 框架）
- 不做 SFTP 连接器测试（需要 SSH 服务器）

## 子任务详细设计

### 1 通用 crate 测试（rex-common）

- **功能目标**：补充 rex-common 中缺失的序列化和边界测试
- **文件结构**：
  - 修改 `crates/rex-common/src/sql.rs`（添加 ViewInfo/ProcedureInfo 序列化测试）
  - 修改 `crates/rex-common/src/cli.rs`（添加 TLS/ACME flags 解析测试）
  - 修改 `crates/rex-common/src/version.rs`（添加 pre-release 版本号测试、VersionInfo 序列化测试）
  - 修改 `crates/rex-common/src/update_state.rs`（添加所有 UpdatePhase 变体序列化测试）
- **测试内容**：
  - ViewInfo 序列化往返测试
  - ProcedureInfo 序列化往返测试
  - CLI 全部 flags 组合解析测试（--tls-cert、--tls-key、--ca-cert、--insecure、--acme-http-port）
  - is_newer 对 pre-release 版本的处理（如 0.1.0-alpha）
  - VersionInfo Serialize/Deserialize 往返测试
  - 所有 UpdatePhase 变体的序列化往返测试
- **测试标准**：所有新增测试通过 `cargo test -p rex-common`
- **提交信息**：`test: add missing serialization and edge case tests for rex-common`

### 2 协议连接器测试

- **功能目标**：补充协议连接器 crate 的配置序列化和纯逻辑函数测试
- **文件结构**：
  - 修改 `crates/rex-sqlite/src/connector.rs`（添加配置序列化往返、表名验证边界测试）
  - 修改 `crates/rex-mysql/src/connector.rs`（添加配置序列化往返测试、SQL 转义逻辑测试）
  - 修改 `crates/rex-postgresql/src/connector.rs`（添加配置序列化往返测试、EXPLAIN 计划嵌套深度测试）
  - 修改 `crates/rex-redis/src/resp.rs`（添加 RESP 编解码器往返测试、零长度 bulk string 边界测试、RespError Display 测试）
- **测试内容**：
  - SqliteConfig 序列化往返测试
  - MySqlConfig 序列化往返测试
  - PostgresConfig 序列化往返测试
  - RedisConfig 序列化往返测试
  - extract_pg_plan_node 深层嵌套（3+ 层）和缺失字段边界测试
  - RespDecoder + RespEncoder 编解码往返测试
  - 零长度 bulk string 解码测试
  - RespError Display 格式化测试
  - 表名验证边界测试（空字符串、特殊字符、SQL 注入尝试）
- **测试标准**：所有新增测试通过对应 crate 的 `cargo test -p <crate>`
- **提交信息**：`test: add config serialization and edge case tests for protocol connectors`

### 3 传输引擎测试

- **功能目标**：补充 rex-transfer 传输引擎的边缘情况和错误路径测试
- **文件结构**：
  - 修改 `crates/rex-transfer/src/task.rs`（添加 TransferManager 边缘情况测试）
  - 修改 `crates/rex-transfer/src/executor.rs`（添加 executor 错误路径测试）
  - 修改 `crates/rex-transfer/src/local.rs`（添加 LocalConnector 边界测试）
- **测试内容**：
  - TransferManager.set_status 对不存在的任务返回错误
  - TransferManager.set_progress 对不存在的任务返回错误
  - TransferManager.cancel_task 从 Running 状态取消
  - TransferProgress.percent() 100% 和边界值测试
  - execute_transfer 当 set_status(Running) 失败时的早期返回
  - do_transfer total=0 时的进度更新逻辑
  - LocalConnector::new 传入文件（非目录）时的错误
  - LocalConnector resolve 当父目录不存在时的错误
- **测试标准**：所有新增测试通过 `cargo test -p rex-transfer`
- **提交信息**：`test: add edge case and error path tests for transfer engine`
