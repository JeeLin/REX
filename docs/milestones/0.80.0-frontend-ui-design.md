# 0.80.0: 前端界面设计与优化

## Context

0.79.0 完成了 Redis 操作界面增强（5 类型可视化、批量操作、监控面板、搜索过滤）。本里程碑转向前端整体视觉和交互质量提升。

审计发现当前前端存在：
- GlobalQueryModal 引用 9 个未定义 CSS 变量，light 主题渲染异常
- AppLayout 使用未定义的 `--transition-normal`，侧边栏动画失效
- AgentCard 重新定义全局类，样式重复 60+ 行
- 弹窗（GlobalQueryModal、ResourceEditModal 等）无过渡动画
- CodeMirror/xterm.js 硬编码暗色，light 主题不可读
- AGENTS.md 记录的 3 个前端 UI bug 未修复（快捷键展示异常、分屏拖拽不可用、SSH Ctrl+C/V 冲突）

版本类型：minor（新功能 + 质量提升）

## 子任务详细设计

### 1 CSS 变量修复与设计 token 补齐

- **功能目标**：修复 GlobalQueryModal 和 AppLayout 中的无效 CSS 变量引用，补齐缺失的 design token
- **文件结构**（创建/修改哪些文件）
  - 修改：`packages/rex-console-web/src/styles/variables.css` — 补齐缺失变量
  - 修改：`packages/rex-console-web/src/components/GlobalQueryModal.vue` — 替换为正确变量
  - 修改：`packages/rex-console-web/src/layouts/AppLayout.vue` — 替换 `--transition-normal`
- **接口设计**（组件 props / 数据模型）
  - 新增 CSS 变量：
    - `--bg-panel`：面板背景色（dark: #1C2128, light: #F6F8FA）
    - `--bg-header`：头部背景色（dark: #161B22, light: #FFFFFF）
    - `--bg-input`：输入框背景色（dark: #0D1117, light: #F6F8FA）
    - `--bg-muted`：弱化背景色（dark: #21262D, light: #F3F4F6）
    - `--border-hover`：悬停边框色（dark: #484F58, light: #D0D7DE）
    - `--transition-normal`：250ms ease（fast=150ms 和 base=200ms 之间）
  - 修复 GlobalQueryModal 中 9 个未定义变量：`--bg-panel`→`--bg-elevated`，`--bg-header`→`--bg-surface`，`--primary`→`--accent`，`--primary-dark`→`--accent-hover`，`--bg-input`→`--bg-deep`，`--bg-muted`→`--bg-hover`，`--error`→`--danger`，`--border-hover`→新增变量
- **交互设计**：无 UI 变化，仅变量映射修正
- **后端流程**：无
- **测试标准**：dark/light 主题切换后 GlobalQueryModal 和侧边栏动画正常
- **提交信息**：`fix(css): repair undefined CSS variables and add missing design tokens`

### 2 Light 主题适配（CodeMirror + xterm.js）

- **功能目标**：CodeMirror SQL 编辑器和 xterm.js 终端在 light 主题下正确渲染
- **文件结构**（创建/修改哪些文件）
  - 修改：`packages/rex-console-web/src/features/workspace/WorkspaceSql.vue`（或 SqlConsole.vue）— CodeMirror 主题动态切换
  - 修改：`packages/rex-console-web/src/features/workspace/WorkspaceTerminal.vue` — xterm theme 动态切换
  - 修改：`packages/rex-console-web/src/pages/Terminal.vue` — 同上
- **接口设计**
  - CodeMirror：监听 `data-theme` 属性变化，切换 `@codemirror/theme-one-dark` ↔ light 等效主题
  - xterm.js：根据主题切换 theme 配置 `{ background, foreground, cursor, selection }` 预设
- **交互设计**
  - 切换主题后，编辑器和终端立即响应，无需刷新
  - 终端保持光标闪烁、选区高亮等行为一致
- **后端流程**：无
- **测试标准**：dark→light→dark 切换后，SQL 编辑器可读（文字清晰），终端可读（文字清晰）
- **提交信息**：`fix(theme): dynamic CodeMirror/xterm theme switching for light mode`

### 4 弹窗过渡动画补齐

- **功能目标**：为 GlobalQueryModal、ResourceEditModal、EnvironmentEditModal 等添加打开/关闭过渡动画
- **文件结构**
  - 修改：`packages/rex-console-web/src/components/GlobalQueryModal.vue` — 包裹 `<Transition name="modal">`
  - 修改：`packages/rex-console-web/src/components/EnvironmentEditModal.vue` — 同上
  - 修改：`packages/rex-console-web/src/features/agents/AgentCard.vue`（配置弹窗）— 同上
- **接口设计**
  - 复用 ConfirmDialog 已有的 `.modal-enter-active` / `.modal-leave-active` 动画（scale 0.95→1 + opacity）
  - 弹窗 overlay 同步 fade
- **交互设计**
  - 所有弹窗打开时：0.2s scale 0.95→1 + opacity 0→1
  - 关闭时：0.15s scale 1→0.95 + opacity 1→0
  - `prefers-reduced-motion` 时跳过动画
- **后端流程**：无
- **测试标准**：打开/关闭各弹窗时动画流畅，无闪烁
- **提交信息**：`feat(ux): add transition animations to modals`

## 设计核对点

1. **Token 一致性**：所有组件使用 variables.css 中的 token，无硬编码颜色值
2. **主题兼容**：dark/light 主题下所有主要页面（Dashboard、Settings、SQL Console、Terminal）可读
3. **动画一致性**：所有弹窗使用统一的 modal 过渡动画
4. **样式单一来源**：全局类在 base.css 中定义一次，组件不重复定义
5. **无障碍**：`prefers-reduced-motion` 支持，所有交互元素有 focus ring
6. **已知 bug 修复**：#3/#4/#5 三个前端 bug 全部解决
