# 0.62.0: 审计日志移动端优化

## Context

0.61.0 完成了 Agent 管理移动端优化。审计日志页面（PRODUCT.md 3.10）的筛选栏在移动端水平排列会拥挤，日志表格在窄屏下无法完整显示。

版本类型：minor（新功能，无后端变更）

## 产品边界

**做什么：**
- 审计日志筛选栏移动端垂直排列
- 审计日志表格移动端水平滚动
- 审计统计卡片移动端布局优化

**不做什么：**
- 不修改后端审计 API
- 不改变桌面端审计日志行为

## 子任务详细设计

### 1 审计日志筛选栏移动端适配

- **功能目标**：优化筛选栏在移动端的布局，从水平排列改为垂直堆叠
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/AuditLog.vue`
- **功能点**：
  - 筛选栏在移动端（< 768px）改为垂直排列
  - 筛选分隔线在移动端隐藏
  - 筛选 select 在移动端全宽
  - 重置按钮在移动端右对齐
- **提交信息**：`feat: adapt audit log filters for mobile`

### 2 审计日志表格移动端适配

- **功能目标**：优化日志表格在移动端的可读性
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/AuditLog.vue`
- **功能点**：
  - 表格外层添加 `overflow-x: auto` 支持水平滚动
  - 表格设置 `min-width: 600px` 保证内容不挤压
  - 表格行在移动端减小内边距
- **提交信息**：`feat: adapt audit log table for mobile`

### 3 审计统计卡片移动端适配

- **功能目标**：优化统计卡片在移动端的布局
- **文件结构**：
  - 修改 `packages/rex-console-web/src/pages/AuditLog.vue`
- **功能点**：
  - 统计卡片在移动端（< 768px）切换为 2 列网格
  - 卡片内边距在移动端减小
- **提交信息**：`feat: adapt audit stats cards for mobile`
