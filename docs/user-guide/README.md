# REX Hub 用户指南

## 快速开始

### 1. 安装

```bash
# Docker 部署（推荐）
docker run -d \
  --name rex-hub \
  -p 3000:3000 \
  -v rex-data:/data \
  ghcr.io/jlin/rex-hub:latest

# 二进制部署
./rex-hub
```

### 2. 首次访问

1. 打开浏览器访问 `http://localhost:3000`
2. 首次运行会自动跳转到密码设置页面
3. 设置管理员密码后进入系统

### 3. 创建环境

1. 点击侧边栏「环境」→「新建环境」
2. 填写环境名称和描述
3. 选择连接方式（直连 / Agent 代理）

### 4. 添加资源

1. 进入环境详情页
2. 点击「添加资源」
3. 选择协议（SSH / MySQL / PostgreSQL / Redis / S3）
4. 填写连接信息
5. 测试连接成功后创建

### 5. 连接资源

- **SSH 终端**：在工作空间中打开 SSH Tab
- **数据库**：在 SQL 控制台中选择数据源
- **Redis**：在 Redis 控制台中连接
- **文件管理**：在文件管理器中浏览远程文件

## 功能模块

### 工作空间

多标签工作区，支持分屏、广播模式、快捷键。

### SSH 终端

基于 xterm.js 的完整终端，支持主题、查找、SFTP 抽屉。

### SQL 控制台

数据库查询管理，支持 MySQL / PostgreSQL / SQLite。

### Redis 控制台

Redis 缓存管理，支持键树、值查看器、CLI。

### 文件管理

SFTP / S3 文件浏览和传输，支持双面板、传输队列。

### Agent 管理

内网穿透代理管理，支持自动注册、配置、日志查看。
